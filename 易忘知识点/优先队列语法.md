# C++ 优先队列（priority_queue）语法速查

## 1. 默认 = 大顶堆

```cpp
priority_queue<int> pq;        // 默认大顶堆，top() 是最大值
priority_queue<int> pq(vec.begin(), vec.end());  // 用数组初始化
```

## 2. 小顶堆（要写全三个模板参数）

```cpp
priority_queue<int, vector<int>, greater<int>> minHeap;  // top() 是最小值
//                  底层容器        比较器（greater → 小顶堆）
```

> 记法：`greater` → 堆顶反而是小的 → **小顶堆**。

## 3. 自定义比较器（用 lambda，注意 `=` 不能漏！）

```cpp
auto cmp = [](ListNode* a, ListNode* b) {
    return a->val > b->val;   // > 表示小顶堆（按 val 升序）
};
priority_queue<ListNode*, vector<ListNode*>, decltype(cmp)> pq(cmp);
```

> [!warning] 易错
> `auto cmp[](...)` 是**错的**，编译不过。lambda 必须用 `=` 赋值：
> `auto cmp = [](...){...};`

## 4. 常用成员函数 + 复杂度

```cpp
pq.push(x);   // 入堆 O(log n)
pq.pop();     // 弹出堆顶 O(log n)
pq.top();     // 看堆顶（不弹出）O(1)
pq.size();    // 元素个数
pq.empty();
```

## 5. 用在哪

- **TopK 问题**：找第 K 大 → 大小为 k 的**小顶堆**（见 [[0215-数组中的第K个最大元素]]）
- 合并 K 个有序链表 / 流式数据取最值
- Dijkstra 最短路、动态中位数（双堆）
