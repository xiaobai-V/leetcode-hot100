# C++面向对象 极速速记笔记
## 一、三大核心
1. **封装**：属性私有，方法公开，隐藏实现
2. **继承**：子类复用父类代码，代码复用
3. **多态**：同一接口不同实现，**父类指针/引用调用子类方法**

## 二、类与对象
```cpp
class 类名{
private:  // 私有 本类访问
protected:// 保护 本类+子类
public:   // 公有 全部访问
    // 成员变量
    // 成员函数
};
对象：类名 对象名;
```
- 成员变量**尽量私有**，用`get/set`访问

## 三、构造&析构
1. **构造函数**：同名，无返回，创建对象自动调用
```cpp
Person(){} // 默认构造
Person(int a):age(a){} // 初始化列表(优先用)
```
2. **析构函数**：`~类名()`，释放资源自动调用
```cpp
~Person(){}
```
3. **拷贝构造**：`Person(const Person& p)`
浅拷贝：值复制 | 深拷贝：重新开内存

## 四、this指针
- 指向**当前对象**
- 用途：区分成员变量与形参、返回对象本身

## 五、静态成员 static
1. 静态成员**属于类**，不属于对象
2. 调用：`类名::静态成员`
3. 静态函数**只能访问静态变量**

## 六、继承
```cpp
class 子类 : 继承方式 父类{}
```
- 继承方式：`public`最常用
- 父类私有**子类不可继承**
- 子类构造**先调用父类构造**

## 七、多态（必考）
### 条件
1. 公有继承
2. 重写父类虚函数
3. 父类指针/引用指向子类对象

```cpp
class A{virtual void fun(){}} // 虚函数
class B:A{void fun()override{}} // 重写
A* p = new B; p->fun(); // 走子类
```
- **纯虚函数**：`virtual void fun()=0;`
- 含纯虚函数 = **抽象类**，不能实例化

## 八、访问权限速记
- private：仅本类
- protected：本类+子类
- public：任意

## 九、const修饰
1. `const 成员函数`：不能修改成员变量
2. `const 对象`：只能调用const函数

## 十、重载 vs 重写
- **函数重载**：同类，函数名同，参数不同
- **重写(覆盖)**：父子类，虚函数，声明完全一致

## 十一、内存分区
- 普通成员：存**对象空间**
- 静态成员：存**全局区**
- 虚函数：存在**虚函数表**

## 十二、常用关键字
- `explicit`：禁止隐式类型转换
- `override`：强制检查重写
- `final`：禁止继承/禁止重写
- `friend`：友元，突破访问权限

## 十三、C++11常用
- 列表初始化 `{}`
- 匿名对象 `Person()`
- 移动构造、右值引用`&&`
