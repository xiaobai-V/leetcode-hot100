# 560. 和为 K 的子数组

> [!abstract] 一句话本质
> **前缀和 + 哈希表计数**，不是滑动窗口（因为有负数，窗口和不单调），不是双指针。

> [!quote] 链接
> - https://leetcode.cn/problems/subarray-sum-equals-k/

## 题目
给定整数数组 `nums` 和整数 `k`，统计并返回数组中和为 `k` 的连续子数组的个数。**数组中可能有负数**。

## 思路（从暴力到最优）

**暴力**：枚举所有子数组算和 → O(n²)。

**前缀和 O(n²)**：用 `preSum[j] - preSum[i]` 表示子数组 `nums[i+1..j]` 的和。仍需双层循环枚举 i、j。

**关键转化**：固定 `j`，要找有多少个 `i < j` 满足 `preSum[j] - preSum[i] == k`，移项变 `preSum[i] == preSum[j] - k`。变成"**查询历史前缀和中等于某值的个数**"——经典哈希表场景，和两数之和同构。

**统一边界**：定义虚拟 `preSum[-1] = 0`，初始化 `umap[0] = 1`。这样"从下标 0 开始的子数组恰好和为 k"会被自然处理，不需要特判。

**最终做法**（边遍历边查）：
1. 维护当前前缀和 `preSum`（单变量即可，不需要存数组）
2. 查 `umap[preSum - k]`，加到结果
3. 把 `preSum` 计入哈希表

## 关键卡点

> [!warning] 我当时卡在这
> - **O(n²) 前缀和**：双层循环枚举 i、j。能过但不够优。
> - **想不到 O(n)**：没意识到 `preSum[j] - preSum[i] == k` 可以移项成 `preSum[i] == preSum[j] - k`，从而用哈希表计数。
> - **特判 `preSum[i] == k`**：通过 `umap[0] = 1`（虚拟 `preSum[-1]=0`）一次性消掉。
> - **为什么不是滑动窗口**：负数让窗口和不单调，无法根据当前和与 k 的关系决定窗口收缩还是扩张。

## 代码

```cpp
class Solution {
public:
    int subarraySum(vector<int>& nums, int k) {
        int n = nums.size();
        int res = 0;
        unordered_map<int, int> umap; // 前缀和 -> 出现次数
        int preSum = 0;
        umap[0] = 1; // 虚拟 preSum[-1] = 0，处理从下标 0 开始的子数组

        for (int i = 0; i < n; i++) {
            preSum += nums[i];
            if (umap.find(preSum - k) != umap.end()) {
                res += umap[preSum - k];
            }
            umap[preSum]++;
        }
        return res;
    }
};
```

## 复杂度
- 时间：O(n)
- 空间：O(n) — 哈希表最多存 n 个不同前缀和
