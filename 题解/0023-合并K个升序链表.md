# 23. 合并 K 个升序链表

> [!abstract] 一句话本质
> **K 个有序链表抢一个出口**，用最小堆当"裁判"：每次吐出当前全局最小，弹一个就补一个 `next`。堆的大小始终 ≤ K。

> [!quote] 链接
> - https://leetcode.cn/problems/merge-k-sorted-lists/

## 题目
给定 K 个升序链表数组 `lists`，合并成一个升序链表并返回头节点。

## 思路（从暴力到最优）

**方法一：数组排序（暴力，没利用"各自有序"）**
- 把所有节点塞进数组，按 val 排序，重组 next
- 时间 O(N log N)，空间 O(N)。简单但浪费了"K 条链表本身已有序"这个性质

**方法二：朴素多路归并（利用有序，但找最小太慢）**
- 维护 K 个头指针，每次**线性扫一遍 O(K)** 找最小，接到结果后，该指针后移
- 时间 O(N·K)，空间 O(1)。瓶颈在"找最小"这步

**方法三：最小堆（最优）**
- 把方法二里"O(K) 找最小"换成**最小堆**：堆顶 O(1) 拿最小，push/pop O(log K) 维护
- 堆里始终只放"每条链表当前的候选头"，最多 K 个 → 单次操作 O(log K)
- 总时间 O(N log K)，空间 O(K)

> [!info] 核心直觉
> 看到"从一堆候选里反复取最值"→ 想到堆（优先队列）。这是堆的标志性应用场景。

## 关键卡点
> [!warning] 我当时卡在这
> - **想不到用优先队列/堆**：没想到"反复取最小"是堆的标准场景
> - **C++ 比较器方向记混**：`priority_queue` 默认是**最大堆**；最小堆要传仿函数且用 `a->val > b->val`。口诀——`comp(a,b)` 返回 true 表示 **a 优先级低、排后面**；想最小堆（小在前）就让大的被判低优先级，用 `>`
> - **dummy 虚拟头结点**省去大量边界处理（不用单独处理第一个节点）
> - 边界：`lists` 里**单条链表可能为空**（`!= nullptr` 判断）；**全空**时堆始终为空，循环不进入，返回 `nullptr`，正确

## 代码

```cpp
class Solution {
private:
    struct Cmp {
        bool operator()(ListNode* a, ListNode* b) {
            return a->val > b->val; // 返回 true → a 优先级低，排后面 → 小值堆顶 = 最小堆
        }
    };

public:
    ListNode* mergeKLists(vector<ListNode*>& lists) {
        priority_queue<ListNode*, vector<ListNode*>, Cmp> minHeap;
        for (auto node : lists) {
            if (node != nullptr)      // 跳过空链表
                minHeap.push(node);
        }

        ListNode* dummy = new ListNode(0);
        ListNode* cur = dummy;
        while (!minHeap.empty()) {
            ListNode* top = minHeap.top();   // 当前全局最小
            minHeap.pop();
            cur->next = top;
            cur = cur->next;
            if (top->next)                    // 弹一个补一个，堆大小维持 ≤ K
                minHeap.push(top->next);
        }

        ListNode* head = dummy->next;
        delete dummy;                         // 释放虚拟头
        return head;
    }
};
```

## 复杂度
- 时间：O(N log K)，N = 总节点数，K = 链表数
- 空间：O(K)，堆最多同时存 K 个候选节点

## 一句话记忆点

> K 个有序序列合并 / 反复取最值 → 最小堆当裁判，弹堆顶接尾 + 补 next。C++ 最小堆比较器用 `>`（大的排后面）。
