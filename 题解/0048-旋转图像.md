# 48. 旋转图像

> [!abstract] 一句话本质
> **转置 + 水平翻转 = 顺时针 90°**，不是逐层旋转，而是分解为两个独立的原地操作。

> [!quote] 链接
> - https://leetcode.cn/problems/rotate-image/

## 题目
给定 n×n 矩阵，原地顺时针旋转 90 度。

## 思路（从暴力到最优）

**暴力：辅助矩阵**
新建一个矩阵，`new[j][n-1-i] = old[i][j]`。简单但空间 O(n²)。

**最优：分解为两步原地操作**
观察规律：顺时针 90° = 转置 + 水平翻转

```
原矩阵      转置后      水平翻转后
1 2 3       1 4 7       7 4 1
4 5 6  →    2 5 8  →    8 5 2
7 8 9       3 6 9       9 6 3
```

- 转置：沿主对角线交换 `matrix[i][j]` 和 `matrix[j][i]`
- 水平翻转：每行左右对称交换

两步都是原地，总空间 O(1)。

## 关键卡点

> [!warning] 易错点
> - 转置循环必须 `j < i`，不能 `j < n`，否则每个元素交换两次等于没交换
> - 顺序不能反：先翻转再转置 = 逆时针 90°

## 代码

```cpp
class Solution {
public:
    void rotate(vector<vector<int>>& matrix) {
        int n = matrix.size();
        // 1. 转置
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < i; j++) {
                swap(matrix[i][j], matrix[j][i]);
            }
        }
        // 2. 水平翻转每一行
        for (int i = 0; i < n; i++) {
            for (int left = 0, right = n - 1; left < right; left++, right--) {
                swap(matrix[i][left], matrix[i][right]);
            }
        }
    }
};
```

## 复杂度
- 时间：O(n²)，两次遍历整个矩阵
- 空间：O(1)，原地操作

## 一句话记忆点

> [!tip] 下次看到类似题
> 旋转矩阵 → 转置+翻转组合：
> - 顺时针 90°：转置 → 水平翻转
> - 逆时针 90°：水平翻转 → 转置
