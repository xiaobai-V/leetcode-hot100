# 102. 二叉树的层序遍历

> [!abstract] 一句话本质
> **BFS + 记录每层大小**——用 queue 逐层弹出，每轮先记下当前队列长度就是这一层的节点数。

> [!quote] 链接
> - https://leetcode.cn/problems/binary-tree-level-order-traversal/

## 题目
给定二叉树，返回其节点值的层序遍历（逐层从左到右）。

## 思路

BFS 模板题。核心技巧：**每轮 while 循环开始时，`q.size()` 就是当前层的节点数**，用 for 循环弹出这一层的所有节点，同时把下一层的子节点入队。一轮结束就得到了一层的结果。

为什么不能直接 `while(!q.empty())` 逐个弹出？因为那样你不知道哪些属于同一层。`sz = q.size()` 这个"快照"就是分层的关键。

## 关键卡点

> [!warning] 易错点
> - `sz = q.size()` 必须在 for 循环**之前**取，否则循环中 queue 在变化，size 不准
> - 空树直接返回空 vector，别漏

## 代码

```cpp
class Solution {
private:
    vector<vector<int>> res;
    void bfs(TreeNode* root) {
        if (!root) return;
        queue<TreeNode*> q;
        q.push(root);
        while (!q.empty()) {
            int sz = q.size();
            vector<int> path;
            for (int i = 0; i < sz; i++) {
                root = q.front();
                q.pop();
                path.push_back(root->val);
                if (root->left) q.push(root->left);
                if (root->right) q.push(root->right);
            }
            res.push_back(path);
        }
    }
public:
    vector<vector<int>> levelOrder(TreeNode* root) {
        bfs(root);
        return res;
    }
};
```

## 复杂度
- 时间：O(n)，每个节点访问一次
- 空间：O(n)，队列最多存一层节点，最宽一层约 n/2
