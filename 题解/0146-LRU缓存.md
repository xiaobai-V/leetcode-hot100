# 146. LRU 缓存

> [!abstract] 一句话本质
> **LRU = 淘汰最久没用的**。用「哈希表 O(1) 定位 + 双向链表 O(1) 维护使用顺序」：命中就移到头部，满了就删尾部。

> [!quote] 链接
> - https://leetcode.cn/problems/lru-cache/

## 题目
设计一个容量为 `capacity` 的 LRU 缓存，支持 `get(key)` 和 `put(key, value)`，两者都要 **O(1)**。容量满时 `put` 淘汰最久未使用的 key。

## 思路

**为什么单个数据结构不行？**
- 纯哈希表：O(1) 查找，但**无法记录"使用顺序"** → 没法知道谁最久没用
- 纯链表/数组：能记录顺序，但查找/移动不是 O(1)

**最优解：哈希表 + 双向链表（各司其职）**

| 结构 | 职责 | 为什么 |
|---|---|---|
| `unordered_map<int, Node*>` | key → 节点指针，**O(1) 定位** | 满足 get/put 查找 |
| 双向链表 | **维护使用顺序**：最近用的在 head 端，最久没用的在 tail 端 | map 做不到的事 |

两者靠"map 存的是链表节点指针"这根线串起来：map 负责找，链表负责排序。

**核心规则**（一条心法覆盖大半逻辑）：**只要 get 或 put 命中一个 key，就把它移到头部变"最新"。**

- get 命中 / put 覆盖已存在 key → 移到头部
- put 新 key 未满 → 新建节点插到头部 + 存 map
- put 新 key 已满 → 删尾部 + 新建节点插到头部 + 存 map

**两个基本操作（地基）**：
- `remove(x)`：把 x 从链表**摘下来**，只改前后节点的指针，**不动内存**
- `addToHead(x)`：把**游离节点** x 插到 head 之后
- "移到头部" = `remove(x); addToHead(x);` 两步走

> [!info] 为什么必须双向链表？
> 移到头部要先摘下节点，摘节点要改前驱。单向链表没有 `prev`，找前驱要 O(n)；双向链表节点自带 `prev`，O(1) 改指针。**移动是高频操作，所以必须双向。**

## 关键卡点
> [!warning] 我当时卡在这
> - **一开始只用单哈希表**，发现无法记录使用顺序（自己都问出"如何标记"）→ 必须加双向链表
> - **Node 必须存 key**：淘汰尾节点后要靠 `node->key` 去 map 删项，光存 val 不够
> - **remove 只摘链、不 `delete`**：它要服务两个场景——淘汰（可删）和移到头部（要复用，不能删）。delete 写死在 remove 里会炸
> - **addToHead 只插入、不摘链**：接收的必须是游离节点，否则对 `pre=nullptr` 的新节点解引用崩溃。所以"移到头部"必须 `remove` 在前
> - **构造函数要 head/tail 互连**：`head->next = tail;` 之后**别忘了 `tail->pre = head;`**
> - **get/put 命中都要移到头部**：容易只 `return val` 或只更新 val 忘了移动
> - **put 已满时 erase + delete 两个都要做**：`erase` 删 map、`delete` 删内存，两套独立，少一个要么悬空指针要么内存泄漏

## 代码

```cpp
class LRUCache {
private:
    struct Node {
        int key, val;
        Node* pre;
        Node* next;
        Node(int k, int v) : key(k), val(v), pre(nullptr), next(nullptr) {}
    };

    int cap;
    unordered_map<int, Node*> umap;
    Node* head;
    Node* tail;

    void remove(Node* x) {              // 摘链，不动内存
        x->pre->next = x->next;
        x->next->pre = x->pre;
    }
    void addToHead(Node* x) {           // 把游离节点插到 head 后
        x->next = head->next;
        head->next->pre = x;
        head->next = x;
        x->pre = head;
    }

public:
    LRUCache(int capacity) {
        cap = capacity;
        head = new Node(0, 0);
        tail = new Node(0, 0);
        head->next = tail;
        tail->pre = head;               // 双向都要连
    }

    int get(int key) {
        if (umap.find(key) != umap.end()) {
            remove(umap[key]);          // 移到头部 = 摘 + 插
            addToHead(umap[key]);
            return umap[key]->val;
        }
        return -1;
    }

    void put(int key, int value) {
        if (umap.count(key)) {          // 已存在：更新 + 移到头部
            umap[key]->val = value;
            remove(umap[key]);
            addToHead(umap[key]);
        } else if (umap.size() < cap) { // 未满：新建 + 插头部 + 存 map
            Node* t = new Node(key, value);
            addToHead(t);
            umap[key] = t;
        } else {                        // 已满：淘汰尾部 + 新建插入
            Node* old = tail->pre;
            umap.erase(old->key);       // 删 map
            remove(old);
            delete old;                 // 删内存
            Node* t = new Node(key, value);
            addToHead(t);
            umap[key] = t;
        }
    }
};
```

## 复杂度
- get / put：均 **O(1)**（哈希表查/插 O(1) + 改固定个数链表指针 O(1)）
- 空间：O(capacity)
