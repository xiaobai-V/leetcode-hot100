# 54. 螺旋矩阵

> [!abstract] 一句话本质
> **用四个边界变量收缩模拟螺旋遍历**，不是方向数组 + visited 标记，而是维护 up/down/left/right 逐层剥洋葱。

> [!quote] 链接
> - https://leetcode.cn/problems/spiral-matrix/

## 题目
给定 m×n 矩阵，按螺旋顺序返回所有元素。

## 思路（从暴力到最优）

**暴力：方向数组 + visited**
用方向数组 `{0,1},{1,0},{0,-1},{-1,0}` 循环转向，额外开一个 visited 矩阵记录是否访问过。简单但空间 O(mn)。

**最优：四边界收缩**
维护 `up/down/left/right` 四个边界，每走完一行/一列就收缩对应边界：
- → 走完顶部行：`up++`
- ↓ 走完右侧列：`right--`
- ← 走完底部行：`down--`
- ↑ 走完左侧列：`left++`

一圈走完，进入内层，直到元素收集完毕。

**关键：提前返回**
最后一圈可能只剩一行或一列，走完第一个方向就凑够了，后面三个方向不能继续走。在每个 for 循环内部加 `if (res.size() == m*n) return` 即可。

## 关键卡点

> [!warning] 我当时卡在这
> - 边界条件不重不漏：单行、单列时容易重复访问
> - 收缩时机：走完一个方向后立即收缩，但下一个方向要用收缩前的边界
> - 提前返回：while 条件只在圈首检查，中途凑够必须手动 return

## 代码

```cpp
class Solution {
public:
    vector<int> spiralOrder(vector<vector<int>>& matrix) {
        vector<int> res;
        int m = matrix.size(), n = matrix[0].size();
        int up = 0, down = m - 1, left = 0, right = n - 1;
        while (res.size() < m * n) {
            for (int j = left; j <= right; j++) {
                res.push_back(matrix[up][j]);
                if (res.size() >= m * n) return res;
            }
            up++;
            for (int i = up; i <= down; i++) {
                res.push_back(matrix[i][right]);
                if (res.size() >= m * n) return res;
            }
            right--;
            for (int j = right; j >= left; j--) {
                res.push_back(matrix[down][j]);
                if (res.size() >= m * n) return res;
            }
            down--;
            for (int i = down; i >= up; i--) {
                res.push_back(matrix[i][left]);
                if (res.size() >= m * n) return res;
            }
            left++;
        }
        return res;
    }
};
```

## 复杂度
- 时间：O(m×n)，每个元素访问一次
- 空间：O(1)，只用四个边界变量（不计结果数组）
