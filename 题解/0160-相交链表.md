# 160. 相交链表

> [!abstract] 一句话本质
> **找两个链表的第一个公共节点**，本质是让两个指针走完各自的"总路程"后相遇。

> [!quote] 链接
> - https://leetcode.cn/problems/intersection-of-two-linked-lists/

## 题目
给定两个单链表 headA 和 headB，判断它们是否相交，若相交返回第一个公共节点，否则返回 null。

## 思路（从暴力到最优）

**方法一：哈希表**
- 遍历链表 A，把所有节点指针存入哈希集合
- 遍历链表 B，每走一步查集合，第一个命中的就是交点
- 时间 O(m+n)，空间 O(m)

**方法二：双指针（最优）**
- 先分别求出两条链表的长度 a、b
- 让较长链表的指针先走 |a-b| 步，对齐"剩余路程"
- 然后两个指针同步走，第一个相等的节点就是交点
- 时间 O(m+n)，空间 O(1)

> [!tip] 更优雅的写法
> 双指针还有一种写法：pA 走完 A 就接上 headB，pB 走完 B 就接上 headA，这样两者走的总路程都是 a+b-c，一定会在交点相遇（或同时走到 null）。

## 关键卡点
> [!warning] 我当时卡在这
> - 存节点指针而不是节点值——值相同不代表是同一个节点
> - 不相交时返回 nullptr，不会死循环

## 代码

**哈希表解法：**
```cpp
class Solution {
public:
    ListNode *getIntersectionNode(ListNode *headA, ListNode *headB) {
        unordered_set<ListNode *> uset;
        ListNode *temp = headA;
        while (temp != nullptr) {
            uset.insert(temp);
            temp = temp->next;
        }
        temp = headB;
        while (temp != nullptr) {
            if (uset.count(temp)) return temp;
            temp = temp->next;
        }
        return nullptr;
    }
};
```

**双指针解法：**
```cpp
class Solution {
public:
    ListNode* getIntersectionNode(ListNode* headA, ListNode* headB) {
        int lenA = 0, lenB = 0;
        ListNode* curA = headA;
        ListNode* curB = headB;
        while (curA != nullptr) { lenA++; curA = curA->next; }
        while (curB != nullptr) { lenB++; curB = curB->next; }
        curA = headA; curB = headB;
        if (lenA > lenB)
            for (int i = 0; i < lenA - lenB; i++) curA = curA->next;
        else
            for (int i = 0; i < lenB - lenA; i++) curB = curB->next;
        while (curA != nullptr && curB != nullptr) {
            if (curA == curB) return curA;
            curA = curA->next;
            curB = curB->next;
        }
        return nullptr;
    }
};
```

## 复杂度
- 哈希表：时间 O(m+n)，空间 O(m)
- 双指针：时间 O(m+n)，空间 O(1)
