# 114. 二叉树展开为链表

> [!abstract] 一句话本质
> **把二叉树原地展开成右倾链表**，核心是后序遍历 + 拼接子树。

> [!quote] 链接
> - https://leetcode.cn/problems/flatten-binary-tree-to-linked-list/

## 题目

给定二叉树根节点，原地展开成右倾链表，顺序为前序遍历（根→左→右）。

## 思路（从暴力到最优）

### 解法一：后序遍历 + 拼接（自写，更直观）

前序遍历是根→左→右，展开后左子树在中间。所以：
1. 先递归展开左右子树
2. 把左子树接到右边，左指针置空
3. **遍历到左子树的最后一个节点**，把原来的右子树接上

之前错在哪：`left->right = right`——`left` 是左子树的**根节点**，不是**最后一个节点**！左子树展开后是链表，要走到末尾才能接右子树。

### 解法二：后序遍历（根→右→左）+ 全局变量

用全局变量 `prev` 记录"上一个访问的节点"，从右往左遍历：
- 每次把当前节点的 `right` 指向 `prev`
- `left` 置空
- 更新 `prev = root`

本质是**逆序构建链表**——先处理最右边的节点，逐步往左拼接。

两种解法对比：
- 解法一：更直观，但需要遍历左子树找末尾节点
- 解法二：更简洁，O(1) 额外操作，但思路不那么直接

## 关键卡点

> [!warning] 我当时卡在这
> - **错把左子树根节点当最后节点**：`left->right = right` 是错的，`left` 只是根，要遍历到末尾才能接右子树
> - **忘记清空左指针**：展开后所有节点的 `left` 必须是 `nullptr`

> [!warning] 易错边界
- 空树直接返回
- 只有左子树或只有右子树时，代码也能处理

## 代码

### 解法一：后序遍历 + 拼接（自写）

```cpp
class Solution {
public:
    void flatten(TreeNode* root) {
        if (!root) return;
        flatten(root->left);
        flatten(root->right);

        TreeNode* left = root->left;
        TreeNode* right = root->right;

        root->left = nullptr;
        root->right = left;

        // 遍历到左子树的最后一个节点
        TreeNode* p = root;
        while (p->right != nullptr) {
            p = p->right;
        }
        p->right = right;
    }
};
```

### 解法二：后序遍历（根→右→左）+ 全局变量

```cpp
class Solution {
private:
    TreeNode* pre = nullptr;
public:
    void flatten(TreeNode* root) {
        if (!root) return;
        flatten(root->right);
        flatten(root->left);
        root->left = nullptr;
        root->right = pre;
        pre = root;
    }
};
```

### 解法三：迭代 + O(1) 额外空间（推荐）

不用递归栈，原地完成。对每个有左子树的节点：找左子树最右节点，把原右子树挂上去，再把左子树整体挪到右、`left` 置空。

```cpp
class Solution {
public:
    void flatten(TreeNode* root) {
        TreeNode* cur = root;
        while (cur) {
            if (cur->left) {
                TreeNode* left = cur->left;
                TreeNode* temp = cur->left;
                while (temp->right) temp = temp->right;   // 左子树最右节点
                temp->right = cur->right;                 // 原右子树挂到末尾
                cur->left = nullptr;
                cur->right = left;                        // 左子树挪到右
            }
            cur = cur->right;
        }
    }
};
```

## 复杂度

- 解法一：时间 O(n)，最坏情况（链状左子树）需要遍历左子树找末尾，均摊 O(n)；空间 O(h)
- 解法二：时间 O(n)，每个节点恰好一次；空间 O(h)
- 解法三（迭代）：时间 O(n)；**额外空间 O(1)**（不用递归栈），最优
