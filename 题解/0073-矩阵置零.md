# 73. 矩阵置零

> [!abstract] 一句话本质
> **用矩阵自身的第一行和第一列当标记数组**，实现 O(1) 额外空间，不是开额外数组记录。

> [!quote] 链接
> - https://leetcode.cn/problems/set-matrix-zeroes/

## 题目
给定 `m x n` 矩阵，若某个元素为 0，则将其所在行和列全部置为零。要求原地操作。

## 思路（从暴力到最优）

**方法 A：O(m+n) 额外空间**
用两个数组 `rowIndex[m]`、`columnIndex[n]` 记录哪些行/列需要置零。第一遍扫描记录，第二遍按标记清零。简单直观。

**方法 B：O(1) 空间（进阶）**
观察到方法 A 的标记数组可以复用矩阵本身——**用第一行和第一列当标记**。

关键步骤：
1. **先单独检查**第一行、第一列本身是否有 0（用 `firstRowHasZero`、`firstColumnHasZero` 记录），因为后面会用它们当标记，会覆盖原始值。
2. **标记阶段**（`i` 从 1 开始）：遍历 `matrix[1..m-1][0..n-1]`，若 `matrix[i][j]==0`，则 `matrix[i][0]=0`、`matrix[0][j]=0`。
3. **按标记清零**：遍历 `i=1..m-1`，若 `matrix[i][0]==0` 则整行清零；遍历 `j=0..n-1`，若 `matrix[0][j]==0` 则整列清零。
4. **最后处理**第一行/第一列：根据步骤 1 的标志决定是否清零。

## 关键卡点

> [!warning] 我当时卡在这
> - **为什么要先单独检查第一行/第一列**：不检查就直接当标记，后面无法判断它们本身是否需要清零。
> - **标记阶段 i 为什么从 1 开始**：从 0 开始会把第一行/第一列的值改掉（它们本身就是标记数组），标记信息被破坏。
> - **单元素矩阵**：`[[0]]` 或 `[[1]]` 都能正确处理，因为第一行/第一列的单独检查覆盖了这个 case。

## 代码

```cpp
// 方法 B：O(1) 空间
class Solution {
public:
    void setZeroes(vector<vector<int>>& matrix) {
        int m = matrix.size(), n = matrix[0].size();
        int firstRowHasZero = 0, firstColumnHasZero = 0;

        // 检查第一列是否有 0
        for (int i = 0; i < m; i++)
            if (matrix[i][0] == 0) firstColumnHasZero = 1;
        // 检查第一行是否有 0
        for (int j = 0; j < n; j++)
            if (matrix[0][j] == 0) firstRowHasZero = 1;

        // 用第一行、第一列做标记（i 从 1 开始）
        for (int i = 1; i < m; i++)
            for (int j = 0; j < n; j++)
                if (matrix[i][j] == 0) {
                    matrix[i][0] = 0;
                    matrix[0][j] = 0;
                }

        // 按标记清零行
        for (int i = 1; i < m; i++)
            if (matrix[i][0] == 0)
                for (int j = 0; j < n; j++)
                    matrix[i][j] = 0;

        // 按标记清零列
        for (int j = 0; j < n; j++)
            if (matrix[0][j] == 0)
                for (int i = 0; i < m; i++)
                    matrix[i][j] = 0;

        // 最后处理第一行/第一列
        if (firstRowHasZero)
            for (int j = 0; j < n; j++) matrix[0][j] = 0;
        if (firstColumnHasZero)
            for (int i = 0; i < m; i++) matrix[i][0] = 0;
    }
};
```

## 复杂度
- 方法 A：时间 O(mn)，空间 O(m+n)
- 方法 B：时间 O(mn)，空间 O(1)
