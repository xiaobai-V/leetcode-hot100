# 15. 三数之和

> [!abstract] 一句话本质
> **排序 + 固定一个数 + 双指针两数之和**。本质是 n 遍 Two Sum，target = -nums[i]。

> [!quote] 链接
> - https://leetcode.cn/problems/3sum/

## 题目
找出数组中所有三元组 [a,b,c]，使 a + b + c = 0。结果不能有重复三元组。

## 思路（从暴力到最优）
1. **暴力**：三重循环枚举，O(n³)，且有大量重复需要去重。
2. **排序 + 双指针**：
   - 先排序，使双指针有方向性（和太大移右指针，太小移左指针）。
   - 固定 `nums[i]`，在 `i+1` 到末尾用双指针找 `nums[j] + nums[k] = -nums[i]`。
   - 排序后相同数相邻，去重只需和前一个比较。
3. **去重三层**：
   - `i`：跳过 `nums[i] == nums[i-1]`，避免相同 target。
   - `j`/`k`：找到答案后，记录当前值，while 跳过所有相同值。

## 关键卡点
> [!warning] 我当时卡在这
> - 找到答案后直接 break，遗漏了同一 target 下的多组解
> - j/k 去重逻辑过于复杂——简化方案：只在找到答案时用 while 跳过相同值
> - `<` 和 `>` 分支不需要去重，只有 `==` 分支需要

## 代码
```cpp
class Solution {
public:
    vector<vector<int>> threeSum(vector<int>& nums) {
        sort(nums.begin(), nums.end());
        vector<vector<int>> ans;
        for (int i = 0; i <= (int)nums.size() - 3; i++) {
            if (i > 0 && nums[i] == nums[i - 1]) continue;
            int j = i + 1, k = nums.size() - 1;
            while (j < k) {
                int sum = nums[j] + nums[k];
                if (sum < -nums[i]) {
                    j++;
                } else if (sum > -nums[i]) {
                    k--;
                } else {
                    ans.push_back({nums[i], nums[j], nums[k]});
                    int val_j = nums[j], val_k = nums[k];
                    while (j < k && nums[j] == val_j) j++;
                    while (j < k && nums[k] == val_k) k--;
                }
            }
        }
        return ans;
    }
};
```

## 复杂度
- 时间：O(n²)，排序 O(n log n) + n 次双指针 O(n)
- 空间：O(1)（不含输出）
