# 206. 反转链表

> [!abstract] 一句话本质
> **逐个断开旧指针、接上新指针**，不是"调换头尾"而是"逐节点翻转指向"。

> [!quote] 链接
> - https://leetcode.cn/problems/reverse-linked-list/

## 题目
给定单链表头节点 head，反转链表，返回新的头节点。

## 思路（从暴力到最优）

**核心操作**：每个节点的 next 指向前一个节点。

**方法一：迭代**
- 三个指针保护现场：pre（已反转部分的头）、cur（当前节点）、temp（暂存 cur->next）
- 循环中：先记 temp = cur->next，再 cur->next = pre，然后 pre = cur, cur = temp
- cur 为 nullptr 时，pre 就是新头

**方法二：递归**
- 递归函数 reverse(pre, cur)：把 cur 及其后续节点反转，pre 是已反转部分
- base case：cur == nullptr → return pre
- 递归：暂存 temp = cur->next，cur->next = pre，递归 reverse(cur, temp)
- 本质和迭代一样，只是用递归栈代替手动循环

## 关键卡点
> [!warning] 我当时卡在这
> - 三个指针缺一不可：temp 暂存 cur->next 是为了断链后不丢失后续节点
> - 递归思路：假设后面的已经反转好了，当前节点只需要接上去

## 代码

**迭代：**
```cpp
class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        ListNode* pre = nullptr;
        ListNode* cur = head;
        while (cur != nullptr) {
            ListNode* temp = cur->next;
            cur->next = pre;
            pre = cur;
            cur = temp;
        }
        return pre;
    }
};
```

**递归：**
```cpp
class Solution {
    ListNode* reverse(ListNode* pre, ListNode* cur) {
        if (cur == nullptr) return pre;
        ListNode* temp = cur->next;
        cur->next = pre;
        return reverse(cur, temp);
    }
public:
    ListNode* reverseList(ListNode* head) {
        return reverse(nullptr, head);
    }
};
```

## 复杂度
- 迭代：时间 O(n)，空间 O(1)
- 递归：时间 O(n)，空间 O(n)（栈帧）
