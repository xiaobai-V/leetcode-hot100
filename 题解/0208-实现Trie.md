# 208. 实现 Trie (前缀树)

> [!abstract] 一句话本质
> **Trie = 每个节点存 26 个子指针 + 一个 isEnd 标记**。三个操作都是逐字符往下走：insert 走不动就新建，search 走完看 isEnd，startsWith 走完就 true。

> [!quote] 链接
> - https://leetcode.cn/problems/implement-trie-prefix-tree/

## 题目
实现 Trie，支持 insert(word)、search(word)、startsWith(prefix) 三个操作。

## 思路
Trie 是一棵 26 叉树，每个节点代表一个字符：
- `next[26]`：26 个子指针，对应 'a'-'z'
- `isEnd`：标记这个节点是否是某个单词的结尾

三个操作都是同一个套路：从根节点开始，逐字符往下走。

## 关键卡点
> [!warning] 我当时卡在这
> - Trie 类本身可以当节点用（第一种写法），也可以单独定义 Node（第二种写法），推荐第二种更清晰
> - `memset(next, 0, sizeof(next))` 可以初始化指针数组为 nullptr
> - search 和 startsWith 的唯一区别：最后返回 `cur->isEnd` vs `return true`

## 代码
```cpp
class Trie {
private:
    struct Node {
        bool isEnd;
        Node* next[26];
        Node() : isEnd(false) {
            for (int i = 0; i < 26; i++) next[i] = nullptr;
        }
    };
    Node* head;

public:
    Trie() : head(new Node()) {}

    void insert(string word) {
        Node* cur = head;
        for (char ch : word) {
            int idx = ch - 'a';
            if (!cur->next[idx]) cur->next[idx] = new Node();
            cur = cur->next[idx];
        }
        cur->isEnd = true;
    }

    bool search(string word) {
        Node* cur = head;
        for (char ch : word) {
            int idx = ch - 'a';
            if (!cur->next[idx]) return false;
            cur = cur->next[idx];
        }
        return cur->isEnd;
    }

    bool startsWith(string prefix) {
        Node* cur = head;
        for (char ch : prefix) {
            int idx = ch - 'a';
            if (!cur->next[idx]) return false;
            cur = cur->next[idx];
        }
        return true;
    }
};
```

## 复杂度
- 时间：O(L) — L 为字符串长度，每次操作逐字符遍历
- 空间：O(N×L) — N 个单词，平均长度 L
