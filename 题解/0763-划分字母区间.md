# 763. 划分字母区间

> [!abstract] 一句话本质
> **把串切成尽可能多的片段，每个字母只属于一个片段**。每段右边界 = 段内所有字母「最后出现位置」的最大值；扫到 `i == 右边界` 就切一刀。骨架和 [[0045-跳跃游戏II]] 同构。

> [!quote] 链接
> - https://leetcode.cn/problems/partition-labels/

## 题目
字符串 `s`，切成尽可能多的片段，使每个字母只出现在一个片段里。返回所有片段的长度列表。

## 思路（从暴力到最优）

**硬约束翻译**：「每个字母只在一个片段」= 一个片段必须包住其中所有字母的**最后一次出现**。所以某段的右边界 ≥ 段内任一字母的最后位置。

**暴力**：扫到一个字母就 for 一遍找它最右 → 每次 O(n)，整体 O(n²)，又慢又易写错。

**最优（预处理 + 一次扫描，O(n)）**：
1. **预处理** `last` 表：先扫一遍，`last[c] = i`，同一字母后面覆盖前面，天然留下「最后出现」。
2. **主扫描切分**：维护 `curEnd`（当前段右边界）、`preEnd`（上一段终点+1 = 本段起点）。
   - `curEnd = max(curEnd, last[s[i]])`：这个字母最远到哪，段就得包到哪。
   - `i == curEnd` 时：段内所有字母都被包住 → **最早合法切点**，记长度 `curEnd - preEnd + 1`，`preEnd = curEnd + 1` 开新段。

> [!info] 为什么 `curEnd` 取 max
> 一段里可能有多个不同字母，每个都不能漏到下一段。段的右边界必须 ≥ 段内**每个**字母的最后位置 → 取它们的最大值。直接 `curEnd = last[s[i]]` 会丢掉之前字母的更远要求。

> [!info] 为什么 `i == curEnd` 是最早合法切点
> - 往前切：会把某个最后位置 > 切点的字母拆进两段 → 不合法。
> - 往后切：合法但段更少 → 不是「尽可能多段」的最优。
> - 恰好在 `curEnd` 切：段内字母的最后位置都 ≤ curEnd，全包住了，且是最早。

## 关键卡点
> [!warning] 我当时卡在这
> - 一开始想「边扫边现找某字母最右」（写了 `maxPos`），既 O(n²) 低效、又写出 `s[i] == start`（char 与 int 比）的类型 bug。**直接删掉，改用预处理。**
> - 没想清「预处理必须单独先扫一遍」：判断 `i == curEnd` 时 `last[s[i]]` 必须是字母的**全局最后**位置，必须提前算好；若合并进主循环边扫边赋值，`last[s[i]] == i` 会让 `curEnd` 被 `i` 推着走、每个字母都切成一段。
> - `curEnd` 是 `max` 而非直接赋值——段内多字母要取最远。

## 代码
```cpp
class Solution {
public:
    vector<int> partitionLabels(string s) {
        unordered_map<char, int> last;          // 每个字母最后出现的位置
        int n = s.size();
        for (int i = 0; i < n; i++) last[s[i]] = i;   // 预处理

        vector<int> res;
        int curEnd = 0, preEnd = 0;              // 当前段右边界 / 本段起点
        for (int i = 0; i < n; i++) {
            curEnd = max(curEnd, last[s[i]]);     // 这字母最远到哪，段就包到哪
            if (i == curEnd) {                    // 最早合法切点
                res.push_back(curEnd - preEnd + 1);
                preEnd = curEnd + 1;              // 新段起点
            }
        }
        return res;
    }
};
```
> 也可用 `int last[26]` + `s[i]-'a'` 当下标，比 `unordered_map` 更省。

## 复杂度
- 时间：O(n)，两次线性扫描。
- 空间：O(1)，`last` 只有 26 个字母。
