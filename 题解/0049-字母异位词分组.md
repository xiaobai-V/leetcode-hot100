# 49. 字母异位词分组

> [!abstract] 一句话本质
> **异位词排序后相同**，用排序后的字符串当哈希 key，让哈希表自动分组，而不是逐一比对。

> [!quote] 链接
> - https://leetcode.cn/problems/group-anagrams/

## 题目
给定字符串数组，将字母异位词分组在一起。字母异位词指字母相同但排列不同的字符串。

## 思路（从暴力到最优）
1. **暴力**：两两比较字符频率，O(n²·k)，太慢。
2. **排序 + 哈希**：对每个字符串排序，异位词排序结果相同 → 用排序后的字符串当 key，`unordered_map<string, vector<string>>` 自动分组。遍历一遍即可。
3. **优化：计数数组替代排序**：用 `int count[26]` 统计字符频率，拼成字符串（如 `"#1#0#2#..."` ）当 key。每个字符串 O(k) 而非 O(k log k)。

## 关键卡点
> [!warning] 我当时卡在这
> - 一开始想用 `vector<unordered_map>` 逐一比对，思路绕远
> - `std::sort` 是原地排序无返回值，需要先复制字符串再排序
> - `unordered_map` 的 `[]` 会自动创建不存在的 key，if/else 判断可以省略
> - 遍历 map 取值时，迭代器是 `pair`，需要 `.second` 取 vector

## 代码
```cpp
class Solution {
public:
    vector<vector<string>> groupAnagrams(vector<string>& strs) {
        unordered_map<string, vector<string>> umap;
        for (int i = 0; i < strs.size(); i++) {
            string key = strs[i];
            sort(key.begin(), key.end());
            umap[key].push_back(strs[i]);
        }
        vector<vector<string>> result;
        for (auto& temp : umap) {
            result.push_back(temp.second);
        }
        return result;
    }
};
```

## 复杂度
- 时间：O(n · k log k)，n 为字符串数量，k 为平均长度
- 空间：O(n · k)，哈希表存储所有字符串

> [!note] 优化版复杂度
> 用计数数组当 key：时间 O(n · k)，空间不变。
