# 45. 跳跃游戏 II

> [!abstract] 一句话本质
> **求到达终点的最少跳跃次数**，不是「能不能到」（那是 [[0055-跳跃游戏]]），而是「最少几步」。把每一跳能覆盖的范围看成 BFS 的**一层**，答案 = 层数。

> [!quote] 链接
> - https://leetcode.cn/problems/jump-game-ii/

## 题目
非负整数数组 `nums`，初始在下标 0，`nums[i]` 表示从下标 `i` 最多能跳几步。保证能到达终点，求**最少跳跃次数**到末尾下标。

## 思路（从暴力到最优）

**暴力 BFS 思想**：从下标 0 出发，第一跳覆盖 `[1, nums[0]]`，这一段是「第 1 层」；再从这一层出发，能到的最远是「第 2 层」……每拓展一层步数 +1，到达终点的层数即为答案。朴素 BFS 反复扫描区间 → O(n²)。

**贪心优化（O(n)）**：边遍历边维护两个变量——
- `maxPos`：遍历到 `i` 时，**目前为止**能到达的最远位置，随时更新 `maxPos = max(maxPos, i + nums[i])`。
- `end`：**当前这一层**的右边界。当 `i` 走到 `end`，说明这一层走完了，必须再跳一步进入下一层：`ans++`，并把下一层的边界设为 `maxPos`。

> [!info] 关键认知：什么是「层」
> `end` = **所需步数相同**的一组元素的右边界。`maxPos` 与 `end` 的区别，正是本题和「跳跃游戏 I」的分水岭：
> - **55（能否到达）**：只关心一个 `maxPos`，看它能否覆盖终点。
> - **45（最少几步）**：还要用 `end` 标记每一跳的边界，**只在 `i` 碰到 `end` 时** `ans++`。

## 关键卡点
> [!warning] 我当时卡在这
> - 一开始没分清 `maxPos`（随时更新的最远可达）和 `end`（当前这一跳的边界）的含义，把两者搞混。
> - 没建立「层」的概念，导致看不出 `ans` 该在哪里 +1。抓住「**层 = 所需步数相同的一段，end = 层右边界**」就通了。

## 代码
```cpp
class Solution {
public:
    int jump(vector<int>& nums) {
        int maxPos = 0, end = 0, ans = 0;
        for (int i = 0; i < nums.size() - 1; i++) {
            maxPos = max(maxPos, i + nums[i]);
            if (i == end) {        // 走到当前层的最后一个元素，必须再跳一步
                end = maxPos;       // 进入下一层，更新边界
                ans++;
            }
        }
        return ans;
    }
};
```

## 复杂度
- 时间：O(n)，每个元素只扫一遍。
- 空间：O(1)，三个变量。

## 一句话记忆点
> [!tip] 下次看到类似题
> **求最少跳跃次数 = BFS 求层数**：`maxPos` 记最远可达，`end` 记当前层右边界，`i` 一碰到 `end` 就 `ans++`。循环只到 `n-1`（站在终点上不必再跳）。
