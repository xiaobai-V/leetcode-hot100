# 41. 缺失的第一个正数

> [!abstract] 一句话本质
> **把数组本身当哈希表用**，把每个数放到它"该在的位置"（nums[i] 放到 index nums[i]-1），然后遍历找第一个位置不对的。

> [!quote] 链接
> - https://leetcode.cn/problems/first-missing-positive/

## 题目
给定未排序整数数组，找出没有出现的最小正整数。要求 O(n) 时间 O(1) 空间。

## 思路（从暴力到最优）
1. **哈希表**：遍历存入 set，从 1 开始逐个检查是否存在，O(n) 时间 O(n) 空间。
2. **原地哈希 O(1) 空间**：
   - 关键洞察：答案一定在 `[1, n+1]` 范围内（n 个数最多填充 1~n）。
   - 第一遍：遍历数组，把每个在 `[1, n]` 范围内的数放到正确位置（nums[i] 放到 index nums[i]-1）。
   - 第二遍：找第一个 `nums[i] != i+1` 的位置，返回 `i+1`。都对就返回 `n+1`。

## 关键卡点
> [!warning] 我当时卡在这
> - 看完答案才做出来，原地哈希思路不直观
> - while 循环条件：`i != nums[i] - 1`（当前值不在正确位置才交换）
> - **重复元素死循环**：`[1, 1]` 会无限交换。正确条件应该是 `nums[i] != nums[nums[i] - 1]`（目标位置的值不等于当前值才交换）
> - 第二遍判断：找 `nums[i] != i+1`，不是找 `nums[i] > n`

## 代码
```cpp
class Solution {
public:
    int firstMissingPositive(vector<int>& nums) {
        int n = nums.size();
        for (int i = 0; i < n; i++) {
            // 注意条件：目标位置的值不等于当前值，避免重复元素死循环
            while (nums[i] > 0 && nums[i] <= n && nums[i] != nums[nums[i] - 1]) {
                swap(nums[nums[i] - 1], nums[i]);
            }
        }
        for (int i = 0; i < n; i++) {
            if (nums[i] != i + 1) return i + 1;
        }
        return n + 1;
    }
};
```

## 复杂度
- 时间：O(n)，每个元素最多被交换一次
- 空间：O(1)，原地操作
