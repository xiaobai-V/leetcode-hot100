# 34. 在排序数组中查找元素的第一个和最后一个位置

> [!abstract] 一句话本质
> **两次红蓝边界法**，一次找左边界（第一个 >= target），一次找右边界（最后一个 <= target），用指针是否交错判断存在性。

> [!quote] 链接
> - https://leetcode.cn/problems/find-first-and-last-position-of-element-in-sorted-array/

## 题目
给定排序数组 nums 和目标值 target，找到 target 的起始和结束位置。不存在返回 [-1, -1]。

## 思路

### 暴力
遍历数组找第一个和最后一个 target，O(n)。

### 红蓝边界法（两次二分）
**找开始位置（第一个 >= target）：**
- 蓝色区：`< target`
- 红色区：`>= target`
- 返回 `right`（第一个红色）

**找结束位置（最后一个 <= target）：**
- 蓝色区：`<= target`
- 红色区：`> target`
- 返回 `left`（最后一个蓝色）

**判断存在性：**
- target 存在：`startIdx <= endIdx`
- target 不存在：两个指针交错，`startIdx > endIdx`

### 为什么这样定义红蓝？
- 开始位置要找"第一个 >= target"，所以 `< target` 是蓝色，`>= target` 是红色
- 结束位置要找"最后一个 <= target"，所以 `<= target` 是蓝色，`> target` 是红色
- 两轮的分界线恰好是 target 的边界

## 关键卡点
> [!warning] 我当时卡在这
> - 结束位置为什么用 `<=` 而不是 `<`？因为要找的是"最后一个等于 target 的位置"，`<=` 把 target 本身归入蓝色区，`left` 就停在最后一个 target 上
> - 判断存在性为什么是 `>=` 不是 `>`？因为 target 存在时 startIdx 可以等于 endIdx（只有一个 target）

## 代码
```cpp
class Solution {
public:
    vector<int> searchRange(vector<int>& nums, int target) {
        int n = nums.size();

        // 开始位置：第一个 >= target
        int left = -1, right = n;
        while (left + 1 != right) {
            int mid = (left + right) >> 1;
            if (nums[mid] < target) {
                left = mid;
            } else {
                right = mid;
            }
        }
        int startIdx = right;

        // 结束位置：最后一个 <= target
        left = -1, right = n;
        while (left + 1 != right) {
            int mid = (left + right) >> 1;
            if (nums[mid] <= target) {
                left = mid;
            } else {
                right = mid;
            }
        }
        int endIdx = left;

        // 判断存在性：指针交错说明不存在
        if (endIdx >= startIdx) {
            return {startIdx, endIdx};
        }
        return {-1, -1};
    }
};
```

## 复杂度
- 时间：O(log n)，两次二分
- 空间：O(1)

> [!note] 面试追问点
> - 为什么用两次二分而不是一次？一次二分只能找到一个边界，要找两个边界必须两次
> - 空数组会崩吗？不会，哨兵位 `left=-1, right=n` 保证了边界安全

## 一句话记忆点
> [!tip] 下次看到类似题
> 找范围 → 两次红蓝边界法：第一次 `< target` / `>= target` 找左边界，第二次 `<= target` / `> target` 找右边界，指针交错 = 不存在。
