# 104. 二叉树的最大深度

> [!abstract] 一句话本质
> 树的最大深度 = `1 + max(左子树深度, 右子树深度)`。递归分治一行搞定；BFS 层序遍历数层数也行。

> [!quote] 链接
> - https://leetcode.cn/problems/maximum-depth-of-binary-tree/

## 题目
给定二叉树根节点 `root`，返回其最大深度（从根到最远叶子的节点数）。

## 思路

**方法一：递归分治（一行）**
- 空节点深度 0；非空节点深度 = 1 + max(左深度, 右深度)
- 本质是后序遍历（先算左右子树，再算自己）

**方法二：BFS 层序遍历**
- 每处理完一层 depth++，层数即深度
- 关键技巧：`int sz = q.size(); for(i=0; i<sz; i++)` 先数当前层节点数，弹完一层再 depth++
  - 为什么不能直接 `while(!q.empty())`：遍历当前层时会把下一层节点加入队列，`q.empty()` 判断会混入下一层，计数错乱

## 复杂度计算（通用方法，贯穿树专题）

| | 时间 | 空间 | 为什么 |
|---|---|---|---|
| BFS | O(n) | O(w)，w = 最大层宽 | 队列最多存一整层节点 |
| DFS/递归 | O(n) | O(h)，h = 树高 | 递归栈深度 = 树高 |

- BFS 空间最坏：完全二叉树最后一层 w ≈ n/2 → O(n)
- DFS 空间最坏：链状树 h = n → O(n)；平衡树 h = log n → O(log n)

> [!tip] 口诀
> **BFS 空间看宽度（队列），DFS 空间看深度（栈）**。

## 关键卡点
> [!warning] 我当时卡在这
> - 复杂度空间计算不熟：BFS 空间看**最大层宽**，DFS 空间看**树高**，两者不同
> - BFS 的 `sz` 技巧：遍历当前层时下一层节点会混入队列，必须先 `sz=q.size()` 再循环弹 sz 个

## 代码

**递归分治：**
```cpp
class Solution {
public:
    int maxDepth(TreeNode* root) {
        if (!root) return 0;
        return max(maxDepth(root->left), maxDepth(root->right)) + 1;
    }
};
```

**BFS 层序遍历：**
```cpp
class Solution {
public:
    int maxDepth(TreeNode* root) {
        if (!root) return 0;
        queue<TreeNode*> q;
        q.push(root);
        int depth = 0;
        while (!q.empty()) {
            int sz = q.size();          // 当前层节点数
            for (int i = 0; i < sz; i++) {
                TreeNode* node = q.front(); q.pop();
                if (node->left)  q.push(node->left);
                if (node->right) q.push(node->right);
            }
            depth++;                    // 当前层处理完，深度+1
        }
        return depth;
    }
};
```
