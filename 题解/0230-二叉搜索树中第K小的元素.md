# 230. 二叉搜索树中第 K 小的元素

> [!abstract] 一句话本质
> **BST 中序遍历严格递增**，第 K 小就是遍历到的第 K 个节点。

> [!quote] 链接
> - https://leetcode.cn/problems/kth-smallest-element-in-a-bst/

## 题目

给定 BST 根节点和整数 k，返回树中第 k 小的元素（1-indexed）。

## 思路（从暴力到最优）

### 直接思路：中序遍历取第 K 个

BST 的核心性质：**中序遍历结果严格递增**。所以第 K 小的元素就是中序遍历访问的第 K 个节点。

用迭代式中序遍历（栈模拟），维护计数器 `cnt`，每弹出一个节点 `cnt++`，当 `cnt == k` 时直接返回。

### 进阶思路（如果频繁增删查）

在每个节点维护 `leftSize`（左子树节点数），这样查询第 K 小可以在 O(log n) 内完成。但本题只需单次查询，O(n) 遍历足够。

## 关键卡点

> [!warning] 理解要点
> - BST 中序遍历严格递增，这是这道题的核心性质
> - 迭代写法比递归更直观：能主动控制流程，提前 return 更清晰

> [!warning] 易错边界
> - k 从 1 开始，不是 0
> - 题目保证 k 有效，但代码最后 return 0 是防御性写法

## 代码

```cpp
class Solution {
public:
    int kthSmallest(TreeNode* root, int k) {
        int cnt = 0;
        stack<TreeNode*> stk;
        TreeNode* cur = root;
        while (cur != nullptr || !stk.empty()) {
            while (cur != nullptr) {
                stk.push(cur);
                cur = cur->left;
            }
            cur = stk.top();
            stk.pop();
            cnt++;
            if (cnt == k) return cur->val;
            cur = cur->right;
        }
        return 0;
    }
};
```

## 复杂度

- 时间：O(n)，最坏遍历所有节点；k 小时可提前终止
- 空间：O(h)，栈深度等于树高

## 一句话记忆点

> [!tip] 下次看到类似题
> **BST 第 K 小 → 中序遍历数到第 K 个就停**。BST 的中序遍历是有序的，这是高频考点。
