# 347. 前 K 个高频元素

> [!abstract] 一句话本质
> **TopK 的变体**：先用哈希表统计频次，再套 [[0215-数组中的第K个最大元素]] 的小顶堆模板——堆里比的是"频次"而不是"数值本身"，所以要写**自定义比较器**。

> [!quote] 链接
> - https://leetcode.cn/problems/top-k-frequent-elements/

## 题目
返回数组中出现频率前 K 高的元素。

## 思路（三步）

1. **统计频次**：`unordered_map<int,int>` 记录每个数出现次数。O(n)
2. **小顶堆维护前 K 高频**：堆元素是 `pair<int,int>`（数字, 频次），大小限制 k。
   - 堆没满 → push；
   - 堆满了 → 当前元素频次 > 堆顶频次 → pop 堆顶、push 当前。
3. **输出**：把堆里 k 个元素弹出到数组。

> [!info] 自定义比较器：为什么 `>` 是小顶堆
> priority_queue 的比较器 `cmp(a,b)` 返回 true ⟺ **a 优先级低于 b**（b 先出堆）。
> 写 `a.second > b.second` ⟺ 频次高的 a 优先级低、沉底 ⟺ 堆顶是频次最低的 ⟺ 小顶堆。
>
> 🔑 记忆钩子（和内置比较器对应）：
> - `a < b` → 等价 `less` → **大顶堆**
> - `a > b` → 等价 `greater` → **小顶堆**

## 关键卡点
> [!warning] 我当时卡在这
> - **第一次写自定义比较器，方向靠猜**：`a.second > b.second` 为什么是小顶堆？记住钩子"`>`等价 greater→小顶堆"，别靠试。
> - **比较器参数要用 `const&`**：`pair` 拷贝有开销，写成 `const pair<int,int>& a` 避免拷贝。
> - **lambda 别漏 `=`**：`auto cmp = [](...){...};`（曾踩过 `auto cmp[]` 编译不过的坑）。

## 代码
```cpp
class Solution {
public:
    vector<int> topKFrequent(vector<int>& nums, int k) {
        // 1. 统计频次
        unordered_map<int, int> cnt;
        for (int x : nums) cnt[x]++;

        // 2. 小顶堆：按频次比较，大小限制 k
        auto cmp = [](const pair<int, int>& a, const pair<int, int>& b) {
            return a.second > b.second;   // > → 小顶堆
        };
        priority_queue<pair<int, int>, vector<pair<int, int>>, decltype(cmp)> pq(cmp);

        for (const auto& p : cnt) {
            if ((int)pq.size() < k) {
                pq.push(p);
            } else if (p.second > pq.top().second) {
                pq.pop();
                pq.push(p);
            }
        }

        // 3. 堆里 k 个元素转到数组
        vector<int> res;
        while (!pq.empty()) {
            res.push_back(pq.top().first);
            pq.pop();
        }
        return res;
    }
};
```

## 复杂度
- 时间：O(n + m log k)。n 个元素统计频次 O(n)；m 种不同值入堆维护 O(m log k)；输出 O(k log k)。m ≤ n。
- 空间：O(m + k)。哈希表 O(m)，堆 O(k)。
