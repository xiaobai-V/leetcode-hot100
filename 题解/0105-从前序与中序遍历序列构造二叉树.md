# 105. 从前序与中序遍历序列构造二叉树

> [!abstract] 一句话本质
> **前序找根，中序分左右**，递归构造子树。

> [!quote] 链接
> - https://leetcode.cn/problems/construct-binary-tree-from-preorder-and-inorder-traversal/

## 题目

给定前序遍历和中序遍历数组，构造二叉树。假设没有重复元素。

## 思路（从暴力到最优）

### 核心性质

- **前序遍历**：`[根, 左子树, 右子树]`——第一个元素是根
- **中序遍历**：`[左子树, 根, 右子树]`——根节点把数组分成左右两部分

### 算法步骤

1. 前序遍历第一个元素 `preorder[pre_start]` 是根节点
2. 在中序遍历中找到根节点位置 `root_idx`，用哈希表 O(1) 查找
3. 左子树长度 = `root_idx - in_start`
4. 递归构造：
   - 左子树：前序 `[pre_start+1, pre_start+left_len]`，中序 `[in_start, root_idx-1]`
   - 右子树：前序 `[pre_start+left_len+1, pre_end]`，中序 `[root_idx+1, in_end]`

### 参数简化

只需要 4 个参数：`pre_start`, `pre_end`, `in_start`。`in_end` 可以推算：
```
in_end = in_start + (pre_end - pre_start)
```
因为左右子树在前序和中序中的长度相同。

## 关键卡点

> [!warning] 我当时卡在这
> - **混淆两个数组的索引**：`root_idx` 是中序遍历的位置，不能当前序遍历的索引用
> - **左子树长度计算**：`root_idx - in_start`，不是 `root_idx - pre_start`

> [!warning] 易错边界
- 空数组返回 `nullptr`
- 单节点直接返回
- 哈希表用值作为 key（`umap[value] = index`），不是前序索引

## 代码

```cpp
class Solution {
private:
    unordered_map<int, int> umap;
    TreeNode* build(vector<int>& preorder, int pre_start, int pre_end, int in_start) {
        if (pre_start > pre_end) return nullptr;

        TreeNode* root = new TreeNode(preorder[pre_start]);
        int root_idx = umap[preorder[pre_start]];
        int left_len = root_idx - in_start;

        root->left = build(preorder, pre_start + 1, pre_start + left_len, in_start);
        root->right = build(preorder, pre_start + left_len + 1, pre_end, root_idx + 1);
        return root;
    }

public:
    TreeNode* buildTree(vector<int>& preorder, vector<int>& inorder) {
        int n = preorder.size();
        for (int i = 0; i < n; i++) umap[inorder[i]] = i;
        return build(preorder, 0, n - 1, 0);
    }
};
```

## 复杂度

- 时间：O(n)，每个节点恰好访问一次，哈希表 O(1) 查找
- 空间：O(n)，哈希表存储 + 递归栈 O(h)
