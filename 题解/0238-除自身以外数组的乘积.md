# 238. 除自身以外数组的乘积

> [!abstract] 一句话本质
> **每个位置的答案 = 左边所有数的乘积 × 右边所有数的乘积**，不能用除法，就用前后缀分解。

> [!quote] 链接
> - https://leetcode.cn/problems/product-of-array-except-self/

## 题目
给定数组 nums，返回数组 answer，其中 answer[i] 等于 nums 中除 nums[i] 之外其余各数的乘积。不能用除法，O(n) 时间。

## 思路（从暴力到最优）
1. **暴力**：对每个 i，遍历所有 j ≠ i 相乘，O(n²)。
2. **前后缀数组**：
   - `left[i]` = nums[0] × nums[1] × ... × nums[i-1]（i 左边所有数的乘积）
   - `right[i]` = nums[i+1] × ... × nums[n-1]（i 右边所有数的乘积）
   - `answer[i]` = left[i] × right[i]
   - 初始化 left[0] = 1，right[n-1] = 1（边界：一边没数，乘积为 1）
3. **空间优化**：用 answer 数组本身先存左边乘积，再从右往左乘上右边乘积。乘法满足交换律和结合律，两遍扫描互不干扰。

## 关键卡点
> [!warning] 我当时卡在这
> - 为什么不能用除法：题目明确禁止，且数组可能含 0
> - left[0] = 1 的含义：第一个元素左边没有数，乘积单位元为 1
> - 优化版安全：先存左边再乘右边，乘法独立可交换，不会互相覆盖

## 代码
```cpp
// 前后缀数组版 O(n) 空间
class Solution {
public:
    vector<int> productExceptSelf(vector<int>& nums) {
        int n = nums.size();
        vector<int> ans(n), left(n), right(n);
        left[0] = 1;
        right[n - 1] = 1;
        for (int i = 1; i < n; i++)
            left[i] = left[i - 1] * nums[i - 1];
        for (int i = n - 2; i >= 0; i--)
            right[i] = right[i + 1] * nums[i + 1];
        for (int i = 0; i < n; i++)
            ans[i] = left[i] * right[i];
        return ans;
    }
};

// 空间优化版 O(1) 空间（不含输出）
class Solution {
public:
    vector<int> productExceptSelf(vector<int>& nums) {
        int n = nums.size();
        vector<int> ans(n, 1);
        int left = 1, right = 1;
        for (int i = 1; i < n; i++) {
            left *= nums[i - 1];
            ans[i] *= left;
        }
        for (int i = n - 2; i >= 0; i--) {
            right *= nums[i + 1];
            ans[i] *= right;
        }
        return ans;
    }
};
```

## 复杂度
- 时间：O(n)，两遍扫描
- 空间：O(1)（优化版，不含输出数组）
