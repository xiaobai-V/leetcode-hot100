# 739. 每日温度

> [!abstract] 一句话本质
> 每个位置求「右边第一个更大值」，是 **Next Greater Element** 模式 → **单调栈**。

> [!quote] 链接
> - https://leetcode.cn/problems/daily-temperatures/

## 题目
给定每日温度数组，对每一天求：多少天后才出现更暖的一天；等不到则填 0。

## 思路（从暴力到最优）

**暴力 O(n²)**：对每个 `i` 向右扫描找第一个 `> T[i]` 的位置。会超时。

**单调栈 O(n)**：栈里维护「还没找到暖天的下标」，从栈底到栈顶**温度递减**。

为什么这个结构天然合适（两步闭环）：
1. **单调是必然的**：栈里 `a`（早/下）、`b`（晚/上），若 `T[a] < T[b]`，则 `b` 入栈那天就该把 `a` 弹掉给答案，`a` 不可能还在栈里。所以「还在栈里」自动 ⇒ 从底到顶递减。
2. **栈 = LIFO**：新来的 `i` 要兑现「比它冷的」待办，栈顶是最冷的，从栈顶一路弹到不比它冷为止；若连栈顶都暖不过，自己入栈等着。

遍历结束栈里剩的下标，res 默认 0，正是「等不到」的答案，不用再处理。

## 关键卡点
> [!warning] 我当时卡在这
> - 一开始想用**二分**找右边更大——但数组**无序，二分不适用**。
> - 栈里**存下标不存值**：答案是下标之差 `i - prev`，存值就算不出天数。
> - `for` 套 `while` 看似 O(n²)，其实每个元素最多入栈、出栈各一次，**均摊 O(n)**。
> - 弹栈必须用 `while` 不能 `if`：一个高温可能连续兑现多个下降的栈顶。

## 代码
```cpp
class Solution {
public:
    vector<int> dailyTemperatures(vector<int>& temperatures) {
        int n = temperatures.size();
        vector<int> res(n, 0);        // 默认 0：等不到的不用再处理
        stack<int> stk;               // 存下标，温度从栈底到栈顶递减
        for (int i = 0; i < n; i++) {
            // 今天比栈顶那天暖 → 栈顶「解脱」，一直弹到不比栈顶暖
            while (!stk.empty() &&
                   temperatures[i] > temperatures[stk.top()]) {
                int prev = stk.top(); stk.pop();
                res[prev] = i - prev;
            }
            stk.push(i);              // 今天入栈，等以后更暖的一天
        }
        return res;
    }
};
```

## 复杂度
- 时间：O(n)，每个下标最多入栈、出栈各一次。
- 空间：O(n)，栈最坏存全部下标。

## 一句话记忆点
> [!tip] 下次看到类似题
> **「求右边第一个更大/更小」→ 单调栈**。栈存下标；递减栈找「更大」，递增栈找「更小」；新元素把能弹的栈顶全弹掉。
