# 236. 二叉树的最近公共祖先

> [!abstract] 一句话本质
> **后序遍历收集左右子树的搜索结果，根据两侧是否都找到了目标节点来决定谁是祖先**，不是"找路径再比较"，而是"递归返回谁被找到了"。

> [!quote] 链接
> - https://leetcode.cn/problems/lowest-common-ancestor-of-a-binary-tree/

## 题目
给定一棵二叉树和两个节点 p、q，找到它们的最近公共祖先（一个节点可以是自己的祖先）。

## 思路（从暴力到最优）

**暴力**：分别找 root→p 和 root→q 的路径，比较最后一个公共节点。时间 O(n)，空间 O(n)，需要存路径。

**最优**：后序遍历，递归函数返回"我这棵子树里找到了谁"：
- `root == p || root == q`：找到了，返回 root
- 左右子树都找到了（`left && right`）：p、q 分居两侧，root 就是分岔口，返回 root
- 只有一边找到了：返回那一边的结果（祖先在那边）
- 两边都没找到：返回 nullptr

关键：后序遍历是必须的——你要先知道左右子树的结果，才能决定当前节点该返回什么。

## 关键卡点

> [!warning] 我当时卡在这
> - 递归返回值的含义搞混了：不是直接返回"公共祖先"，而是返回"我这棵子树里找到了谁"
> - `if (left && right)` 是两侧都找到了（p、q 分居），不是两侧都没找到

## 代码

```cpp
class Solution {
public:
    TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
        if (root == nullptr || root == p || root == q) {
            return root;
        }

        TreeNode* left = lowestCommonAncestor(root->left, p, q);
        TreeNode* right = lowestCommonAncestor(root->right, p, q);

        if (left && right) {
            return root;
        } else if (left) {
            return left;
        } else if (right) {
            return right;
        }
        return nullptr;
    }
};
```

## 复杂度
- 时间：O(n)，每个节点最多访问一次
- 空间：O(h)，递归栈深度等于树高
