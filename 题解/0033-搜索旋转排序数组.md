# 33. 搜索旋转排序数组

> [!abstract] 一句话本质
> **旋转后仍然是两段有序数组**，先判断 mid 在哪段，再判断 target 在哪段，O(log n) 搜索。

> [!quote] 链接
> - https://leetcode.cn/problems/search-in-rotated-sorted-array/

## 题目
给定旋转后的排序数组 nums（无重复）和目标值 target，找到 target 的索引。不存在返回 -1。

## 思路

### 暴力
遍历数组，O(n)。

### 二分法（一次遍历）
旋转后数组分成两段有序部分，每次二分时：

**Step 1: 判断 mid 在哪段**
```cpp
if (nums[left] <= nums[mid])  // mid 在左半段（左半段有序）
else                          // mid 在右半段（右半段有序）
```

**Step 2: 判断 target 是否在有序段里**
- 左半段有序 `[left, mid)`：`nums[left] <= target && target < nums[mid]`
- 右半段有序 `(mid, right]`：`nums[mid] < target && target <= nums[right]`

**Step 3: 移动指针**
- target 在有序段 → 在那段里继续找
- target 不在有序段 → 去另一边找

### 为什么 `<=` 而不是 `<`？
当 `left == mid` 时，左半段只有一个元素，也是有序的。如果用 `<`，会错误地认为右半段有序。

### 为什么右边用 `<` 不是 `<=`？
因为已经判断过 `nums[mid] != target`，所以 target 不可能等于 `nums[mid]`。

## 关键卡点
> [!warning] 我当时卡在这
> - 情况太多，写不下去 → 其实只有 2 种情况（mid 在左/右），不是 4 种
> - `nums[left] <= nums[mid]` 的 `<=` 漏掉 → `[3,1]` 样例挂
> - `left + (right - left) >> 1` 优先级 bug → `>>` 优先级低于 `+`

## 代码

### 解法一：调用辅助函数
```cpp
class Solution {
    int binarySearch(vector<int>& nums, int target, int start, int end) {
        if (start < 0 || end >= nums.size() || start > end) return -1;
        int left = start, right = end;
        while (left <= right) {
            int mid = (left + right) >> 1;
            if (nums[mid] == target) return mid;
            else if (nums[mid] < target) left = mid + 1;
            else right = mid - 1;
        }
        return -1;
    }
public:
    int search(vector<int>& nums, int target) {
        int n = nums.size();
        int left = 0, right = n - 1;
        while (left <= right) {
            int mid = (left + right) >> 1;
            if (nums[mid] == target) return mid;
            if (nums[left] <= nums[mid]) {
                int leftRet = binarySearch(nums, target, left, mid);
                if (leftRet != -1) return leftRet;
                left = mid + 1;
            } else {
                int rightRet = binarySearch(nums, target, mid, right);
                if (rightRet != -1) return rightRet;
                right = mid - 1;
            }
        }
        return -1;
    }
};
```

### 解法二：直接判断（推荐）
```cpp
class Solution {
public:
    int search(vector<int>& nums, int target) {
        int n = nums.size();
        int left = 0, right = n - 1;
        while (left <= right) {
            int mid = (left + right) >> 1;
            if (nums[mid] == target) return mid;
            if (nums[left] <= nums[mid]) {
                // 左半段有序 [left, mid)
                if (nums[left] <= target && target < nums[mid]) {
                    right = mid - 1;
                } else {
                    left = mid + 1;
                }
            } else {
                // 右半段有序 (mid, right]
                if (nums[mid] < target && target <= nums[right]) {
                    left = mid + 1;
                } else {
                    right = mid - 1;
                }
            }
        }
        return -1;
    }
};
```

## 复杂度
- 时间：O(log n)
- 空间：O(1)

> - 为什么右边用 `<`？已经排除 `nums[mid] == target`
> - 有重复元素怎么办？（81题）最坏 O(n)
