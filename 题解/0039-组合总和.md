# 39. 组合总和

> [!abstract] 一句话本质
> **可重复选的组合枚举**，通过传 `start = i`（而非 `i+1`）允许重复选同一元素，用排序 + break 剪枝。

> [!quote] 链接
> - https://leetcode.cn/problems/combination-sum/

## 题目

给定候选数组 `candidates`（无重复）和目标值 `target`，找出所有和为 target 的组合。同一个数字可以无限次重复选取。

## 思路（从暴力到最优）

**暴力**：枚举所有组合，检查和是否为 target。问题：有重复组合（[2,3] 和 [3,2] 算两个）。

**优化 1：排序 + start 参数**
- 排序后，每次递归从 `start` 开始选，保证组合是"递增"的
- `start = i`（不是 `i+1`）→ 允许重复选同一个元素
- 这样 [2,3,5] 只会生成 [2,3,3]，不会生成 [3,2,3]

**优化 2：剪枝**
- 排序后，`candidates[i] > target` 时直接 `break`，后面更大，不可能

**和子集/全排列的区别**：
- 子集/全排列：每个元素只能用一次 → 递归传 `i+1`
- 组合总和：元素可重复用 → 递归传 `i`

## 关键卡点

> [!warning] 我当时卡在这
> - `start` 参数：不加会导致 [2,3] 和 [3,2] 重复入结果
> - 剪枝：排序后用 `break` 而非 `continue`，因为后续元素更大，不可能满足条件

## 代码

```cpp
class Solution {
    vector<vector<int>> res;
    vector<int> path;
    void backtrack(vector<int>& candidates, int target, int start) {
        if (target <= 0) {
            if (target == 0)
                res.push_back(path);
            return;
        }
        for (int i = start; i < candidates.size(); i++) {
            if (candidates[i] > target)
                break;  // 排序后，后续更大，直接剪枝
            path.push_back(candidates[i]);
            backtrack(candidates, target - candidates[i], i);  // 传 i 允许重复选
            path.pop_back();
        }
    }
public:
    vector<vector<int>> combinationSum(vector<int>& candidates, int target) {
        sort(candidates.begin(), candidates.end());
        backtrack(candidates, target, 0);
        return res;
    }
};
```

## 复杂度

- 时间：O(n^(T/M))，n = 数组长度，T = target，M = 最小元素
- 空间：O(T/M)，递归深度

## 一句话记忆点

> [!tip] 下次看到类似题
> **可重复选 → 传 `i`；不可重复选 → 传 `i+1`**。排序 + break 剪枝是标配。
