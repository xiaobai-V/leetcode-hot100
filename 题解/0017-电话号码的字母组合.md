# 17. 电话号码的字母组合

> [!abstract] 一句话本质
> **穷举所有可能的字母组合**，不是暴力嵌套循环，而是用回溯递归处理不定层数的穷举。

> [!quote] 链接
> - https://leetcode.cn/problems/letter-combinations-of-a-phone-number/

## 题目
给定一个数字字符串 digits，返回它能表示的所有字母组合（手机九宫格键盘映射）。

## 思路（从暴力到最优）
**暴力想法**：N 层 for 循环嵌套。但 digits 长度不定，写死层数不现实。

**回溯思路**：
- 每个数字对应一组字母，我们需要从每组中选一个字母，拼成一个组合
- 用递归处理"不定层数"的问题：每次处理一个数字，选一个字母，递归处理下一个数字
- 关键是**选择 → 递归 → 撤销**的三步走：选了 letter 后递归，递归回来后 pop_back() 撤销选择，这样下一个循环才能选不同的 letter

**为什么不用循环嵌套**：回溯是通用模板，适用于组合、排列、子集等问题，而循环嵌套只适合层数固定的情况。

## 关键卡点
> [!warning] 我当时卡在这
> - 回溯专题下没考虑过循环嵌套，直接按模板写的
> - `pop_back()` 的作用是撤销选择、恢复现场，不是简单的"删掉当前 letter"
> - `start` 参数控制当前处理到第几个数字，确保不回头选前面的，同时 `start == digits.size()` 作为终止条件

## 代码
```cpp
class Solution {
public:
    unordered_map<char, string> umap = {
        {'2', "abc"}, {'3', "def"},  {'4', "ghi"}, {'5', "jkl"},
        {'6', "mno"}, {'7', "pqrs"}, {'8', "tuv"}, {'9', "wxyz"}};
    vector<string> combinations;
    string path;
    void backtrack(string digits, int start) {
        if (start == digits.size()) {
            combinations.push_back(path);
            return;
        }
        const string& letters = umap[digits[start]];
        for (char letter : letters) {
            path.push_back(letter);
            backtrack(digits, start + 1);
            path.pop_back();
        }
    }
    vector<string> letterCombinations(string digits) {
        backtrack(digits, 0);
        return combinations;
    }
};
```

## 复杂度
- 时间：O((n+m) × 3^n × 4^m)，n = 对应 3 个字母的数字个数，m = 对应 4 个字母的数字个数
- 空间：O(n+m)，递归栈深度

> [!tip] 下次看到类似题
> 穷举所有组合 → 回溯三步走：选 → 递归 → 撤销。不确定层数就用递归，别写死循环。
