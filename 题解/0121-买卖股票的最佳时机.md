# 121. 买卖股票的最佳时机

> [!abstract] 一句话本质
> **固定卖出日，最佳买入就是历史最小值**。遍历每个卖出日，用维护的 minVal 算"当天最大利润"，取 max。一次扫描 O(n)。

> [!quote] 链接
> - https://leetcode.cn/problems/best-time-to-buy-and-sell-stock/

## 题目
给定每天股价 prices，只能买卖一次（买入在前、卖出在后），求最大利润。不交易则利润为 0。

## 思路（从暴力到最优）
1. **暴力** O(n²)：枚举所有 (买入 i, 卖出 j)，i<j，取 `max(prices[j]-prices[i])`。
2. **贪心** O(n)：固定卖出日 j，最佳买入就是 `[0..j-1]` 的最小值 minVal。一遍扫描维护 minVal，每天算 `prices[j]-minVal` 取 max。
3. **差分法**（迁移 53 题）：`prices[j]-prices[i] = sum(diff[i+1..j])`，所以最大利润 = 差分数组 diff 的最大连续子数组和，套 Kadane。

### 贪心正确性证明
最优解一定是某个 (i,j)，i<j。固定卖出日 j 时利润 = `prices[j]-prices[i]`，要让利润最大，`prices[i]` 越小越好，所以取 `i∈[0,j-1]` 的最小值 minVal。遍历所有卖出日 j 取 max，就穷尽了所有买卖对 → 一定取到全局最优。

## 关键卡点
> [!warning] 我当时卡在这 / 易错
> - **minVal 更新顺序**：必须先 `temp = prices[i] - minVal`（用旧值算利润），再 `minVal = min(minVal, prices[i])`。反过来结果也对（因为 `res=max` 把负数/0 都挡了），但语义上 temp 应反映"当天相对历史最小的真实利润"——今天创新低时，正确顺序 temp 是负数、反过来变 0。写对顺序避免在变体题出错。
> - **边界**：prices 为空时 `minVal = prices[0]` 越界，工程上应开头特判（题目保证 ≥1 元素）。
> - 单元素：返回 0（不能交易），正确。

## 代码（贪心，最优）
```cpp
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int res = 0;
        int minVal = prices[0];   // 历史最小买入价
        for (int i = 0; i < prices.size(); i++) {
            int temp = prices[i] - minVal;       // 先用旧 minVal 算当天最大利润
            minVal = min(minVal, prices[i]);     // 再更新（顺序不能反）
            res = max(res, temp);
        }
        return res;
    }
};
```

## 复杂度
- 时间：O(n)，一次扫描
- 空间：O(1)
