# 139. 单词拆分

> [!abstract] 一句话本质
> **判断前缀能否拆分**，不是盯着当前字符，而是枚举哪个词可以作为当前前缀的最后一段。

> [!quote] 链接
> - https://leetcode.cn/problems/word-break/

## 题目

给定字符串 `s` 和词典 `wordDict`，判断 `s` 能否由词典中的若干单词拼接而成。词典里的单词可以重复使用。

## 思路（从暴力到最优）

最直接的想法是不断尝试切分字符串：每次选一个词作为开头或结尾，再递归判断剩下的部分。但很多子串会被反复判断，所以可以用动态规划记录“某个前缀是否已经可拆”。

定义：

- `dp[i]` 表示 `s` 的前 `i` 个字符，也就是 `s[0..i-1]`，能否被词典拼出来。

初始化：

- `dp[0] = true`，空串可以被拼出来。这个边界能兼容整个前缀本身就是一个词的情况。

转移：

枚举当前位置 `i`，再枚举词典中的单词 `word`。如果 `word` 能作为 `s[0..i-1]` 的最后一段，并且前面的 `s[0..i-len-1]` 已经可拆，那么整个前 `i` 个字符也可拆。

```cpp
if (i >= len && dp[i - len] && s.substr(i - len, len) == word) {
    dp[i] = true;
}
```

答案：

- `dp[s.size()]`

## 关键卡点

> [!warning] 我当时卡在这
> - `dp[i]` 要定义成“前 `i` 个字符可不可以被表示”，而不是单独看第 `i` 个字符。
> - 转移的核心是“前半段可拆 + 最后一段正好是词典里的 `word`”，这样整个前缀就可拆。
> - `dp[0] = true` 很关键，否则像 `"leet"` 这种单个词作为前缀时，无法从空前缀转移过来。
> - `dp[i]` 已经变成 `true` 后可以 `break`，不用继续检查其他单词。

## 代码

```cpp
class Solution {
public:
    bool wordBreak(string s, vector<string>& wordDict) {
        vector<bool> dp(s.size() + 1, false);
        dp[0] = true;

        for (int i = 1; i <= s.size(); i++) {
            for (string& word : wordDict) {
                int len = word.size();
                if (i >= len && dp[i - len] && s.substr(i - len, len) == word) {
                    dp[i] = true;
                    break;
                }
            }
        }

        return dp[s.size()];
    }
};
```

## 复杂度

- 时间：`O(n * m * L)`，`n` 是 `s` 长度，`m` 是词典单词数，`L` 是平均单词长度；`substr` 和字符串比较会带来额外长度开销。
- 空间：`O(n)`。

## 一句话记忆点

> [!tip] 下次看到类似题
> 字符串能否拼出来：设 `dp[i]` 看前缀，枚举最后一个词，检查“前缀已合法 + 后缀等于 word”。
