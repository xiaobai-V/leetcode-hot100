# 226. 翻转二叉树

> [!abstract] 一句话本质
> **翻转 = 递归交换左右子树**。前序（先交换再递归）或后序（先递归再交换）都行，本质一样；中序要小心。

> [!quote] 链接
> - https://leetcode.cn/problems/invert-binary-tree/

## 题目
给定二叉树根节点 `root`，将其翻转（每个节点的左右子树互换），返回根节点。

## 思路

**递归（前序，先交换再递归）**
- 先存 `temp = root->left`（因为下一行会改 `root->left`）
- `root->left = invertTree(root->right);`
- `root->right = invertTree(temp);`

**递归（后序，先递归再交换）**
- `invertTree(root->left);`
- `invertTree(root->right);`
- `swap(root->left, root->right);`

**为什么两种顺序结果一样？**
"交换左右"和"递归翻转子树"是独立操作：先翻转再交换 = 先交换再翻转，最终结构相同。

> [!warning] temp 的必要性
> 如果不先存 `root->left`，`root->left = invertTree(root->right)` 会把原左子树覆盖掉，下一行 `invertTree(root->left)` 拿到的已经是翻转后的右子树了，结果错乱。

## 代码

```cpp
class Solution {
public:
    TreeNode* invertTree(TreeNode* root) {
        if (!root) return nullptr;
        TreeNode* temp = root->left;
        root->left = invertTree(root->right);
        root->right = invertTree(temp);
        return root;
    }
};
```

## 复杂度
- 时间：O(n)，每个节点访问一次
- 空间：O(h)，h = 树高（递归栈深度）

## 一句话记忆点
> [!tip] 下次看到类似题
> 翻转二叉树 → 递归交换左右子树，前序后序都行。记得用 `temp` 先存被覆盖的那侧。
