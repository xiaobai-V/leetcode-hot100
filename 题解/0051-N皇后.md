# 51. N 皇后

> [!abstract] 一句话本质
> **回溯逐行放置皇后**，每行放一个，用 `isValid` 检查列、45°对角线、135°对角线是否冲突。

> [!quote] 链接
> - https://leetcode.cn/problems/n-queens/

## 题目
n 皇后问题：将 n 个皇后放置在 n×n 的棋盘上，使得皇后彼此之间不能攻击（不能同行、同列、同对角线）。返回所有不同的解决方案。

## 思路（从暴力到最优）
1. **暴力想法**：枚举所有 n^n 种放置方式，检查每种是否合法。O(n^n × n²)。
2. **优化 → 回溯剪枝**：逐行放置皇后，每行只放一个，用 isValid 检查是否合法。
3. **关键**：只检查上方（列、45°、135°），因为下方还没放皇后。

## 关键卡点
> [!warning] 我当时卡在这
> - isValid 要检查三个方向：列、45°对角线、135°对角线
> - 只检查上方，因为是一行一行放的，下方还没放
> - 对角线判断：45° 是 `i--, j--`，135° 是 `i--, j++`
> - 终止条件：`row == n`（所有行都放完了）

## 代码
```cpp
class Solution {
    vector<vector<string>> res;
    vector<string> path;
    bool isValid(int row, int col, vector<string>& board) {
        // 检查列
        for (int i = 0; i < row; i++) {
            if (board[i][col] == 'Q') {
                return false;
            }
        }
        // 检查 45° 对角线（左上）
        int i = row - 1, j = col - 1;
        while (i >= 0 && j >= 0) {
            if (board[i][j] == 'Q') {
                return false;
            }
            i--;
            j--;
        }
        // 检查 135° 对角线（右上）
        i = row - 1, j = col + 1;
        while (i >= 0 && j < board.size()) {
            if (board[i][j] == 'Q') {
                return false;
            }
            i--;
            j++;
        }
        return true;
    }

    void backtrack(int n, int row, vector<string>& board) {
        if (row == n) {
            res.push_back(path);
            return;
        }
        for (int j = 0; j < n; j++) {
            if (isValid(row, j, board)) {
                board[row][j] = 'Q';
                path.push_back(board[row]);
                backtrack(n, row + 1, board);
                path.pop_back();
                board[row][j] = '.';
            }
        }
    }

public:
    vector<vector<string>> solveNQueens(int n) {
        vector<string> board(n, string(n, '.'));
        backtrack(n, 0, board);
        return res;
    }
};
```

## 复杂度
- 时间：O(n!) — 第一行 n 种选择，第二行 n-1 种...，剪枝后远小于此
- 空间：O(n²) — 棋盘 + 递归栈
