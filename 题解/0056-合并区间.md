# 56. 合并区间

> [!abstract] 一句话本质
> **按左端点排序后一次扫描**——排序保证当前区间只可能与上一个未合并区间重叠，贪心合并即可。

> [!quote] 链接
> - https://leetcode.cn/problems/merge-intervals/

## 题目
给定一组区间 `intervals`，合并所有重叠的区间，返回不重叠的结果。

## 思路（从暴力到最优）

**为什么必须排序**：不排序时，后面的区间可能与更早的已合并区间重叠，导致遗漏。例如 `[[1,3],[3,4],[0,3]]` 不排序会得到 `[[1,4],[0,3]]` 而非正确的 `[[0,4]]`。

**排序后贪心**：按左端点升序排，扫描时维护当前合并区间 `[left, right]`：
- 若 `intervals[i][0] <= right` → 重叠，更新 `right = max(right, intervals[i][1])`
- 否则 → 当前区间结束，push 进结果，开启新区间

**为什么排序后只看上一个就够**：排序后区间左端点单调递增，所以当前区间不可能与"上上一个"重叠（如果重叠，那上一个也一定重叠，已经被合并进来了）。

## 关键卡点

> [!warning] 我当时卡在这
> - **`right` 必须用 `max` 更新**：包含关系 `[[1,4],[2,3]]`，第二个完全在第一个内，直接赋值 `right=intervals[i][1]=3` 会丢掉 4。
> - **`sort` lambda 语法**：参数要用 `const vector<int>&`（**const 引用**），避免拷贝、防止误改。
> - **空输入边界**：`intervals[0]` 在空数组时越界。LC 保证非空，工程代码开头建议特判。

## 代码

```cpp
class Solution {
public:
    vector<vector<int>> merge(vector<vector<int>>& intervals) {
        if (intervals.empty()) return {};  // 工程边界
        
        vector<vector<int>> res;
        sort(intervals.begin(), intervals.end(),
             [](const vector<int>& a, const vector<int>& b) {
                 return a[0] < b[0];
             });

        int left = intervals[0][0], right = intervals[0][1];
        for (int i = 1; i < intervals.size(); i++) {
            if (intervals[i][0] <= right) {
                right = max(right, intervals[i][1]);  // 必须用 max
            } else {
                res.push_back({left, right});
                left = intervals[i][0];
                right = intervals[i][1];
            }
        }
        res.push_back({left, right});  // 最后一个别忘了
        return res;
    }
};
```

## 复杂度
- 时间：O(n log n) — 排序主导
- 空间：O(log n) — 排序的栈空间（不计结果）

## 一句话记忆点

> [!tip] 下次看到类似题
> **区间合并/调度 → 先按左端点排序，再扫描贪心**。`right` 更新必用 `max`（防包含关系丢解），最后一段别忘了 push。
