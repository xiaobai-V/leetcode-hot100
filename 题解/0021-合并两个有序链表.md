# 21. 合并两个有序链表

> [!abstract] 一句话本质
> **双指针逐个比较挂链**，不是新建链表而是复用原节点。

> [!quote] 链接
> - https://leetcode.cn/problems/merge-two-sorted-lists/

## 题目
将两个升序链表合并为一个新的升序链表。

## 思路

**方法：dummyHead + 双指针**
- dummyHead 简化头节点处理
- cur1、cur2 分别指向两条链表，比较大小，小的接到结果链表后
- 一条走完后，直接接上另一条的剩余部分
- 时间 O(m+n)，空间 O(1)

## 关键卡点
> [!warning] 易错点
> - 条件判断要用 `cur1 != nullptr && cur2 != nullptr`（先判非空再访问），不能用 `!cur1 && !cur2`（否定形式导致空指针解引用）
> - dummyHead 最后要 delete 避免内存泄漏

## 代码
```cpp
class Solution {
public:
    ListNode* mergeTwoLists(ListNode* list1, ListNode* list2) {
        ListNode* dummyHead = new ListNode(0);
        ListNode* cur1 = list1;
        ListNode* cur2 = list2;
        ListNode* cur = dummyHead;
        while (cur1 != nullptr || cur2 != nullptr) {
            if (cur1 != nullptr && cur2 != nullptr) {
                if (cur1->val < cur2->val) {
                    cur->next = cur1;
                    cur1 = cur1->next;
                } else {
                    cur->next = cur2;
                    cur2 = cur2->next;
                }
            } else if (cur1 != nullptr) {
                cur->next = cur1;
                cur1 = cur1->next;
            } else {
                cur->next = cur2;
                cur2 = cur2->next;
            }
            cur = cur->next;
        }
        ListNode* head = dummyHead->next;
        delete dummyHead;
        return head;
    }
};
```

## 复杂度
- 时间：O(m+n)
- 空间：O(1)
