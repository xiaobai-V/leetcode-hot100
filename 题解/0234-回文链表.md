# 234. 回文链表

> [!abstract] 一句话本质
> **快慢指针找中点 + 反转后半段 + 逐个比较**，不是复制新链表而是原地操作。

> [!quote] 链接
> - https://leetcode.cn/problems/palindrome-linked-list/

## 题目
给定单链表头节点 head，判断是否为回文链表。

## 思路（从暴力到最优）

**方法一：复制 + 反转 + 比较（你的第一版）**
- 复制整条链表到新链表，反转新链表，逐个比较
- 时间 O(n)，空间 O(n)——复制了整条链表

**方法二：快慢指针 + 反转后半段（最优）**
1. **找中点**：快慢指针，fast 走两步 slow 走一步，fast 到终点时 slow 在中点
2. **反转后半段**：从 slow 开始反转（复用 206 题的技巧）
3. **比较**：前半段和反转后的后半段逐个比较
- 时间 O(n)，空间 O(1)

> [!tip] 找中点的细节
> fast 从 head 出发、slow 从 head 出发：
> - 奇数个节点：fast 停在最后一个节点，slow 在正中间（需要 slow->next 开始反转后半段，跳过中间节点）
> - 偶数个节点：fast 停在 nullptr，slow 在前半段末尾的下一个（slow 就是后半段起点）

## 关键卡点
> [!warning] 我当时卡在这
> - 第一反应是复制链表，但空间 O(n) 不够优
> - 快慢指针找中点后，奇数/偶数情况的处理：关键是 mid 从哪里开始反转
> - 反转后半段后，不需要恢复链表（题目没要求）

## 代码

**最优解（快慢指针 + 反转后半段）：**
```cpp
class Solution {
    ListNode* reverseList(ListNode* head) {
        ListNode* pre = nullptr;
        ListNode* cur = head;
        while (cur != nullptr) {
            ListNode* temp = cur->next;
            cur->next = pre;
            pre = cur;
            cur = temp;
        }
        return pre;
    }
public:
    bool isPalindrome(ListNode* head) {
        // 快慢指针找中点
        ListNode* slow = head;
        ListNode* fast = head;
        while (fast != nullptr && fast->next != nullptr) {
            slow = slow->next;
            fast = fast->next->next;
        }
        // slow 现在是中点（奇数）或后半段起点（偶数）
        // 反转后半段
        ListNode* secondHalf = reverseList(slow);
        // 比较前半段和反转后的后半段
        ListNode* p1 = head;
        ListNode* p2 = secondHalf;
        while (p2 != nullptr) {
            if (p1->val != p2->val) return false;
            p1 = p1->next;
            p2 = p2->next;
        }
        return true;
    }
};
```

## 复杂度
- 方法一：时间 O(n)，空间 O(n)
- 方法二：时间 O(n)，空间 O(1)
