# 24. 两两交换链表中的节点

> [!abstract] 一句话本质
> **三指针逐对交换**，不是改值而是改指针指向。

> [!quote] 链接
> - https://leetcode.cn/problems/swap-nodes-in-pairs/

## 题目
给定单链表，两两交换相邻节点，不修改节点值，只改指针。

## 思路

**方法：dummyHead + 三指针**
- pre 指向待交换对的前一个节点，cur 指向第一个，temp 指向第二个
- 交换顺序：先用 temp->next 的值（cur->next = temp->next），再改它（temp->next = cur），最后接上 pre（pre->next = temp）
- 时间 O(n)，空间 O(1)

## 关键卡点
> [!warning] 我当时卡在这
> - 交换顺序不能乱：必须先执行 `cur->next = temp->next`（用到 temp 原始 next），再执行 `temp->next = cur`（覆盖它）
> - 奇数个节点时 `cur && cur->next` 自然退出，最后一个节点不用交换

## 代码
```cpp
class Solution {
public:
    ListNode* swapPairs(ListNode* head) {
        ListNode* dummyHead = new ListNode(0);
        dummyHead->next = head;
        ListNode* pre = dummyHead;
        ListNode* cur = head;
        while (cur && cur->next) {
            ListNode* temp = cur->next;
            pre->next = temp;
            cur->next = temp->next;
            temp->next = cur;
            pre = cur;
            cur = pre->next;
        }
        head = dummyHead->next;
        delete dummyHead;
        return head;
    }
};
```

## 复杂度
- 时间：O(n)
- 空间：O(1)
