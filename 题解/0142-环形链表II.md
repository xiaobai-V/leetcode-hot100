# 142. 环形链表 II

> [!abstract] 一句话本质
> **快慢指针找环入口**，不是判有无环而是利用数学推导定位入口。

> [!quote] 链接
> - https://leetcode.cn/problems/linked-list-cycle-ii/

## 题目
给定单链表 head，若有环返回环入口节点，否则返回 nullptr。

## 思路

**第一步：快慢指针判环（同 141）**
- slow 走 1 步，fast 走 2 步，相遇说明有环

**第二步：数学推导找入口**
- 设 head 到环入口距离 a，环入口到相遇点距离 b，环长 c
- 相遇时：slow 走了 a+b，fast 走了 a+b+nc（n 圈）
- 因为 fast 速度是 slow 两倍：2(a+b) = a+b+nc
- 化简得：**a = c-b + (n-1)c**
- 含义：从 head 走 a 步 = 从相遇点走 c-b 步（绕若干圈后），两者都到达环入口

**做法**：slow 回到 head，fast 留在相遇点，两者每次各走 1 步，相遇点即为环入口。

## 关键卡点
> [!warning] 我当时卡在这
> - 数学推导：2(a+b) = a+b+nc → a = c-b + (n-1)c，核心是 a 和 c-b 同余
> - 第二步 fast 留在相遇点不动，不要继续走两步

## 代码
```cpp
class Solution {
public:
    ListNode *detectCycle(ListNode *head) {
        ListNode* slow = head;
        ListNode* fast = head;
        // 第一步：判环
        while (fast != nullptr && fast->next != nullptr) {
            slow = slow->next;
            fast = fast->next->next;
            if (slow == fast) {
                // 第二步：找入口
                slow = head;
                while (slow != fast) {
                    slow = slow->next;
                    fast = fast->next;
                }
                return slow;
            }
        }
        return nullptr;
    }
};
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 一句话记忆点
> [!tip] 下次看到类似题
> 找环入口→快慢指针相遇后，一个回起点一个留原地，同步走 1 步再相遇就是入口。公式：a = c-b。
