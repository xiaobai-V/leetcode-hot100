# 283. 移动零

> [!abstract] 一句话本质
> **双指针覆盖写**，right 扫描非零元素往 left 位置填，最后补零。不是真的"移动"，而是"非零前移 + 尾部置零"。

> [!quote] 链接
> - https://leetcode.cn/problems/move-zeroes/

## 题目
将数组中的零移到末尾，保持非零元素相对顺序，原地操作。

## 思路（从暴力到最优）
1. **暴力**：额外数组存非零元素，再补零，O(n) 空间。
2. **双指针覆盖写**：left 指向下一个写入位置，right 扫描数组。遇到非零就写到 left 位置，left++。扫描完后，left 之后的位全填零。O(1) 空间，遍历至多两遍。
3. **swap 版本**：遇到非零直接 swap(nums[left], nums[right])，一步到位，只遍历一遍。当 left == right 时 swap 是自交换，无害但冗余。

## 关键卡点
> [!warning] 我当时卡在这
> - 无明显卡点，一次 AC

## 代码
```cpp
class Solution {
public:
    void moveZeroes(vector<int>& nums) {
        int left = 0;
        for (int right = 0; right < nums.size(); right++) {
            if (nums[right] != 0) {
                nums[left++] = nums[right];
            }
        }
        while (left < nums.size()) {
            nums[left++] = 0;
        }
    }
};
```

> [!note] swap 一遍写法
> ```cpp
> if (nums[right] != 0) swap(nums[left++], nums[right]);
> ```

## 复杂度
- 时间：O(n)
- 空间：O(1)，原地操作
