# 35. 搜索插入位置

> [!abstract] 一句话本质
> **找到第一个 >= target 的位置**，标准二分查找的入门题。

> [!quote] 链接
> - https://leetcode.cn/problems/search-insert-position/

## 题目
给定排序数组 nums 和目标值 target，找到 target 的索引，如果不存在返回它会被插入的位置。

## 思路

### 方法一：标准二分法
```cpp
int left = 0, right = n - 1;
while (left <= right) {
    int mid = left + (right - left) / 2;
    if (nums[mid] < target) {
        left = mid + 1;
    } else {
        right = mid - 1;
    }
}
return left;  // left 就是插入位置
```

### 方法二：红蓝边界法（推荐）
```cpp
// 蓝色区（< target）：left 指向最后一个蓝色
// 红色区（>= target）：right 指向第一个红色
int left = -1, right = n;
while (left + 1 != right) {
    int mid = (left + right) >> 1;
    if (nums[mid] < target) {
        left = mid;   // mid 是蓝色，收缩左边界
    } else {
        right = mid;  // mid 是红色，收缩右边界
    }
}
return right;  // right 就是第一个红色（>= target）
```

## 关键卡点
> [!warning] 我当时卡在这
> - 标准二分法的边界条件容易搞混（`<=` 还是 `<`，`+1` 还是 `-1`）
> - 红蓝边界法的开区间设计：`left = -1`, `right = n`，循环条件 `left + 1 != right`

## 红蓝边界法优势
1. **边界清晰**：永远是开区间 `(-1, n)`，不需要纠结初始值
2. **不会死循环**：`left + 1 == right` 时自然退出
3. **统一模板**：`left = mid` / `right = mid`，不需要 `+1` / `-1`
4. **通杀所有二分题**：33、34、153、704 都能直接套

## 复杂度
- 时间：O(log n)
- 空间：O(1)

> [!note] 面试追问点
> - 为什么用 `left + (right - left) / 2` 而不是 `(left + right) / 2`？防溢出
> - 红蓝边界法的 `left = -1` 和 `right = n` 是什么含义？哨兵位，表示边界外

## 一句话记忆点
> [!tip] 下次看到类似题
> 二分查找 → 红蓝边界法，开区间 + 收缩边界，`right` 就是第一个 >= target 的位置。
