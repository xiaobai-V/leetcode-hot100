# 25. K 个一组翻转链表

> [!abstract] 一句话本质
> **分组反转 + 拼接**，每组就是 206 反转链表，但用半开区间 `[head, nextStart)` 让翻转和接链一步到位。

> [!quote] 链接
> - https://leetcode.cn/problems/reverse-nodes-in-k-group/

## 题目
给定单链表，每 k 个节点一组翻转，不足 k 个保持原序。

## 思路

**核心：反转函数用半开区间 `[head, nextStart)`**
- `reverse(head, nextStart)`：反转从 head 到 nextStart 之间的节点，反转时每个节点直接指向 nextStart
- 好处：反转和接链合二为一，不需要额外的 `tail->next = nextGroup`

**主流程：**
1. fast 走 k 步找本组末尾，不足 k 个直接结束
2. 记录 curHead（本组头）和 nxtGroup（下一组头）
3. `prevTail->next = reverse(curHead, nxtGroup)` 反转并接链
4. 更新 prevTail = curHead（反转后变尾），fast = prevTail
5. 重复

## 关键卡点
> [!warning] 我当时卡在这
> - 不是用 nullptr 终止反转，而是用 nextStart 作为终止和初始 pre
> - 反转后 curHead（原头）变成尾，更新 prevTail 时要记对

## 代码
```cpp
class Solution {
    ListNode* reverse(ListNode* head, ListNode* nextStart) {
        ListNode* pre = nextStart;
        ListNode* cur = head;
        while (cur != nextStart) {
            ListNode* nxt = cur->next;
            cur->next = pre;
            pre = cur;
            cur = nxt;
        }
        return pre;
    }
public:
    ListNode* reverseKGroup(ListNode* head, int k) {
        ListNode* dummy = new ListNode(0, head);
        ListNode* prevTail = dummy;
        ListNode* fast = dummy;
        while (true) {
            for (int i = 0; i < k && fast; ++i)
                fast = fast->next;
            if (!fast) break;
            ListNode* curHead = prevTail->next;
            ListNode* nxtGroup = fast->next;
            prevTail->next = reverse(curHead, nxtGroup);
            prevTail = curHead;
            fast = prevTail;
        }
        return dummy->next;
    }
};
```

## 复杂度
- 时间：O(n)，每个节点遍历两次（一次找末尾，一次反转）
- 空间：O(1)
