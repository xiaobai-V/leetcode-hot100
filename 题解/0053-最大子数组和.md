# 53. 最大子数组和

> [!abstract] 一句话本质
> **回答"前面的累积是帮我还是害我"**——害我（<0）就丢掉重来，帮我（>0）就接上。

> [!quote] 链接
> - https://leetcode.cn/problems/maximum-subarray/

## 题目
给定整数数组 `nums`（至少 1 个元素），找出和最大的连续子数组，返回其和。

## 思路（从暴力到最优）

**暴力**：枚举所有子数组算和 → O(n²)。

**核心抉择**：每来一个 `nums[i]`，要不要把它接在前面子数组后面？只有当前缀和 `> 0` 时接上才更划算，否则不如从 `nums[i]` 单独开始。

**两种等价写法**：

**写法 A（DP）**：`dp[i]` = 以 `nums[i]` 结尾的最大子数组和
- 转移：`dp[i] = max(dp[i-1] + nums[i], nums[i])`
- 边界：`dp[0] = nums[0]`
- 答案：`max(dp[i])`

**写法 B（贪心）**：累加和 `sum`，遇到 `sum < 0` 重置为 0
- 数学上和写法 A 等价——`dp[i]` 退化成单变量就是 `sum`
- 空间从 O(n) 压缩到 O(1)

## 关键卡点

> [!warning] 我当时卡在这
> - **更新顺序不能换**：必须**先用 sum 更新答案，再判断重置**。如果反过来（先重置再用 sum 更新），全负数组会返回 0 而不是最大负数。例如 `[-3,-1,-2]` 正确答案是 `-1`，反顺序会得 0。
> - **`res` 初始化**：用 `INT_MIN` 安全（本题数据范围内不会溢出），但用 `nums[0]` 更稳。**不能用 0**——会丢掉全负数组的情况。
> - **空数组边界**：题目保证至少 1 个元素，工程代码仍建议开头特判 `nums.empty()`。

## 代码

```cpp
// 写法 B：贪心 O(n) / O(1)
class Solution {
public:
    int maxSubArray(vector<int>& nums) {
        int res = nums[0];  // 用 nums[0] 比 INT_MIN 更稳
        int sum = 0;
        for (int x : nums) {
            sum += x;
            res = max(res, sum);  // 顺序：先更新答案
            if (sum < 0) sum = 0; //         再重置
        }
        return res;
    }
};
```

```cpp
// 写法 A：DP（空间压缩前）
class Solution {
public:
    int maxSubArray(vector<int>& nums) {
        int n = nums.size();
        vector<int> dp(n);
        dp[0] = nums[0];
        int res = dp[0];
        for (int i = 1; i < n; i++) {
            dp[i] = max(dp[i-1] + nums[i], nums[i]);
            res = max(res, dp[i]);
        }
        return res;
    }
};
```

## 复杂度
- 时间：O(n)
- 空间：贪心 O(1)，DP 原始 O(n)、可压缩到 O(1)

> **最大子数组和 → 贪心累加，sum<0 重置 0；更新答案在重置之前**。DP 转移 `dp[i] = max(dp[i-1]+x, x)` 与贪心等价。
