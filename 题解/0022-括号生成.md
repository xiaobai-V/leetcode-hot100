# 22. 括号生成

> [!abstract] 一句话本质
> **回溯 + 双计数剪枝**，不是暴力枚举所有 2^(2n) 种组合，而是只生成合法的括号序列。

> [!quote] 链接
> - https://leetcode.cn/problems/generate-parentheses/

## 题目
数字 n 代表生成括号的对数，请你设计一个函数，用于能够生成所有可能的并且有效的括号组合。

## 思路（从暴力到最优）
1. **暴力想法**：枚举所有 2^(2n) 种 '(' 和 ')' 的组合，然后验证是否合法。O(2^(2n) × n)。
2. **优化 → 回溯剪枝**：用两个计数器 `leftCnt` 和 `rightCnt` 跟踪左右括号数量，只在合法时继续递归。
3. **关键剪枝**：
   - `leftCnt > n` 或 `rightCnt > n` → 括号超量
   - `rightCnt > leftCnt` → 右括号不能比左括号多（否则非法）
   - `leftCnt == rightCnt` 时，下一个必须是左括号（提前剪枝）

## 关键卡点
> [!warning] 我当时卡在这
> - 剪枝条件要写全：`leftCnt < 0 || leftCnt > n || rightCnt < 0 || rightCnt > n || rightCnt > leftCnt`
> - 终止条件：`path.size() == n * 2`（不是 n）
> - 优化：`if(leftCnt == rightCnt && i == 1) continue;` 提前剪掉无效分支

## 代码
```cpp
class Solution {
    vector<string> res;
    string path;
    vector<char> choices{'(', ')'};
    void backtrack(int n, int leftCnt, int rightCnt) {
        if (leftCnt < 0 || leftCnt > n || rightCnt < 0 || rightCnt > n ||
            rightCnt > leftCnt) {
            return;
        }
        if (path.size() == n * 2) {
            res.push_back(path);
            return;
        }

        for (int i = 0; i < 2; i++) {
            if(leftCnt == rightCnt && i == 1)
                continue;
            char ch = choices[i];
            path.push_back(ch);
            if (ch == '(') {
                backtrack(n, leftCnt + 1, rightCnt);
            } else {
                backtrack(n, leftCnt, rightCnt + 1);
            }
            path.pop_back();
        }
    }

public:
    vector<string> generateParenthesis(int n) {
        backtrack(n, 0, 0);
        return res;
    }
};
```

## 复杂度
- 时间：O(4ⁿ / √n) — 卡特兰数上界，剪枝后远小于此
- 空间：O(n) — 递归栈深度

## 一句话记忆点
> [!tip] 下次看到类似题
> 括号生成 = 回溯 + 两个计数器 + 三个剪枝条件。记住 `rightCnt > leftCnt` 是核心非法判断。
