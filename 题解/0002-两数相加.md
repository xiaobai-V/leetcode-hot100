# 2. 两数相加

> [!abstract] 一句话本质
> **模拟竖式加法**，从低位到高位逐位相加，用链表表示结果。

> [!quote] 链接
> - https://leetcode.cn/problems/add-two-numbers/

## 题目
两个非空链表表示两个非负整数，每个节点存一位数字，逆序排列（低位在前）。求它们的和，返回同样格式的链表。

## 思路

**方法：dummyHead + 模拟加法**
- 两个指针同步遍历两条链表
- 每步取两个值（走完的当 0）+ 进位，算当前位和新进位
- 循环结束后，如果进位不为 0，再加一个节点
- 时间 O(max(m,n))，空间 O(max(m,n))

**简化技巧**：走完的链表值当 0，避免三路分支。

## 关键卡点
> [!warning] 我当时卡在这
> - 最后进位：循环结束时 carrier 可能不为 0（如 99+1=100），必须单独处理
> - 走完的链表值当 0，简化代码结构

## 代码
```cpp
class Solution {
public:
    ListNode* addTwoNumbers(ListNode* l1, ListNode* l2) {
        ListNode* dummyHead = new ListNode(0);
        ListNode* cur1 = l1;
        ListNode* cur2 = l2;
        ListNode* cur = dummyHead;
        int carrier = 0;
        while (cur1 != nullptr || cur2 != nullptr) {
            int add1 = cur1 ? cur1->val : 0;
            int add2 = cur2 ? cur2->val : 0;
            int sum = add1 + add2 + carrier;
            carrier = sum / 10;
            cur->next = new ListNode(sum % 10);
            cur = cur->next;
            if (cur1) cur1 = cur1->next;
            if (cur2) cur2 = cur2->next;
        }
        if (carrier != 0) {
            cur->next = new ListNode(carrier);
        }
        ListNode* head = dummyHead->next;
        delete dummyHead;
        return head;
    }
};
```

## 复杂度
- 时间：O(max(m,n))
- 空间：O(max(m,n))
