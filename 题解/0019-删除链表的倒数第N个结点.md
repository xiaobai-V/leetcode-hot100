# 19. 删除链表的倒数第 N 个结点

> [!abstract] 一句话本质
> **快慢指针一次遍历找倒数第 n 个**，不是先求长度再定位。

> [!quote] 链接
> - https://leetcode.cn/problems/remove-nth-node-from-end-of-list/

## 题目
给定单链表，删除倒数第 n 个节点，返回头节点。

## 思路

**方法一：两次遍历**
- 第一次求长度 sz，第二次走到第 sz-n 个节点，删除下一个
- 时间 O(L)，空间 O(1)

**方法二：快慢指针一次遍历（最优）**
- dummyHead 处理删除头节点的边界
- fast 先走 n 步，然后 fast 和 slow 同时走
- fast 到最后一个节点时，slow 在倒数第 n+1 个节点（待删节点的前一个）
- 删除 slow->next
- 时间 O(L)，空间 O(1)

> [!tip] while 条件选择
> 用 `fast != nullptr && fast->next != nullptr`，让 fast 停在最后一个节点。
> 如果用 `fast != nullptr`，fast 走到 nullptr，slow 会多走一步，停在待删节点本身。

## 关键卡点
> [!warning] 我当时卡在这
> - dummyHead 是必须的，否则删除第一个节点时没有前驱
> - while 条件决定了 slow 停在哪里：`fast->next != nullptr` → slow 停在前一个节点

## 代码
```cpp
class Solution {
public:
    ListNode* removeNthFromEnd(ListNode* head, int n) {
        ListNode* dummyHead = new ListNode(0);
        dummyHead->next = head;
        ListNode* slow = dummyHead;
        ListNode* fast = dummyHead;
        for (int i = 0; i < n; i++) {
            fast = fast->next;
        }
        while (fast->next != nullptr) {
            fast = fast->next;
            slow = slow->next;
        }
        ListNode* temp = slow->next;
        slow->next = temp->next;
        delete temp;
        head = dummyHead->next;
        delete dummyHead;
        return head;
    }
};
```

## 复杂度
- 时间：O(L)，L 为链表长度
- 空间：O(1)
