# 138. 随机链表的复制

> [!abstract] 一句话本质
> **深拷贝带 random 指针的链表**，关键是建立"原节点→新节点"的映射。

> [!quote] 链接
> - https://leetcode.cn/problems/copy-list-with-random-pointer/

## 题目
给定一个特殊链表，每个节点有 next 和 random 指针，深拷贝这条链表。

## 思路

**方法一：哈希表映射（直观）**
- 第一次遍历：复制所有节点，存入 `umap[原节点] = 新节点`
- 第二次遍历：`newNode->random = umap[oldNode->random]`
- 时间 O(n)，空间 O(n)

**方法二：交织法（O(1) 空间）**
- 第一步：把新节点插到原节点后面 → 1→1'→2→2'→...
- 第二步：设置 random → `newNode->random = oldNode->random->next`（如果 random 不为空）
- 第三步：拆分链表，把原链表和新链表分开
- 时间 O(n)，空间 O(1)

## 关键卡点
> [!warning] 我当时卡在这
> - 卡在"知道原节点的 random 指向哪个原节点，但不知道对应的新节点"
> - 哈希表解决映射问题；交织法利用物理位置关系避免映射
> - 交织法第二步要判断 `cur->random` 是否为空

## 代码

**哈希表法：**
```cpp
class Solution {
public:
    Node* copyRandomList(Node* head) {
        unordered_map<Node*, Node*> umap;
        Node* cur = head;
        while (cur) {
            umap[cur] = new Node(cur->val);
            cur = cur->next;
        }
        cur = head;
        while (cur) {
            umap[cur]->next = umap[cur->next];
            umap[cur]->random = umap[cur->random];
            cur = cur->next;
        }
        return umap[head];
    }
};
```

**交织法：**
```cpp
class Solution {
public:
    Node* copyRandomList(Node* head) {
        if (!head) return nullptr;
        // 1. 交织
        Node* cur = head;
        while (cur) {
            Node* nxt = cur->next;
            cur->next = new Node(cur->val);
            cur->next->next = nxt;
            cur = nxt;
        }
        // 2. 设置 random
        cur = head;
        while (cur) {
            if (cur->random)
                cur->next->random = cur->random->next;
            cur = cur->next->next;
        }
        // 3. 拆分
        Node* dummy = new Node(0);
        Node* cp = dummy;
        cur = head;
        while (cur) {
            cp->next = cur->next;
            cur->next = cur->next->next;
            cp = cp->next;
            cur = cur->next;
        }
        return dummy->next;
    }
};
```

## 复杂度
- 哈希表：时间 O(n)，空间 O(n)
- 交织法：时间 O(n)，空间 O(1)
