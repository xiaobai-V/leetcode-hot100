# 279. 完全平方数

> [!abstract] 一句话本质
> **把 n 拆成若干个平方数，求最少使用数量**，不是判断某个平方数能不能用，而是枚举最后选的那个平方数。

> [!quote] 链接
> - https://leetcode.cn/problems/perfect-squares/

## 题目

给定整数 `n`，返回和为 `n` 的完全平方数的最少数量。完全平方数是 `1, 4, 9, 16...` 这类数。

## 思路（从暴力到最优）

最直接的想法是递归枚举每次选择哪个平方数：要凑出 `i`，可以先凑出 `i - 1^2`，再加一个 `1^2`；也可以先凑出 `i - 2^2`，再加一个 `2^2`。这些子问题会大量重复，所以用动态规划记录答案。

定义：

```text
dp[i] = 刚好凑出 i 所需要的最少完全平方数个数
```

初始化：

```text
dp[0] = 0
```

这个初始化很关键：当 `i` 本身就是完全平方数时，比如 `i = j * j`，就能自然得到：

```text
dp[i] = dp[i - j*j] + 1 = dp[0] + 1 = 1
```

不需要单独判断 `i` 是否是完全平方数。

转移时枚举最后选的平方数 `j*j`：

```text
dp[i] = min(dp[i], dp[i - j*j] + 1)
```

其中 `+1` 表示这次新加入的平方数 `j*j`。由于最后一个平方数一定是某个 `j*j`，枚举所有 `j*j <= i` 就能覆盖所有可能。

以 `n = 12` 为例：

```text
dp[12] 可以来自：
dp[11] + 1   // 最后加 1
dp[8] + 1    // 最后加 4
dp[3] + 1    // 最后加 9
```

取最小值就是答案。

## 关键卡点

> [!warning] 我当时卡在这
> - `dp[0] = 0` 不是凑数答案，而是为了让 `i = j*j` 时可以自然转移出 `dp[i] = 1`。
> - `dp[i]` 要理解成“刚好凑出 i”的最少数量。
> - 内层循环从 `j = 0` 开始虽然不影响结果，但 `j = 0` 只会得到 `dp[i] = dp[i] + 1`，是冗余的，最好从 `1` 开始。
> - 复杂度不是 `O(n^2)`，因为每个 `i` 只枚举到 `sqrt(i)`，所以是 `O(n * sqrt(n))`。

## 代码

```cpp
class Solution {
public:
    int numSquares(int n) {
        vector<int> dp(n + 1, n);
        dp[0] = 0;

        for (int i = 1; i <= n; i++) {
            for (int j = 1; j * j <= i; j++) {
                dp[i] = min(dp[i], dp[i - j * j] + 1);
            }
        }

        return dp[n];
    }
};
```

## 复杂度

- 时间：`O(n * sqrt(n))`
- 空间：`O(n)`

## 一句话记忆点

> [!tip] 下次看到类似题
> 求“凑出 n 的最少数量”时，先想 `dp[i] = min(dp[i - cost] + 1)`；这题的 `cost` 就是所有不超过 `i` 的平方数。
