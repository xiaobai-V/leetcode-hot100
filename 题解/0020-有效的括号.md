# 20. 有效的括号

> [!abstract] 一句话本质
> **栈模拟括号匹配**，遇到左括号入栈，遇到右括号检查栈顶是否匹配。

> [!quote] 链接
> - https://leetcode.cn/problems/valid-parentheses/

## 题目
给定一个只包含 `()[]{}` 的字符串，判断字符串是否有效。有效条件：左括号必须用相同类型的右括号闭合，且按正确顺序闭合。

## 思路

**核心**：括号匹配 = 栈的 LIFO 特性。最近的左括号要和第一个遇到的右括号匹配。

**流程**：
1. 遍历字符串
2. 遇到左括号 → 入栈
3. 遇到右括号 → 检查栈顶是否匹配
   - 匹配 → 弹栈
   - 不匹配 → return false
4. 遍历结束后，栈为空 → true，否则 false

**为什么用栈？** 括号匹配具有嵌套结构——最后打开的要最先关闭，这正是栈的 LIFO 特性。

## 关键卡点
> [!warning] 我当时卡在这
> - 遇到右括号但栈为空 → 说明右括号多了，直接 return false
> - 遍历结束后栈不为空 → 说明左括号多了，返回 false
> - 不匹配时要直接返回 false，不要继续遍历

## 代码
```cpp
class Solution {
public:
    bool isValid(string s) {
        stack<char> stk;
        for (char ch : s) {
            if (stk.empty()) {
                stk.push(ch);
            } else {
                char top = stk.top();
                if (ch == ')' && top == '(' || ch == ']' && top == '[' ||
                    ch == '}' && top == '{') {
                    stk.pop();
                } else {
                    stk.push(ch);
                }
            }
        }
        return stk.empty();
    }
};
```

## 复杂度
- 时间：O(n)，遍历一次字符串
- 空间：O(n)，最坏全是左括号
