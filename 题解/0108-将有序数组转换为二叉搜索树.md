# 108. 将有序数组转换为二叉搜索树

> [!abstract] 一句话本质
> **有序数组 + 二分 = 平衡 BST**——每次取中点作为根，左右子树递归构建，天然保证高度平衡。

> [!quote] 链接
> - https://leetcode.cn/problems/convert-sorted-array-to-binary-search-tree/

## 题目
给定一个升序排列的有序数组，将其转换为一棵高度平衡的二叉搜索树。

## 思路

有序数组 + BST → 中序遍历的逆过程。BST 的中序遍历就是升序，所以反过来，从有序数组构建 BST。

关键：**选中点作为根**。中点左边的元素天然比它小（去左子树），右边天然比它大（去右子树），而且左右两边元素数量接近，树自然平衡。如果不选中点（比如选第一个），会退化成链表。

这就是二分的思想：每次把区间一分为二，中点变根，左右递归。

## 关键卡点

> [!warning] 易错点
> - 边界条件 `start > end` 返回 nullptr：当 `start == end` 时 mid 就是这个元素，递归左右子树时 `mid-1 < start` 或 `mid+1 > end` 触发此条件
> - `mid = start + (end - start) / 2` 防整数溢出，比 `(start + end) / 2` 安全
> - 空数组输入要能处理（虽然题目保证非空）

## 代码

```cpp
class Solution {
private:
    TreeNode* build(vector<int>& nums, int start, int end) {
        if (start > end) return nullptr;
        int mid = start + (end - start) / 2;
        TreeNode* root = new TreeNode(nums[mid]);
        root->left = build(nums, start, mid - 1);
        root->right = build(nums, mid + 1, end);
        return root;
    }
public:
    TreeNode* sortedArrayToBST(vector<int>& nums) {
        return build(nums, 0, nums.size() - 1);
    }
};
```

## 复杂度
- 时间：O(n)，每个节点创建一次
- 空间：O(log n)，递归栈深度 = 树高（平衡树高度 log n）
