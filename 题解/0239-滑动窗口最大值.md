# 239. 滑动窗口最大值

> [!abstract] 一句话本质
> **单调递减队列**维护窗口内"可能成为最大值"的候选下标，不是优先队列（虽然堆也行，但单调队列更省）。

> [!quote] 链接
> - https://leetcode.cn/problems/sliding-window-maximum/

## 题目
给定数组和窗口大小 `k`，返回每个滑动窗口的最大值。

## 思路（从暴力到最优）

**暴力**：每个窗口遍历一次找最大值 → O(n·k)，超时。

**核心观察**：窗口右移时，新加入的 `nums[j]` 会让它左边所有比它小的元素"失效"——既被它压过、又比它先出窗口。比如 `[5,3,1]` 加入 `4`，3 和 1 都可以扔掉（永远不可能当最大值）。

**单调队列**：用双端队列 `deque<int>` 存**下标**，让队首到队尾对应的值**严格单调递减**。
- **入队**：从队尾弹出所有 `nums[队尾] <= nums[i]` 的元素，再把 `i` 入队尾
- **出队**：若 `dq.front() < i - k + 1`（已滑出窗口），从队首弹出
- **窗口最大值** = `nums[dq.front()]`

## 关键卡点

> [!warning] 我当时卡在这
> - **核心观察想不通**：为什么新元素能让左边小的元素"失效"——既被它压过、又比它先出窗口，所以永久无用。
> - **存下标而非存值**：因为要判断下标是否过期（窗口已滑过）。`dq.front() < i` 这行判断必须基于下标。
> - **`>=` 而非 `>`**：相等时留新值，因为新值下标更大、更晚过期。
> - **`if` 还是 `while` 弹出过期**：窗口每次只滑 1 格，每轮最多 1 个下标过期，所以 `if` 够用（用 `while` 也对，更稳健）。

## 代码

```cpp
class Solution {
public:
    vector<int> maxSlidingWindow(vector<int>& nums, int k) {
        int n = nums.size();
        vector<int> res(n - k + 1);
        deque<int> dq; // 存下标，队首到队尾对应的值单调递减

        // 初始化第一个窗口 [0, k-1]
        for (int i = 0; i < k; i++) {
            while (!dq.empty() && nums[i] >= nums[dq.back()]) {
                dq.pop_back();
            }
            dq.push_back(i);
        }
        res[0] = nums[dq.front()];

        // 滑动窗口：i 为窗口起始索引
        for (int i = 1; i < n - k + 1; i++) {
            if (dq.front() < i) dq.pop_front(); // 队首过期，弹出
            int inIdx = i + k - 1;               // 新进入窗口的下标
            while (!dq.empty() && nums[inIdx] >= nums[dq.back()]) {
                dq.pop_back();
            }
            dq.push_back(inIdx);
            res[i] = nums[dq.front()];
        }
        return res;
    }
};
```

## 复杂度
- 时间：O(n) — 摊还分析，每个元素最多入队 1 次、出队 1 次
- 空间：O(k) — 队列最多 k 个元素
