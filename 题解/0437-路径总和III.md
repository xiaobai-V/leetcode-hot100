# 437. 路径总和 III

> [!abstract] 一句话本质
> **前缀和 + 树的 DFS**，和 560 题同一个思想，但路径必须从上往下。

> [!quote] 链接
> - https://leetcode.cn/problems/path-sum-iii/

## 题目

给定二叉树根节点和整数 targetSum，求路径和等于 targetSum 的路径数目。路径可以从任意节点开始，但必须向下。

## 思路（从暴力到最优）

### 解法一：暴力递归 O(n²)

对每个节点，以它为起点往下找所有路径和等于 targetSum 的路径。用两个函数：
- `pathSum(root)`：以 root 为根的树中，所有路径数 = 以 root 为起点的路径数 + 左子树路径数 + 右子树路径数
- `rootSum(node, target)`：从 node 往下走，路径和等于 target 的路径数

时间 O(n²)，最坏链状树。

### 解法二：前缀和 + DFS O(n)

和 560. 和为 K 的子数组 同一个思想：

- 从根到当前节点的前缀和为 `curr`
- 如果之前某个祖先的前缀和是 `curr - targetSum`，说明从那个祖先的下一个节点到当前节点，路径和等于 targetSum
- 用哈希表记录每个前缀和出现的次数

**关键细节**：
1. `prefix[0] = 1` 初始化——处理从根节点开始的路径
2. **回溯**：离开节点时 `prefix[curr]--`，因为前缀和是路径相关的，左子树的前缀和不应该影响右子树

## 关键卡点

> [!warning] 我当时卡在这
> - **为什么需要回溯**：前缀和是"从根到当前节点"的路径和。遍历完左子树去右子树时，左子树的前缀和不应该在哈希表里，否则会错误地跨分支计算路径
> - **`prefix[0] = 1`**：统一处理 `prefix[j] == target` 的情况，不用单独判断

> [!warning] 易错边界
- 空树返回 0
- 路径和可能为负数，用 `long long` 存前缀和

## 代码

### 解法一：暴力递归

```cpp
class Solution {
public:
    int pathSum(TreeNode* root, int targetSum) {
        if (!root) return 0;
        return rootSum(root, targetSum) + 
               pathSum(root->left, targetSum) + 
               pathSum(root->right, targetSum);
    }
    long long rootSum(TreeNode* node, long long target) {
        if (!node) return 0;
        int res = 0;
        if (node->val == target) res++;
        res += rootSum(node->left, target - node->val);
        res += rootSum(node->right, target - node->val);
        return res;
    }
};
```

### 解法二：前缀和 + DFS

```cpp
class Solution {
public:
    unordered_map<long long, int> prefix;
    int dfs(TreeNode* root, long long curr, int targetSum) {
        if (!root) return 0;
        int ret = 0;
        curr += root->val;
        if (prefix.count(curr - targetSum)) {
            ret += prefix[curr - targetSum];
        }
        prefix[curr]++;
        ret += dfs(root->left, curr, targetSum);
        ret += dfs(root->right, curr, targetSum);
        prefix[curr]--; // 回溯：离开节点时减掉
        return ret;
    }
    int pathSum(TreeNode* root, int targetSum) {
        prefix[0] = 1;
        return dfs(root, 0, targetSum);
    }
};
```

## 复杂度

- 解法一：时间 O(n²)，空间 O(h)
- 解法二：时间 O(n)，空间 O(n)（哈希表 + 递归栈）
