# 76. 最小覆盖子串

> [!abstract] 一句话本质
> **变长滑动窗口 + 字符频次计数**——right 贪心扩张直到覆盖，left 在仍覆盖时拼命收缩，不是固定窗口（与 438 不同）。

> [!quote] 链接
> - https://leetcode.cn/problems/minimum-window-substring/

## 题目
给定字符串 `s` 和 `t`，返回 `s` 中涵盖 `t` 所有字符的最小子串。不存在返回空串。

## 思路（从暴力到最优）

**变长滑动窗口**核心策略：
- **right 每次右移 1 步**，扩张窗口
- **每扩张 1 次后，立刻用 while 把 left 收缩到"刚好仍覆盖 t"的位置**——这样才能保证每次找到的是"当前 right 下的最短覆盖"
- 在收缩过程中持续更新最小长度

类比：right 贪心扩展，left 事后修剪。

**O(n) 的原因**：每个元素最多被 right 和 left 各访问 1 次 → 总 O(n)。

**"是否覆盖"的判断**：维护 `formed` 计数器，避免每次遍历 26/52 个字符。
- 方案 A（**本代码**）：`formed` = 已匹配的字符**总数**，最大值 = `tLen`
- 方案 B（**推荐**）：`formed` = 已满足的字符**种类数**，配合 `required` = t 中不同字符种类数

## 关键卡点

> [!warning] 我当时卡在这
> - **大小写映射冲突**：`islower(c) ? c-'a' : c-'A'` 会让 'a' 和 'A' 都映射到 0。修法：大写用 `c-'A'+26`，或者干脆 `vector<int>(128)`。
> - **`formed` 更新条件不对称**：
>   - 加入时（自增后判）：`tCount[idx] >= wCount[idx]` → `formed++`
>   - 移出时（自减后判）：`tCount[idx] > wCount[idx]` → `formed--`
>   
>   不能对换——加入时 `>=` 是"窗口计数还没超过需求时才算 1 次有效匹配"；移出时 `>` 是"减完仍不缺才算仍满足"。
> - **`substr(起始, 长度)` 第二个参数是长度**，不是结束下标
> - **`ansleft` 需要单独记录**：循环结束时的 left 不是最小窗口的起始位置
> - **没找到匹配的边界**：用 `minLen == sLen + 1` 判断

## 代码

```cpp
class Solution {
public:
    string minWindow(string s, string t) {
        int sLen = s.size(), tLen = t.size();
        if (sLen < tLen) return "";

        vector<int> tCount(52);  // 0~25 小写, 26~51 大写
        for (char c : t) {
            int idx = islower(c) ? c - 'a' : c - 'A' + 26;
            tCount[idx]++;
        }

        vector<int> wCount(52);
        int formed = 0;          // 已匹配的字符总数
        int minLen = sLen + 1;
        int ansLeft = 0;
        int left = 0;

        for (int right = 0; right < sLen; right++) {
            // right 入窗口
            int idx = islower(s[right]) ? s[right] - 'a' : s[right] - 'A' + 26;
            wCount[idx]++;
            if (tCount[idx] >= wCount[idx]) formed++;

            // 覆盖时拼命收缩 left
            while (formed == tLen && left <= right) {
                if (right - left + 1 < minLen) {
                    minLen = right - left + 1;
                    ansLeft = left;
                }
                int lIdx = islower(s[left]) ? s[left] - 'a' : s[left] - 'A' + 26;
                wCount[lIdx]--;
                if (tCount[lIdx] > wCount[lIdx]) formed--;
                left++;
            }
        }
        return (minLen == sLen + 1) ? "" : s.substr(ansLeft, minLen);
    }
};
```

## 复杂度
- 时间：O(n) — 每个元素被 left 和 right 各访问最多 1 次
- 空间：O(52) = O(1) — 字符集大小固定
