# 141. 环形链表

> [!abstract] 一句话本质
> **快慢指针判环**，不是遍历记录而是"龟兔赛跑"——有环则必相遇。

> [!quote] 链接
> - https://leetcode.cn/problems/linked-list-cycle/

## 题目
给定单链表 head，判断是否有环。

## 思路（从暴力到最优）

**方法一：哈希表**
- 遍历链表，把每个节点存入哈希集合，遇到已存在的节点说明有环
- 时间 O(n)，空间 O(n)

**方法二：快慢指针（最优）**
- slow 每次走 1 步，fast 每次走 2 步
- 有环：fast 相对 slow 每轮多走 1 步，两者距离每轮缩小 1，最终必相遇（龟兔赛跑）
- 无环：fast 先到 nullptr，退出循环
- 时间 O(n)，空间 O(1)

> [!tip] 为什么从同一出发点
> fast 和 slow 都从 head 出发，避免 head 就是环入口时的误判。如果 fast 从 head->next 出发，第一轮就可能 slow->next == fast，错误返回 true。

## 关键卡点
> [!warning] 我当时卡在这
> - 快慢指针从同一点出发，不是为了"对齐"而是为了避免边界误判
> - 为什么必相遇：相对距离每轮缩小 1，不管初始距离多少都会追上

## 代码
```cpp
class Solution {
public:
    bool hasCycle(ListNode *head) {
        ListNode* slow = head;
        ListNode* fast = head;
        while (fast != nullptr && fast->next != nullptr) {
            slow = slow->next;
            fast = fast->next->next;
            if (slow == fast) return true;
        }
        return false;
    }
};
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

> [!tip] 下次看到类似题
> 判环→快慢指针同起点出发，fast 每次走两步，相遇就有环。
