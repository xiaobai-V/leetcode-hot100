# 84. 柱状图中最大的矩形

> [!abstract] 一句话本质
> **最大矩形的高度一定等于某根柱子的高度**，所以枚举"以每根柱子为高"时能向左右延伸多宽，用**单调递增栈**一次性求出每根柱子左右第一个更矮的位置。

> [!quote] 链接
> - https://leetcode.cn/problems/largest-rectangle-in-histogram/

## 题目
给定非负整数数组 `heights` 表示柱状图各柱子高度，求能画出的最大矩形面积。

## 思路（从暴力到最优）

**暴力 O(n²)**：对每根柱子 `i`（高度 `h`），向左右扩散，直到碰到第一根比 `h` 矮的柱子停止，宽度 = `rightMin - leftMin - 1`，面积 = `h × 宽度`。取所有柱子的最大值。瓶颈：找左右边界各 O(n)。

**优化 O(n)**：用单调递增栈批量求出所有柱子的 `rightMin` 和 `leftMin`。

- **求 rightMin**（从左往右扫）：维护一个**高度从栈底到栈顶递增**的栈，存下标。遇到 `heights[i] < 栈顶高度` 时，栈顶那根柱子的右边界就是 `i`（它右边第一个更矮的找到了），弹出并记录；继续比，直到栈顶不比 `i` 高，把 `i` 入栈。
- **求 leftMin**（从右往左扫）：对称地，从右往左维护递增栈，遇到比栈顶矮的，栈顶的左边界就是当前 `i`。
- **哨兵默认值**：`rightMin` 全初始化为 `n`，`leftMin` 全初始化为 `-1`。等价于在数组左右各加一根**高度 0** 的虚拟柱子——0 比所有柱子都矮，保证"右边/左边没有更矮柱子"的柱子也能拿到正确边界，宽度公式 `rightMin - leftMin - 1` 直接成立，不用特判。

**算面积**：遍历每根柱子，`ans = max(ans, heights[i] × (rightMin[i] - leftMin[i] - 1))`。

> [!info] 为什么单调栈对？
> 栈里相邻两元素，**下面那个就是上面那个"左边第一个更矮的柱子"**——因为中间比它高的都被弹掉了，能留在栈里的都是"更矮且更靠左"的。这就是单调栈能同时给出左右边界的根本原因。记一句话：**栈里存的永远是"已扫描那一侧"的下标**。

## 关键卡点
> [!warning] 我当时卡在这
> - **求左边界时 `while` 里多写了一句 `stk2.push(i)`**：pop 之后立刻 push 当前 `i`，下一轮栈顶变成自己，`i` 重复入栈、单调性被破坏，`leftMin` 算错（柱 3、4 的左边界全错）。正确写法是 `while` 循环**外**只 push 一次。
> - **栈被弹空后忘记 push 当前 `i`**：第一版 `if/while/break` 写太绕，栈清空后漏入栈。
> - **写完两个边界数组就 return，忘了最后还要遍历算面积**（`ans` 一直是 0）。

## 代码
```cpp
class Solution {
public:
    int largestRectangleArea(vector<int>& heights) {
        int n = heights.size();
        // rightMin[i]：i 右侧第一个比 heights[i] 小的下标（默认 n 当右哨兵）
        vector<int> rightMin(n, n);
        stack<int> stRight;
        for (int i = 0; i < n; ++i) {
            while (!stRight.empty() && heights[i] < heights[stRight.top()]) {
                rightMin[stRight.top()] = i;
                stRight.pop();
            }
            stRight.push(i);
        }

        // leftMin[i]：i 左侧第一个比 heights[i] 小的下标（默认 -1 当左哨兵）
        vector<int> leftMin(n, -1);
        stack<int> stLeft;
        for (int i = n - 1; i >= 0; --i) {
            while (!stLeft.empty() && heights[i] < heights[stLeft.top()]) {
                leftMin[stLeft.top()] = i;
                stLeft.pop();
            }
            stLeft.push(i);
        }

        int maxArea = 0;
        for (int i = 0; i < n; ++i) {
            int width = rightMin[i] - leftMin[i] - 1;
            maxArea = max(maxArea, width * heights[i]);
        }
        return maxArea;
    }
};
```

## 复杂度
- 时间：O(n)。每个下标至多入栈一次、出栈一次，虽然 for 套 while，但摊还 O(n)。
- 空间：O(n)。两个边界数组 + 栈。
