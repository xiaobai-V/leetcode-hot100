# 74. 搜索二维矩阵

> [!abstract] 一句话本质
> **把矩阵拍平成一个有序数组，套标准一维二分**。难点不在二分，在「二维坐标 ↔ 一维下标」的映射。

> [!quote] 链接
> - https://leetcode.cn/problems/search-a-2d-matrix/

## 题目
m×n 矩阵，每行从左到右升序，且每行第一个 > 上一行最后一个（即整体可看成一条升序链表）。判断 target 是否在矩阵中。

## 思路

**核心**：矩阵可拍平成长度为 `m*n` 的升序数组，于是退化成普通二分。关键是坐标换算。

**坐标映射**（背下来）：
```
二维 [i][j]  →  一维 idx = i * n + j
一维 idx     →  二维 i = idx / n,  j = idx % n
```
（`n` 是列数，因为行优先存储）

## 关键卡点
> [!warning] 我当时卡在这
> - `matrix[mid]` 不能直接取——`mid` 是一维下标，必须先换算成 `(i, j)`：`matrix[mid/n][mid%n]`
> - 别把 `m`（行数）和 `n`（列数）搞反：除以的是**列数 n**，因为每行有 n 个元素

## 代码
```cpp
class Solution {
public:
    bool searchMatrix(vector<vector<int>>& matrix, int target) {
        int m = matrix.size(), n = matrix[0].size();
        int left = 0, right = m * n - 1;
        while (left <= right) {
            int mid = left + (right - left) / 2;  // 防溢出
            int i = mid / n, j = mid % n;          // 一维 → 二维
            if (matrix[i][j] == target) {
                return true;
            } else if (matrix[i][j] > target) {
                right = mid - 1;
            } else {
                left = mid + 1;
            }
        }
        return false;
    }
};
```

> [!tip] 也可用红蓝染色
> 找「第一个 >= target」的位置，再判断该位置是否 == target。但本题是「精确查找是否存在」，标准二分的 `==` 分支直接返回更简洁。**找边界（>=、<=）才首选红蓝染色**。

## 复杂度
- 时间：$O(\log(m \cdot n))$，每次砍掉一半
- 空间：$O(1)$

## 一句话记忆点
> [!tip] 下次看到类似题
> 拍平的有序矩阵 → 一维二分。`i = mid/n, j = mid%n`，除以列数。
