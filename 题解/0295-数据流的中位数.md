# 295. 数据流的中位数

> [!abstract] 一句话本质
> **双堆切半**：大顶堆装较小的一半（拿左半最大），小顶堆装较大的一半（拿右半最小），左半都 ≤ 右半、左半个数 ≥ 右半，中位数就在两个堆顶。

> [!quote] 链接
> - https://leetcode.cn/problems/find-median-from-data-stream/

## 题目
设计一个数据结构，支持 `addNum(num)` 添加数字、`findMedian()` 返回当前所有数的中位数。数据随时插入，要高效。

## 思路（从暴力到最优）
1. **有序数组**：每次插入后保持有序，取中间。问题：插入是 O(n)（要挪动元素），数据流场景下太慢。
2. **双堆优化**：
   - **大顶堆 `left`**：装较小的一半，堆顶 = 左半最大值
   - **小顶堆 `right`**：装较大的一半，堆顶 = 右半最小值
   - 维持不变量：`left.top() <= right.top()`，且 `left.size() == right.size()` 或 `left.size() == right.size()+1`（left 不吃亏）
   - **为什么左半用大顶堆？** findMedian 要拿"左半的最大值"——大顶堆堆顶就是最大，O(1) 拿到；小顶堆堆顶是最小，拿不到我们要的。右半要拿最小值，所以小顶堆。
   - 中位数：相等 → 两堆顶均值；不等 → left 堆顶。

## 关键卡点
> [!warning] 我当时卡在这 / 易错
> - **左大顶、右小顶的方向不能反**：要拿最大→大顶堆，要拿最小→小顶堆。反了 findMedian 拿到错的值。
> - **addNum 的"转交堆顶"**：当 `left.size()==right.size()` 且 `num > right.top()` 时，**不能**直接 `left.push(num)`——会把比 `right.top()` 还大的数塞进 left，破坏 `left.top()<=right.top()` 不变量，findMedian 取错。正确做法：把 `right.top()` 挪给 left，num 进 right。
> - 一开始想用几个 int 变量（left/right/mid）维护，发现动态插入根本记不住"左半最大/右半最小"，必须用堆。

## 代码
```cpp
class MedianFinder {
private:
    priority_queue<int> left;                              // 大顶堆，装较小一半
    priority_queue<int, vector<int>, greater<int>> right;  // 小顶堆，装较大一半
public:
    MedianFinder() {}

    void addNum(int num) {
        if (left.size() == right.size()) {
            // 目标：让 left 多一个
            if (left.empty()) {
                left.push(num);
            } else if (num > right.top()) {
                // num 属右半：把右半最小值转给 left，num 进 right（维持 left.top<=right.top）
                int temp = right.top();
                right.pop();
                right.push(num);
                left.push(temp);
            } else {
                left.push(num);
            }
        } else {
            // left 比 right 多 1，目标：加到 right 让两边平衡
            if (num < left.top()) {
                // num 属左半：把左半最大值转给 right，num 进 left
                int temp = left.top();
                left.pop();
                left.push(num);
                right.push(temp);
            } else {
                right.push(num);
            }
        }
    }

    double findMedian() {
        if (left.size() == right.size()) {
            return (left.top() + right.top()) / 2.0;
        }
        return left.top();  // left 永远不少
    }
};
```

## 复杂度
- 时间：`addNum` O(log n)（堆插入），`findMedian` O(1)（堆顶）
- 空间：O(n)，存所有数
