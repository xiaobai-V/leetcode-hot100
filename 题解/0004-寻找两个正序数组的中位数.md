# 4. 寻找两个正序数组的中位数

> [!abstract] 一句话本质
> **在短数组上二分切分点**，让左半段 = 右半段（或左多一个），通过比较边界值判断切分是否正确。

> [!quote] 链接
> - https://leetcode.cn/problems/median-of-two-sorted-arrays/

## 题目
两个正序数组 nums1 和 nums2，求它们合并后的中位数。要求时间 O(log(m+n))。

## 思路（从暴力到最优）

**暴力**：合并两个数组再取中位数，O(m+n)。不满足 O(log) 要求。

**最优：二分切分**
- 思路：假设把两个数组各切一刀，左半段和右半段各占一半元素
- `i` = nums1 左半段元素个数，`j = (m+n+1)/2 - i` = nums2 左半段元素个数
- 在**短数组**上二分 i（范围 [0, m]），保证 j 不会越界（j >= 0）
- 切分正确的条件：`nums1[i-1] <= nums2[j] && nums2[j-1] <= nums1[i]`（左半段最大值 ≤ 右半段最小值）

**切分图解**（i=2, j=1）：
```
nums1:  [1, 3 | 5]       i=2
nums2:  [2 | 4, 6]       j=1
        ←左半段→ ←右半段→
左半段 max = max(3, 2) = 3
右半段 min = min(5, 4) = 4
中位数 = (3+4)/2 = 3.5
```

**为什么确保 m <= n？**
- `j = totalLeft - i`，如果在长数组上二分，i 可能很大导致 j < 0 越界
- 在短数组上二分，i ∈ [0, m]，j = totalLeft - i >= totalLeft - m >= 0

**二分调整逻辑：**
- `nums1[i-1] > nums2[j]`：i 太大 → `right = i - 1`
- `nums2[j-1] > nums1[i]`：i 太小 → `left = i + 1`

## 关键卡点
> [!warning] 我当时卡在这
> - 理解"切分"模型：不是在合并后的数组上二分，而是在两个数组上各切一刀，用四个边界值判断切分是否正确
> - `totalLeft = (m+n+1)/2`：奇数时左半段多一个元素，中位数就是左半段最大值；偶数时中位数 = (左max + 右min) / 2
> - 边界处理：`i == 0` / `i == m` 时用 INT_MIN / INT_MAX 代替

## 代码
```cpp
class Solution {
public:
    double findMedianSortedArrays(vector<int>& nums1, vector<int>& nums2) {
        int m = nums1.size(), n = nums2.size();
        if (m > n)
            return findMedianSortedArrays(nums2, nums1);

        int left = 0, right = m;
        while (left <= right) {
            int i = (left + right) / 2;
            int j = (m + n + 1) / 2 - i;

            int left1 = i > 0 ? nums1[i - 1] : INT_MIN;
            int right1 = i < m ? nums1[i] : INT_MAX;
            int left2 = j > 0 ? nums2[j - 1] : INT_MIN;
            int right2 = j < n ? nums2[j] : INT_MAX;

            if (left1 <= right2 && left2 <= right1) {
                if ((m + n) % 2 == 1)
                    return max(left1, left2);
                else
                    return (max(left1, left2) + min(right1, right2)) / 2.0;
            } else if (left1 > right2) {
                right = i - 1;
            } else {
                left = i + 1;
            }
        }
        return 0;
    }
};
```

## 复杂度
- 时间：O(log min(m, n))，在短数组上二分
- 空间：O(1)
