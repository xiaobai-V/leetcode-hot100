# 131. 分割回文串

> [!abstract] 一句话本质
> **回溯枚举切割位置**，和全排列/子集的区别：选择的是"在哪里切"，不是"选哪个元素"。

> [!quote] 链接
> - https://leetcode.cn/problems/palindrome-partitioning/

## 题目
给定字符串 s，将 s 分割成一些子串，使每个子串都是回文串。返回 s 所有可能的分割方案。

## 思路（从暴力到最优）
1. **暴力想法**：枚举所有可能的分割方式（2^n 种），检查每种方式的所有子串是否都是回文。O(n × 2^n)。
2. **优化 → 回溯剪枝**：在回溯过程中，只在当前子串是回文时才继续递归，否则剪枝。
3. **关键**：选择的是"切割位置"，不是"元素"。

## 关键卡点
> [!warning] 我当时卡在这
> - 和全排列/子集的区别：选择的是"切割位置"，不是"元素"
> - 终止条件：`startIdx == s.size()`（切到末尾）
> - 回文判断：双指针法，`while(start < end)`
> - for 循环：从 startIdx 到末尾，尝试切割 `[startIdx, i]`

## 代码
```cpp
class Solution {
    vector<vector<string>> res;
    vector<string> path;
    // 判断是否是回文串
    bool isValid(string& s, int start, int end) {
        if (start < 0 || end >= s.size() || start > end)
            return false;
        while (start < end) {
            if (s[start] != s[end]) {
                return false;
            }
            start++;
            end--;
        }
        return true;
    }

    void backtrack(string& s, int startIdx) {
        if (startIdx == s.size()) {
            res.push_back(path);
            return;
        }

        for (int i = startIdx; i < s.size(); i++) {
            if (isValid(s, startIdx, i)) {
                string substr = s.substr(startIdx, i - startIdx + 1);
                path.push_back(substr);
                backtrack(s, i + 1);
                path.pop_back();
            }
        }
    }

public:
    vector<vector<string>> partition(string s) {
        backtrack(s, 0);
        return res;
    }
};
```

## 复杂度
- 时间：O(n × 2^n) — n 个切割位置，每个位置两种选择（切/不切）
- 空间：O(n) — 递归栈深度
