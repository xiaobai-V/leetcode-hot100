# 70. 爬楼梯

> [!abstract] 一句话本质
> **DP 入门 / 斐波那契递推**。爬到第 `i` 阶的方法数 = 第 `i-1` 阶方法数 + 第 `i-2` 阶方法数，因为最后一步要么跨 1 阶、要么跨 2 阶（两类**互斥**情况，分类计数相加）。

> [!quote] 链接
> - https://leetcode.cn/problems/climbing-stairs/

## 题目
`n` 级台阶，每次能爬 1 或 2 级，求爬到顶有多少种不同方法。

## 思路（DP 三件套）

**状态定义**：`dp[i]` = 爬到第 `i` 级台阶的**方法数**。

**转移方程**：`dp[i] = dp[i-1] + dp[i-2]`
- 盯住**最后一步**：到第 `i` 阶，最后一步只可能是
  - 从 `i-1` 跨 1 级上来 → 方案数 `dp[i-1]`
  - 从 `i-2` 跨 2 级上来 → 方案数 `dp[i-2]`
- 这两类**互斥且穷尽**所有可能 → 用**分类计数原理相加**（不是相乘！）。

**边界**：`dp[1] = 1`，`dp[2] = 2`（`n<=2` 直接返回 `n`）。

> [!info] 为什么是加不是乘
> 「乘法原理」用于分**步骤**（每步选一个，方案相乘）；「加法原理」用于分**类别**（互斥的几类方案相加）。这里最后一步是「要么…要么…」的分类，不是「先…再…」的分步，所以相加。

## 关键卡点
> [!warning] 易错点
> - 别把分类（加）和分步（乘）搞混：最后一步是二选一的**互斥分类** → 相加。
> - `n` 较大时 O(n) 数组浪费空间，可滚动优化到 O(1)。

## 代码

**O(n) 空间（最直观）：**
```cpp
class Solution {
public:
    int climbStairs(int n) {
        if (n <= 2) return n;
        vector<int> dp(n + 1);
        dp[1] = 1; dp[2] = 2;
        for (int i = 3; i <= n; i++)
            dp[i] = dp[i-1] + dp[i-2];
        return dp[n];
    }
};
```

**O(1) 空间（滚动变量，只依赖前两个值）：**
```cpp
class Solution {
public:
    int climbStairs(int n) {
        if (n <= 2) return n;
        int prev = 2, preprev = 1, cur = 0;   // prev=dp[i-1], preprev=dp[i-2]
        for (int i = 3; i <= n; i++) {
            cur = prev + preprev;
            preprev = prev;
            prev = cur;
        }
        return cur;
    }
};
```

## 复杂度
- 时间：O(n)。
- 空间：O(n) → 可优化到 O(1)（滚动）。

## 一句话记忆点
> [!tip] 下次看到类似题
> **最后一步有 k 种互斥选择 → dp[i] = 各选择方案数之和**。爬楼梯就是 `dp[i]=dp[i-1]+dp[i-2]`，本质是斐波那契。
