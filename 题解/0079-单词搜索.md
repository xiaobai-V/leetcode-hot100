# 79. 单词搜索

> [!abstract] 一句话本质
> **回溯 + 标记已访问**，在二维网格中搜索路径，核心是"标记 → 递归 → 撤销"三步走。

> [!quote] 链接
> - https://leetcode.cn/problems/word-search/

## 题目
给定 m×n 二维字符网格 board 和一个字符串 word，判断 word 是否存在于网格中。单词必须按照字母顺序通过相邻单元格（水平或垂直）构建，同一个单元格不能重复使用。

## 思路（从暴力到最优）
1. **暴力想法**：从每个格子出发，DFS 搜索所有可能路径。O(m × n × 4^L)。
2. **优化 → 标记已访问**：用 board 本身标记（改成 '#'）或额外 used 数组，避免重复访问。
3. **关键**：回溯时必须撤销标记，否则会影响其他路径的搜索。

## 关键卡点
> [!warning] 我当时卡在这
> - 用 `last_dir` + `fobidden_dir` 防往回走 → 错！应该用 used 数组或修改 board
> - 变量名冲突：循环变量 `i` 遮盖参数 `i` → 要注意命名
> - 没有回溯撤销 → 必须撤销标记！
> - `board[i][j] = '#'` 标记法：省空间，不用额外数组

## 代码
```cpp
class Solution {
private:
    int m, n;
    bool res = false;
    vector<vector<int>> dirs = {{0, 1}, {1, 0}, {0, -1}, {-1, 0}};
    void backtrack(vector<vector<char>>& board, string& word, int i, int j,
                   int startIdx) {
        if (i < 0 || i >= m || j < 0 || j >= n)
            return;
        if (board[i][j] != word[startIdx])
            return;
        if (startIdx == word.size() - 1) {
            res = true;
            return;
        }

        board[i][j] = '#'; // 标记已经访问过
        for (const auto& dir : dirs) {
            int n_i = i + dir[0];
            int n_j = j + dir[1];
            backtrack(board, word, n_i, n_j, startIdx + 1);
            if (res)
                return;  // 找到就提前返回
        }
        board[i][j] = word[startIdx]; // 回溯撤销
    }

public:
    bool exist(vector<vector<char>>& board, string word) {
        res = false;
        m = board.size(), n = board[0].size();
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (board[i][j] == word[0]) {
                    backtrack(board, word, i, j, 0);
                }
                if (res)
                    return true;
            }
        }
        return false;
    }
};
```

## 复杂度
- 时间：O(m × n × 4^L) — L 为单词长度，每个格子最多 4 个方向
- 空间：O(L) — 递归栈深度
