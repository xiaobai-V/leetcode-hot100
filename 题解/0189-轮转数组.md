# 189. 轮转数组

> [!abstract] 一句话本质
> **右轮转 k 位 = 把后 k 个搬到数组前面**。用三次翻转实现 O(1) 空间，不要开辅助数组。

> [!quote] 链接
> - https://leetcode.cn/problems/rotate-array/

## 题目
给定数组 `nums` 和整数 `k`，将数组**向右**轮转 `k` 位（原地修改）。`k` 可以大于 `n`。

## 思路（从暴力到最优）

### 暴力：每次右移 1 位，重复 k 次
```cpp
for (int t = 0; t < k; t++) {
    int last = nums[n-1];
    for (int i = n-1; i > 0; i--) nums[i] = nums[i-1];
    nums[0] = last;
}
```
**时间 O(n·k)**，`k` 大了直接 TLE。先想到这步是对的，但显然不够。

### 辅助数组：每个元素直接放到目标位置
关键观察：下标 `i` 的元素，右移 k 位后落到 `(i + k) % n`。开个新数组按这个公式放即可。
```cpp
vector<int> tmp(n);
for (int i = 0; i < n; i++) tmp[(i + k) % n] = nums[i];
nums = tmp;
```
**时间 O(n)，空间 O(n)**。LeetCode 上能 AC，但面试官通常会追问"能不能 O(1) 空间"。

### 三次翻转：O(1) 空间的最优解
先记死结论：**整体翻转 → 翻前 k 个 → 翻后 n-k 个**。

**为什么有效**（数学本质，不是巧合）：
- 原数组：`[A | B]`，A 是前 n-k 个，B 是后 k 个。右轮转 k 位的目标 = `[B | A]`。
- 整体翻转：`[A | B] → [Bᶜ | Aᶜ]`（上标 ᶜ 表示倒序）。注意 B 被甩到了前面、A 跑到后面，**位置已经对了**，只是各自反序。
- 翻前 k 个（B 段）：`[Bᶜ | Aᶜ] → [B | Aᶜ]`
- 翻后 n-k 个（A 段）：`[B | Aᶜ] → [B | A]` ✅

下标层面也成立：原位置 `i` 经三次翻转后落到 `(i + k) % n`（可手推验证）。

## 关键卡点
> [!warning] 我当时卡在这
> - **为什么三次翻转等价于轮转**：直觉记法——整体翻转时"后 k 个"自动被甩到前 k 位（虽然反序），再翻回来恢复顺序就完事。
> - **k 的处理**：必须先 `k %= n`，否则 `k ≥ n` 时下标越界或答案错。这步**不能漏**。
> - **k % n == 0 的边界**：右轮转 `n` 位等于没转。代码里要么靠 `k %= n` 自然退化（前 k 翻转和后 n-k 翻转恰好多翻两次又翻回去），要么显式判断 `if (k == 0) return`。

## 代码（推荐写法，显式 `k %= n`）

```cpp
class Solution {
private:
    void reverseRange(vector<int>& nums, int l, int r) {
        while (l < r) swap(nums[l++], nums[r--]);
    }
public:
    void rotate(vector<int>& nums, int k) {
        int n = nums.size();
        k %= n;                          // 关键：先归一化
        reverseRange(nums, 0, n - 1);    // 整体
        reverseRange(nums, 0, k - 1);    // 前 k
        reverseRange(nums, k, n - 1);    // 后 n-k
    }
};
```

> [!note] 对照：我最初 AC 的写法用 `(n - 1 + k) % n` 隐式做 mod，省了一行 `k %= n`，且 `(k-1)%n` 在 `k%n==0` 时恰好等于 `n-1`（整段翻转两次抵消），所以也能过。但**显式 `k %= n` 可读性更好**，强烈推荐改成这种。

## 复杂度
- 时间：O(n)，每个元素被翻转两次（常数次）。
- 空间：O(1)，原地操作。

## 一句话记忆点
> [!tip] 下次看到类似题
> 右轮转 k 位 = 整体翻转 + 翻前 k + 翻后 n-k。**先 `k %= n`**，这是唯一容易漏的点。
