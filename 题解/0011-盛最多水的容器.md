# 11. 盛最多水的容器

> [!abstract] 一句话本质
> **双指针从两端向内收缩，总是移动较短边**。宽度只减不增，面积变大的唯一可能是新短板更高。

> [!quote] 链接
> - https://leetcode.cn/problems/container-with-most-water/

## 题目
给定高度数组，找出两条线与 x 轴构成的最大矩形面积。面积 = 宽度 × min(左高, 右高)。

## 思路（从暴力到最优）
1. **暴力**：枚举所有两两组合，O(n²)。
2. **双指针收缩**：左右指针从两端开始，每次算当前面积，然后移动较短边。
   - 移动较短边：宽度减小，但新短板可能更高，面积可能增大。
   - 移动较长边：宽度减小，高度仍被较短边限制，面积一定减小。
   - 所以只有移动较短边才可能找到更大面积。

## 关键卡点
> [!warning] 我当时卡在这
> - 两边相等时不知道移哪边——其实移哪边都行，因为两边都是"短板"
> - `else if` 条件可以简化为 `else`，前面 `if` 已覆盖 `<` 的情况

## 代码
```cpp
class Solution {
public:
    int maxArea(vector<int>& height) {
        int left = 0, right = height.size() - 1;
        int ans = 0;
        while (left < right) {
            int cur = (right - left) * min(height[left], height[right]);
            ans = max(ans, cur);
            if (height[left] < height[right]) {
                left++;
            } else {
                right--;
            }
        }
        return ans;
    }
};
```

## 复杂度
- 时间：O(n)，指针最多移动 n 次
- 空间：O(1)

> 双指针两端收缩 → 总是移动较短边，贪心寻找更高短板。
