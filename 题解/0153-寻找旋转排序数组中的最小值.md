# 153. 寻找旋转排序数组中的最小值

> [!abstract] 一句话本质
> **旋转排序数组被分成了两段有序子数组**，最小值就是第二段的第一个元素（即第一个 < nums[0] 的元素），用二分找它。

> [!quote] 链接
> - https://leetcode.cn/problems/find-minimum-in-rotated-sorted-array/

## 题目
给定一个旋转过的升序数组（元素互不相同），找出其中的最小元素。要求 O(log n)。

## 思路（从暴力到最优）

**暴力**：遍历数组找最小值，O(n)。

**二分思路**：旋转后的数组形如 `[第一段（大值）, 第二段（小值）]`，两段各自有序。关键观察：
- `nums[mid] >= nums[0]` → mid 在第一段，第一段最小值就是 `nums[0]`，答案不可能在 mid 左侧，向右收缩
- `nums[mid] < nums[0]` → mid 在第二段，`nums[mid]` 本身可能是最小值，向左收缩

不需要关心最小值的**位置**，直接用 `ans = min(ans, ...)` 追踪最小**值**，更直观。

> [!tip] 没旋转的情况
> 数组完全有序时，所有 mid 都满足 `>= nums[0]`，`left` 一路右移，ans 始终是 `nums[0]`，正确。

## 关键卡点

> [!warning] 易错点
> - 判断条件必须是 `>=` 而不是 `>`：当左半段只剩一个元素（即未旋转）时，`nums[mid] == nums[0]`，用 `>` 会错误地进入 else 分支
> - `mid` 的计算用 `left + (right - left) / 2` 防溢出

## 代码

```cpp
class Solution {
public:
    int findMin(vector<int>& nums) {
        int left = 0, right = nums.size() - 1;
        int ans = INT_MAX;
        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] >= nums[0]) {
                ans = min(ans, nums[0]);
                left = mid + 1;
            } else {
                ans = min(ans, nums[mid]);
                right = mid - 1;
            }
        }
        return ans;
    }
};
```

## 复杂度
- 时间：O(log n)
- 空间：O(1)

> 旋转数组找最小值 → 用 `nums[0]` 当分界线，二分找第一个 < nums[0] 的元素，直接取 min 追踪答案。
