# 3. 无重复字符的最长子串

> [!abstract] 一句话本质
> **维护一个无重复字符的滑动窗口，遇到重复时收缩窗口**，不是暴力枚举所有子串。

> [!quote] 链接
> - https://leetcode.cn/problems/longest-substring-without-repeating-characters/

## 题目
给定字符串 `s`，找出不含重复字符的最长子串的长度。

## 思路（从暴力到最优）

**暴力**：枚举所有子串，检查是否有重复 → O(n³)。

**优化思路**：用滑动窗口 + 哈希表。窗口 `[slow, fast]` 内保证无重复字符：
- `fast` 右移，遇到新字符 → 扩展窗口，`cur++`
- `fast` 遇到重复字符 → `slow` 直接跳到重复字符上次出现位置的下一个，`cur = fast - slow + 1`
- 每次记录 `ans = max(ans, cur)`

**关键**：map 里可能残留 `slow` 之前的旧记录（懒删除），用 `temp->second < slow` 判断是否过期。

## 关键卡点

> [!warning] 我当时卡在这
> - **map 旧记录没处理**：遇到重复时想用 `umap.clear()`，但这会丢掉 slow 之后的有效记录。正确做法是不删、用条件跳过（懒删除）。
> - **cur 不能重置为 0**：slow 跳到新位置后，`cur` 应该是 `fast - slow + 1`，不是重新从 0 计数。
> - **最终返回值**：循环结束后要再 `ans = max(ans, cur)`，处理最后一段无重复子串。

## 代码

```cpp
class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        int ans = 0, n = s.size();
        int slow = 0, cur = 0;
        unordered_map<char, int> umap; // 字符 -> 最新下标

        for (int fast = 0; fast < n; fast++) {
            auto temp = umap.find(s[fast]);
            if (temp == umap.end() || temp->second < slow) {
                // 新字符，或旧记录在窗口外（懒删除）
                umap[s[fast]] = fast;
                cur++;
            } else {
                // 窗口内遇到重复
                ans = max(ans, cur);
                slow = temp->second + 1;
                cur = fast - slow + 1;
                umap[s[fast]] = fast;
            }
        }
        return max(ans, cur);
    }
};
```

## 复杂度
- 时间：O(n) — fast 和 slow 各最多遍历一次
- 空间：O(min(n, 字符集大小))
