# 98. 验证二叉搜索树

> [!abstract] 一句话本质
> **验证 BST 不是只看父子关系，而是看整棵子树的上下界约束**。

> [!quote] 链接
> - https://leetcode.cn/problems/validate-binary-search-tree/

## 题目

给定二叉树根节点，判断是否是有效的二叉搜索树。BST 定义：左子树所有节点严格小于根，右子树所有节点严格大于根，且左右子树递归满足 BST。

## 思路（从暴力到最优）

### 错误思路：只检查父子关系

只看 `left->val < root->val < right->val`，忽略了 BST 的全局约束。

反例：`[5, 1, 6, null, null, 3, 7]`，节点 3 是 6 的左子节点，满足 `3 < 6`，但 3 在根节点 5 的右子树中，应该 `3 > 5`，这是个无效 BST。

### 正确思路：上下界递归

递归时传递当前节点允许的值域 `(lower, upper)`：

- 根节点：`(-∞, +∞)`
- 左子节点：`(lower, parent.val)` — 上界收紧为父节点值
- 右子节点：`(parent.val, upper)` — 下界收紧为父节点值

每层检查 `lower < root->val < upper`，如果不满足则非法。

### 中序遍历思路

BST 的中序遍历结果是严格递增序列。遍历时记录前一个值，如果当前值 ≤ 前一个值，则非法。

## 关键卡点

> [!warning] 我当时卡在这
> - 只检查了父子节点的关系，没有考虑右子树中每个节点都要大于根节点
> - 上下界的约束要**往下传递**，不是只看当前层

> [!warning] 易错边界
> - **int 越界**：如果用 `INT_MIN`/`INT_MAX` 作为初始边界，当节点值刚好等于边界值时会误判。改用 `LLONG_MIN`/`LLONG_MAX`
> - **空树**是合法 BST
> - **单节点**是合法 BST

## 代码

### 解法一：上下界递归

```cpp
class Solution {
private:
    bool helper(TreeNode* root, long long lower, long long upper) {
        if (root == nullptr) return true;
        if (root->val <= lower || root->val >= upper) return false;
        return helper(root->left, lower, root->val) &&
               helper(root->right, root->val, upper);
    }

public:
    bool isValidBST(TreeNode* root) {
        return helper(root, LLONG_MIN, LLONG_MAX);
    }
};
```

### 解法二：中序遍历（迭代）

```cpp
class Solution {
public:
    bool isValidBST(TreeNode* root) {
        long long inorder = LLONG_MIN;
        stack<TreeNode*> stk;
        while (!stk.empty() || root != nullptr) {
            while (root != nullptr) {
                stk.push(root);
                root = root->left;
            }
            root = stk.top();
            stk.pop();
            if (root->val <= inorder) return false;
            inorder = root->val;
            root = root->right;
        }
        return true;
    }
};
```

## 复杂度

- 时间：O(n)，每个节点恰好访问一次
- 空间：O(h)，递归栈/显式栈深度等于树高，最坏 O(n)（链状树）
