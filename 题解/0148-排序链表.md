# 148. 排序链表

> [!abstract] 一句话本质
> **链表排序** → 归并排序。链表不支持随机访问，快排的 partition 做不了，归并只需「顺序遍历 + 改 next」完美匹配。

> [!quote] 链接
> - https://leetcode.cn/problems/sort-list/

## 题目
给定单链表头节点 head，将其按升序排列并返回。进阶要求 O(n log n) 时间、O(1) 空间。

## 思路（自顶向下归并）

1. **找中点**：快慢指针，`fast = head->next` 让 `slow` 落在「左中点」。
2. **断开**：`nextHalf = slow->next; slow->next = nullptr;` 把链表物理切成两段独立的、以 nullptr 结尾的链表。
3. **递归**：分别排序左半、右半。
4. **合并**：复用 21 题「合并两个有序链表」（dummy 节点）。

## 关键卡点
> [!warning] 我踩过的坑（致命）
> - **递归切分时必须 `slow->next = nullptr` 物理断开！** 一开始用左闭右开区间 `[head, tail)` 但没断开，`merge` 只认 `nullptr` 结尾，会越过 `slow` 把右半也吞进来，最后 `尾节点->next` 还指着后面 → **成环 → 死循环/TLE**。
> - 想要 O(1) 空间不能用递归（递归栈 O(log n)），要改成**自底向上迭代归并**（步长 1→2→4… 倍增）。

## 代码
```cpp
class Solution {
    ListNode* merge(ListNode* a, ListNode* b) {
        ListNode dummy(0);
        ListNode* cur = &dummy;
        while (a && b) {
            if (a->val < b->val) { cur->next = a; a = a->next; }
            else                 { cur->next = b; b = b->next; }
            cur = cur->next;
        }
        cur->next = a ? a : b;
        return dummy.next;
    }
public:
    ListNode* sortList(ListNode* head) {
        if (!head || !head->next) return head;        // base case：空或单节点
        ListNode *slow = head, *fast = head->next;    // fast 从 head->next → slow 落左中点
        while (fast && fast->next) {
            slow = slow->next;
            fast = fast->next->next;
        }
        ListNode* nextHalf = slow->next;
        slow->next = nullptr;                         // ★ 必须断开，否则 merge 越界成环
        return merge(sortList(head), sortList(nextHalf));
    }
};
```

## 复杂度
- 时间：O(n log n)，每层合并 O(n)，共 log n 层。
- 空间：O(log n)（递归调用栈）。进阶 O(1) 需自底向上迭代归并。

## 一句话记忆点
> [!tip] 下次看到类似题
> 链表排序 → 归并（找中点 + **断开** + 合并）。**断开是灵魂**，不断开必成环。
