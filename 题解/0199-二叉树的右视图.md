# 199. 二叉树的右视图

> [!abstract] 一句话本质
> **右视图 = 每层最后一个节点**，BFS 层序遍历自然得到。

> [!quote] 链接
> - https://leetcode.cn/problems/binary-tree-right-side-view/

## 题目

给定二叉树根节点，站在右侧看过去，返回能看到的节点值（从上到下）。

## 思路（从暴力到最优）

### 思路一：BFS 层序遍历

层序遍历每一层，取最后一个节点即可。因为 BFS 按层处理，每层从左到右入队，最后一个出队的就是最右边的节点。

### 思路二：DFS（根→右→左）

用"根→右→左"的顺序深度优先遍历，每层**第一个**访问到的节点就是右视图。记录当前深度，每层第一次访问时收集节点值。

两种思路本质互补：BFS 按层取最后一个，DFS 按层取第一个（优先走右边）。

## 关键卡点

> [!warning] 理解要点
> - BFS 的 FIFO 性质保证每层从左到右处理，最后一个出队即最右节点
> - 右子树为空时，左子树的节点仍然可见——代码自然处理了这种情况

> [!warning] 易错边界
> - 空树返回空数组
> - `i == sz - 1` 是最后一个节点（0-indexed），不是 `sz`

## 代码

### 解法一：BFS

```cpp
class Solution {
public:
    vector<int> rightSideView(TreeNode* root) {
        vector<int> res;
        if (!root) return res;
        queue<TreeNode*> q;
        q.push(root);
        while (!q.empty()) {
            int sz = q.size();
            for (int i = 0; i < sz; i++) {
                TreeNode* cur = q.front();
                q.pop();
                if (i == sz - 1) res.push_back(cur->val);
                if (cur->left) q.push(cur->left);
                if (cur->right) q.push(cur->right);
            }
        }
        return res;
    }
};
```

### 解法二：DFS（根→右→左）

```cpp
class Solution {
public:
    vector<int> rightSideView(TreeNode* root) {
        vector<int> res;
        dfs(root, 0, res);
        return res;
    }
    void dfs(TreeNode* root, int depth, vector<int>& res) {
        if (!root) return;
        if (depth == res.size()) res.push_back(root->val);
        dfs(root->right, depth + 1, res);
        dfs(root->left, depth + 1, res);
    }
};
```

## 复杂度

- 时间：O(n)，每个节点恰好访问一次
- 空间：O(n)，BFS 最坏情况（完全二叉树最后一层）队列存储 O(n/2) ≈ O(n)

> [!tip] 下次看到类似题
> **右视图 → 层序遍历取每层最后一个**。如果问左视图，取每层第一个即可。
