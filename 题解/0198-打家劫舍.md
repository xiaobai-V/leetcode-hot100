# 198. 打家劫舍

> [!abstract] 一句话本质
> **线性 DP**：相邻两家不能同时偷。`dp[i]` = 前 i+1 户能偷到的**最大金额**（**不代表第 i 户一定被偷**！），在「不偷 i」和「偷 i」两种决策取 `max`。

> [!quote] 链接
> - https://leetcode.cn/problems/house-robber/

## 题目
数组 `nums`，`nums[i]` 是第 i 户的钱。不能偷相邻两户，求能偷到的最大金额。

## 思路（DP 三件套）

**状态定义**：`dp[i]` = 下标 `0~i` 这前 i+1 户能偷到的最大金额。
> ⚠️ 关键认知：`dp[i]` 是「前 i 户的**最优解**」，第 i 户**可能偷、可能不偷**，由 `max` 决定。别误以为「dp[i] 一定偷了第 i 户」。

**转移方程**：`dp[i] = max(dp[i-1], dp[i-2] + nums[i])`
- `dp[i-1]`：**不偷第 i 户** → 最优解继承自前 i-1 户。（注意 `dp[i-1]` 也不代表第 i-1 户一定被偷）
- `dp[i-2] + nums[i]`：**偷第 i 户** → 第 i-1 户被迫跳过，只能从前 i-2 户的最优接上，再加 `nums[i]`。
- 两者取 max = 前 i 户最优。

**边界**：`dp[0] = nums[0]`，`dp[1] = max(nums[0], nums[1])`（前两户只能偷一户）。

## 关键卡点
> [!warning] 灵魂认知
> - **`dp[i]` 不代表第 i 户一定要被偷**——它是「前 i 户最优」，某轮若取 `dp[i-1]`，说明最优解本就**不该偷第 i 户**，`nums[i]` 没加进去也照样是合法最优。这句想通，状态定义才立得住。
> - 偷第 i 户时为什么从 `dp[i-2]` 接、不是 `dp[i-1]`？因为偷了 i，第 i-1 户被禁，只能隔一格继承。

## 代码

**O(n) 空间：**
```cpp
class Solution {
public:
    int rob(vector<int>& nums) {
        int n = nums.size();
        if (n == 1) return nums[0];
        vector<int> dp(n);
        dp[0] = nums[0];
        dp[1] = max(nums[0], nums[1]);
        for (int i = 2; i < n; i++)
            dp[i] = max(dp[i-1], dp[i-2] + nums[i]);
        return dp[n-1];
    }
};
```

**O(1) 空间（滚动，只依赖前两个 + 只返回一个数 → 能滚动）：**
```cpp
class Solution {
public:
    int rob(vector<int>& nums) {
        int n = nums.size();
        if (n == 1) return nums[0];
        int prev = max(nums[0], nums[1]);  // dp[i-1]
        int preprev = nums[0];              // dp[i-2]
        for (int i = 2; i < n; i++) {
            int cur = max(prev, preprev + nums[i]);
            preprev = prev;
            prev = cur;
        }
        return prev;
    }
};
```

## 复杂度
- 时间：O(n)。
- 空间：O(n) → 可滚动到 O(1)。
