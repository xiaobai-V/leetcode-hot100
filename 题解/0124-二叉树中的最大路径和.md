# 124. 二叉树中的最大路径和

> [!abstract] 一句话本质
> **路径可以分叉，但返回给父节点时只能选一边**。用全局变量记录分叉情况（左+右+当前），递归返回单边最大贡献。

> [!quote] 链接
> - https://leetcode.cn/problems/binary-tree-maximum-path-sum/

## 题目
给定二叉树根节点 `root`，找到其中最大路径和（路径可以从任意节点开始到任意节点结束，不一定要经过根）。

## 思路（从暴力到最优）

**关键洞察：路径在某个节点"分叉"**
- 以当前节点为拐点：路径和 = 左贡献 + 右贡献 + 当前值
- 返回给父节点：只能选一边（左或右）+ 当前值（路径不能分叉往上走）

**为什么需要两个概念？**
- `res`（全局变量）：记录当前节点作为拐点时的最大路径和（可以分叉）
- `dfs` 返回值：以当前节点为起点的单边最大路径和（不能分叉）

**负贡献处理：**
- `left = max(0, dfs(root->left))`：如果左边贡献是负数，直接丢弃（不要左边）

## 关键卡点

> [!warning] 我当时卡在这
> - 一开始想用迭代，把问题复杂化了
> - 分叉（res）和直链（返回值）的区别：分叉时可以同时用左右，返回时只能选一边
> - `max(0, ...)` 的作用：负贡献直接丢弃，不要累加

## 代码

```cpp
class Solution {
private:
    int res = INT_MIN;
    int dfs(TreeNode* root) {
        if (!root) return 0;
        int left = max(0, dfs(root->left));   // 左边最大贡献（负数就不要）
        int right = max(0, dfs(root->right)); // 右边最大贡献
        
        res = max(res, left + right + root->val);  // 当前节点作为拐点的路径和
        return max(left, right) + root->val;       // 返回给父节点：只能选一边
    }
public:
    int maxPathSum(TreeNode* root) {
        dfs(root);
        return res;
    }
};
```

## 复杂度
- 时间：O(n)，每个节点访问一次
- 空间：O(h)，h = 树高（递归栈深度）
