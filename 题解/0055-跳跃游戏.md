# 55. 跳跃游戏

> [!abstract] 一句话本质
> **维护当前最远能到达的下标 maxR**，在能到达的范围内一路扫、不断把 maxR 往右推，看能否够到终点。

> [!quote] 链接
> - https://leetcode.cn/problems/jump-game/

## 题目
给定非负数组 nums，nums[i] 表示从下标 i 最多能跳几步。初始在下标 0，判断能否到达最后一个下标。

## 思路（从暴力到最优）
1. **DP** O(n²)：`dp[i] = 能否到达 i`。对每个 i，检查前面所有 j<i 且 dp[j] 且 `j+nums[j]>=i`。问题：每个 i 要回看所有前驱，O(n²)。
2. **贪心** O(n)：维护 `maxR = 当前最远能到达的下标`。一遍扫描，i 在 `[0, maxR]` 范围内（能到达的位置）往后走，每个位置更新 `maxR = max(maxR, i+nums[i])`。一旦 `maxR >= n-1` 就能到终点。
   - **为什么贪心比 DP 快？** DP 逐个位置判"能否到达"要回看所有前驱 O(n²)；贪心只维护一个全局 maxR，O(n) 一遍扫完，不用回看。

## 关键卡点
> [!warning] 我当时卡在这 / 易错
> - **循环条件 `i <= maxR`**：maxR 是下标，下标 0~maxR 都可达，所以含等号。写成 `i < maxR` 会漏掉恰好等于 maxR 的位置。
> - **边界 `nums=[0]`**：maxR=0=n-1，单元素已在终点，返回 true。
> - **边界 `nums=[0,1]`**：起点 nums[0]=0 跳不动，maxR=0，i=1 时 `i>maxR` 退出，返回 false。
> - 初始化 `maxR=nums[0]`（或 `maxR=0` 更标准，循环内统一更新）。

## 代码
```cpp
class Solution {
public:
    bool canJump(vector<int>& nums) {
        int n = nums.size();
        int maxR = nums[0];                  // 当前最远能到达的下标
        for (int i = 0; i <= maxR && i < n; i++) {
            maxR = max(i + nums[i], maxR);   // 不断往右推
            if (maxR >= n - 1) return true;  // 提前剪枝
        }
        return maxR >= n - 1;                // 走出循环说明没够到
    }
};
```

## 复杂度
- 时间：O(n)，每个位置最多访问一次
- 空间：O(1)

> 能否到达终点 → 贪心维护"最远可达 maxR"，在 i<=maxR 范围内一路推，够到 n-1 就 true。
