# 101. 对称二叉树

> [!abstract] 一句话本质
> **对称 = 根的左右子树互为镜像**。写一个 `isMirror(left, right)`：值相等 + 左树的左 vs 右树的右 + 左树的右 vs 右树的左。

> [!quote] 链接
> - https://leetcode.cn/problems/symmetric-tree/

## 题目
给定二叉树根节点 `root`，判断它是否轴对称（左右子树互为镜像）。

## 思路

**错误思路：翻转再比较**
- 先 `invertTree(root->right)` 翻转右子树，再比较左右是否相同
- 问题：翻转会**永久修改原树结构**，导致后续遍历混乱（节点指向可能形成循环，内存爆炸）
- 而且翻转再比较 = 绕远路，不如直接判断镜像

**正确思路：直接递归判断镜像**
- 辅助函数 `isMirror(left, right)` 判断两棵树是否互为镜像
- 递归条件：
  - 两个都空 → `true`
  - 一个空一个不空 → `false`
  - 都非空：值相等 **且** `isMirror(left->left, right->right)` **且** `isMirror(left->right, right->left)`
- 注意比较方向：**左树的左 vs 右树的右，左树的右 vs 右树的左** —— 这就是镜像的定义

> [!warning] 和 226 翻转二叉树的关系
> 翻转一个子树再比较是否相等，**逻辑上等价于**直接判断镜像。但实现上"直接判断镜像"更简洁安全，不需要修改原树。

## 关键卡点
> [!warning] 我当时卡在这
> - 最初想用"翻转右子树再层序遍历比较"，结果翻转修改了原树结构，BFS 遍历时节点指向混乱导致内存爆炸
> - 正确做法不需要翻转，直接写 `isMirror` 递归比较
> - 比较方向容易混：左树的**左** vs 右树的**右**，左树的**右** vs 右树的**左**

## 代码

```cpp
class Solution {
private:
    bool isMirror(TreeNode* left, TreeNode* right) {
        if (!left && !right) return true;
        if (!left || !right) return false;          // 一空一非空
        if (left->val != right->val) return false;
        return isMirror(left->left, right->right)   // 左树左 vs 右树右
            && isMirror(left->right, right->left);   // 左树右 vs 右树左
    }
public:
    bool isSymmetric(TreeNode* root) {
        if (!root) return true;
        return isMirror(root->left, root->right);
    }
};
```

## 复杂度
- 时间：O(n)，每个节点访问一次
- 空间：O(h)，h = 树高（递归栈深度）
