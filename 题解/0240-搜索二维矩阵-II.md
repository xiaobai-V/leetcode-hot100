# 240. 搜索二维矩阵 II

> [!abstract] 一句话本质
> **从右上角出发，一步排除一行或一列**，不是逐行二分，而是利用矩阵有序性做 Z 字形搜索。

> [!quote] 链接
> - https://leetcode.cn/problems/search-a-2d-matrix-ii/

## 题目
矩阵每行从左到右递增、每列从上到下递增，判断 target 是否存在。

## 思路（从暴力到最优）

**暴力：遍历整个矩阵** → O(mn)，没利用有序性。

**方法一：逐行二分**
每行做一次二分查找，时间 O(m log n)。可行但不够优雅。

**最优：Z 字形搜索**
从右上角出发，利用矩阵的有序性：
- 右上角元素 = 这一行的最小值 = 这一列的最大值
- 当前值 == target → 找到
- 当前值 > target → 向左走（排除当前列，因为下面的更大）
- 当前值 < target → 向下走（排除当前行，因为左边的更小）

每次排除一行或一列，时间 O(m+n)。

```
→ → → ↓
      ↓
      ↓
搜索路径类似 Z 字形
```

## 关键卡点

> [!warning] 易错点
> - 起点必须是右上角（或左下角），左上角/右下角/中心都不行，因为无法确定移动方向
> - 这个方法只能判断存在性，不能找到所有重复位置

## 代码

```cpp
class Solution {
public:
    bool searchMatrix(vector<vector<int>>& matrix, int target) {
        int m = matrix.size(), n = matrix[0].size();
        int i = 0, j = n - 1; // 右上角
        while (i < m && j >= 0) {
            if (matrix[i][j] == target) return true;
            if (matrix[i][j] > target) j--; // 排除这一列
            else i++; // 排除这一行
        }
        return false;
    }
};
```

## 复杂度
- 时间：O(m+n)，最多走 m+n-1 步
- 空间：O(1)

> [!tip] 下次看到类似题
> 行列都有序的矩阵搜索 → 右上角出发，大于就左移、小于就下移，Z 字形走到底。
