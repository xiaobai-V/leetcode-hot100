# 543. 二叉树的直径

> [!abstract] 一句话本质
> **后序遍历一次，同时算深度和直径**——经过每个节点的最长路径 = 左子树深度 + 右子树深度，取全局最大。

> [!quote] 链接
> - https://leetcode.cn/problems/diameter-of-binary-tree/

## 题目
给定一棵二叉树，求任意两节点之间的最长路径长度（边数）。

## 思路（从暴力到最优）

**暴力**：对每个节点，分别调用 `depth()` 算左右子树深度，再递归处理左右子树。问题是 `depth()` 被重复调用，同一节点的深度算了多次 → O(n²)。

**优化**：后序遍历，一个 DFS 同时完成两件事：
1. 返回以当前节点为根的子树深度
2. 用返回的左右深度更新全局直径 `ans = max(ans, left + right)`

关键观察：**经过某节点的最长路径 = 左子树最深路径 + 右子树最深路径**（边数相加）。只有后序遍历能先拿到子树结果再处理当前节点。

## 关键卡点

> [!warning] 易错点
> - 直径定义是**边数**不是节点数，所以 `left + right` 就是答案，不需要 +1 -1
> - 直径不一定过根节点，必须全局取 max
> - 边界：空树返回 0

## 代码

```cpp
class Solution {
private:
    int res = 0;
    int dfs(TreeNode* root) {
        if (!root) return 0;
        int left_depth = dfs(root->left);
        int right_depth = dfs(root->right);
        res = max(left_depth + right_depth, res);
        return max(left_depth, right_depth) + 1;
    }
public:
    int diameterOfBinaryTree(TreeNode* root) {
        dfs(root);
        return res;
    }
};
```

## 复杂度
- 时间：O(n)，每个节点访问一次
- 空间：O(h)，递归栈深度，最坏链状树 O(n)
