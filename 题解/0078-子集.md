# 78. 子集

> [!abstract] 一句话本质
> **回溯求所有子集**，和全排列的区别：用 **startIndex** 控制不重复（不是 used[]），每个节点都是合法子集（不只是叶子节点）。

> [!quote] 链接
> - https://leetcode.cn/problems/subsets/

## 题目
给定不含重复元素的数组，返回所有可能的子集。

## 思路
回溯三步走，但和全排列有两个关键区别：
1. **收集时机**：每个节点都收集（不只是叶子节点），因为每个节点都是一个合法子集
2. **去重方式**：用 `startIndex` 控制只选后面的数，避免 [1,2] 和 [2,1] 重复

## 关键卡点
> [!warning] 我当时卡在这
> - `res.push_back(path)` 必须在 `if (startIdx >= nums.size()) return` **之前**，否则会漏掉最后一个元素结尾的子集
> - 递归调用是 `backtrack(nums, i + 1)` 不是 `backtrack(nums, startIdx + 1)`，用 i 才能保证不重复

## 代码
```cpp
class Solution {
    vector<vector<int>> res;
    vector<int> path;
    void backtrack(vector<int>& nums, int startIdx) {
        res.push_back(path);  // 先收集，再判断
        if (startIdx >= nums.size()) return;
        for (int i = startIdx; i < nums.size(); i++) {
            path.push_back(nums[i]);
            backtrack(nums, i + 1);
            path.pop_back();
        }
    }
public:
    vector<vector<int>> subsets(vector<int>& nums) {
        backtrack(nums, 0);
        return res;
    }
};
```

## 复杂度
- 时间：O(n × 2ⁿ) — 2ⁿ 个子集，每个长度最多 n
- 空间：O(n) — 递归栈深度
