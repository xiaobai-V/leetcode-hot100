# 128. 最长连续序列

> [!abstract] 一句话本质
> **只从序列起点开始数长度**，不是对每个数都往后遍历，而是找到序列的开头才展开。

> [!quote] 链接
> - https://leetcode.cn/problems/longest-consecutive-sequence/

## 题目
给定无序整数数组，找出最长连续序列的长度。要求 O(n) 时间。（如 {100,4,200,1,3,2} → {1,2,3,4} 长度 4）

## 思路（从暴力到最优）
1. **排序**：排序后遍历找最长连续，O(n log n)，不满足题目 O(n) 要求。
2. **哈希集合 + 只从起点数**：
   - 所有数放入 `unordered_set`，O(1) 查询存在性。
   - 遍历集合，对每个数判断 `num - 1` 是否不在集合中——不在，说明是序列起点。
   - 从起点开始，用 while 不断查 `num + 1, num + 2, ...`，数出序列长度。
   - 全局取最大值。
3. **为什么是 O(n)**：每个数最多被访问两次（外层一次 + 被某个起点 while 遍历一次），总 O(n)。

## 关键卡点
> [!warning] 我当时卡在这
> - 最初用 unordered_map 边插入边计数，无法区分不同连续段
> - 外层遍历 nums 而非 uset，重复元素导致 TLE
> - STL 语法：set 用 insert 而非 push_back

## 代码
```cpp
class Solution {
public:
    int longestConsecutive(vector<int>& nums) {
        unordered_set<int> uset;
        for (int i = 0; i < nums.size(); i++) {
            uset.insert(nums[i]);
        }
        int ans = 0;
        for (int num : uset) {
            if (uset.find(num - 1) == uset.end()) {
                int temp = 1;
                while (uset.find(num + temp) != uset.end()) {
                    temp++;
                }
                ans = max(ans, temp);
            }
        }
        return ans;
    }
};
```

## 复杂度
- 时间：O(n)，每个元素最多被访问两次
- 空间：O(n)，哈希集合
