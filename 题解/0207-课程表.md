# 207. 课程表

> [!abstract] 一句话本质
> **拓扑排序判断有向图是否有环**，不是检查直接双向边，而是用入度法 BFS 逐层删节点，删不完就有环。

> [!quote] 链接
> - https://leetcode.cn/problems/course-schedule/

## 题目
给定课程总数 numCourses 和先修关系 prerequisites（[a,b] 表示修 a 前必须先修 b），判断能否修完所有课程。

## 思路（从暴力到最优）
1. **错误思路**：检查直接双向边（i↔j）。问题：环可以是间接的（0→1→2→0），三节点环检查不出来。
2. **正确思路 → 拓扑排序（BFS 入度法）**：
   - 建邻接表 + 算每个节点入度
   - 入度为 0 的节点入队（没有前置依赖，可以先修）
   - BFS：弹出节点，把它指向的节点入度 -1，入度变 0 则入队
   - 最后检查：处理了 numCourses 个节点 → 无环，否则有环

## 关键卡点
> [!warning] 我当时卡在这
> - 邻接矩阵 vs 邻接表：邻接矩阵空间 O(n²)，遍历时需要判断是否为 1；邻接表空间 O(n+k)，直接遍历邻居
> - `cnt` 在入队时 ++（不是出队时），因为入度为 0 的节点不会被重复加入
> - 返回条件：`cnt == numCourses` 表示所有课程都能修完

## 代码
```cpp
class Solution {
public:
    bool canFinish(int numCourses, vector<vector<int>>& prerequisites) {
        vector<int> inDegree(numCourses);
        vector<vector<int>> grid(numCourses);
        for (const auto& req : prerequisites) {
            inDegree[req[0]]++;
            grid[req[1]].push_back(req[0]);
        }
        queue<int> q;
        int cnt = 0;
        for (int i = 0; i < numCourses; i++) {
            if (inDegree[i] == 0) {
                cnt++;
                q.push(i);
            }
        }
        while (!q.empty()) {
            int cur = q.front();
            q.pop();
            for (int next : grid[cur]) {
                inDegree[next]--;
                if (inDegree[next] == 0) {
                    cnt++;
                    q.push(next);
                }
            }
        }
        return cnt == numCourses;
    }
};
```

## 复杂度
- 时间：O(n + k) — 建图 O(k)，BFS 每个节点访问一次 O(n)，每条边访问一次 O(k)
- 空间：O(n + k) — 邻接表 + 入度数组 + 队列
