# 155. 最小栈

> [!abstract] 一句话本质
> **辅助栈同步记录每层最小值**，pop 时一起弹掉，getMin 直接取栈顶。

> [!quote] 链接
> - https://leetcode.cn/problems/min-stack/

## 题目
设计一个支持 push、pop、top 和 **O(1) 获取最小值** 的栈。

## 思路（从暴力到最优）

**暴力想法**：用一个变量 minVal 记录当前最小值。push 时更新 minVal。问题：**pop 掉最小值后，不知道新的最小值是多少**——栈只能访问栈顶，无法快速查询全局最小。

**最优：辅助栈（minStk）**
- minStk 和 stk 同步 push/pop
- minStk[i] = stk 中前 i+1 个元素的最小值
- getMin() = minStk.top()，O(1)

**为什么 minStk 每层都存最小值，而不是只存"新的最小值"？**
- 如果只在遇到更小值时才 push minStk，pop 掉最小值后就不知道次小值是多少
- 每层都存，pop 时 minStk 也 pop，自然恢复上一层的最小值

## 关键卡点
> [!warning] 我当时卡在这
> - 卡在 pop 后 minVal 怎么更新：根本原因是栈无法 O(1) 查询全局最小，所以需要辅助栈提前记录
> - minStk 每层都存当前最小值（不是只在变小时存），这样 pop 时自然恢复
> - 边界：push 第一个元素时 minStk 为空，需要特殊处理

## 代码
```cpp
class MinStack {
    stack<int> stk;
    stack<int> minStk;

public:
    MinStack() {}

    void push(int value) {
        stk.push(value);
        if (!minStk.empty())
            minStk.push(min(value, minStk.top()));
        else
            minStk.push(value);
    }

    void pop() {
        minStk.pop();
        stk.pop();
    }

    int top() { return stk.top(); }

    int getMin() { return minStk.top(); }
};
```

## 复杂度
- 时间：所有操作均 O(1)
- 空间：O(n)，辅助栈额外占用
