# 42. 接雨水

> [!abstract] 一句话本质
> **每个位置的水量 = min(左侧最高, 右侧最高) - 当前高度**，短板效应。双指针优化：总是处理较矮侧，因为另一边一定有更高墙挡着。

> [!quote] 链接
> - https://leetcode.cn/problems/trapping-rain-water/

## 题目
给定柱状图高度数组，计算能接多少雨水。

## 思路（从暴力到最优）
1. **暴力**：每个位置向左右扫描找最大值，O(n²)。
2. **前后缀数组**（当前解法）：预处理 `left_max[i]` 和 `right_max[i]`，O(n) 时间 O(n) 空间。
   - `left_max[i] = max(left_max[i-1], height[i-1])`（从左扫）
   - `right_max[i] = max(right_max[i+1], height[i+1])`（从右扫）
   - 水量 = `max(0, min(left_max[i], right_max[i]) - height[i])`
3. **双指针 O(1) 空间**：左右指针从两端收缩，维护 `leftMax` 和 `rightMax`。
   - 总是处理较矮侧。当 `height[left] < height[right]` 时，右侧一定有墙 >= `height[right]`，水位由 `leftMax` 决定，不需要知道 `rightMax` 精确值。
   - 反之同理。

## 关键卡点
> [!warning] 我当时卡在这
> - 双指针解法中，不理解为什么只关心一侧最大值——关键：处理较矮侧时，另一侧一定有更高墙，水位瓶颈在较矮侧
> - 首尾不遍历：数组两端高度为 0，不能作为挡板储水

## 代码
前后缀数组版：
```cpp
class Solution {
public:
    int trap(vector<int>& height) {
        int n = height.size();
        vector<int> left_max(n, 0), right_max(n, 0);
        for (int i = 1; i < n; i++)
            left_max[i] = max(left_max[i - 1], height[i - 1]);
        for (int i = n - 2; i >= 0; i--)
            right_max[i] = max(right_max[i + 1], height[i + 1]);

        int res = 0;
        for (int i = 1; i < n - 1; i++)
            res += max(0, min(left_max[i], right_max[i]) - height[i]);
        return res;
    }
};
```

双指针版（O(1) 空间）：
```cpp
class Solution {
public:
    int trap(vector<int>& height) {
        int left = 0, right = height.size() - 1;
        int leftMax = 0, rightMax = 0, res = 0;
        while (left < right) {
            if (height[left] < height[right]) {
                leftMax = max(leftMax, height[left]);
                res += leftMax - height[left];
                left++;
            } else {
                rightMax = max(rightMax, height[right]);
                res += rightMax - height[right];
                right--;
            }
        }
        return res;
    }
};
```

## 复杂度
- 前后缀数组：时间 O(n)，空间 O(n)
- 双指针：时间 O(n)，空间 O(1)
