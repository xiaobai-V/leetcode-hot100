# 438. 找到字符串中所有字母异位词

> [!abstract] 一句话本质
> **固定大小的滑动窗口**，不是变长窗口。判断窗口内字符频次与 `p` 是否一致。

> [!quote] 链接
> - https://leetcode.cn/problems/find-all-anagrams-in-a-string/

## 题目
给定字符串 `s` 和 `p`，找出 `s` 中所有 `p` 的字母异位词子串的起始索引。

## 思路（从暴力到最优）

**暴力**：每个长度为 `len(p)` 的子串都重新统计字符频次 → O(n·m)。

**优化**：滑动窗口——窗口大小固定为 `len(p)`，每次只更新边界字符的频次：
- 移入新字符 → `sCount[c]++`
- 移出旧字符 → `sCount[c--`
- 比对 `sCount == pCount`

**关键改进**：
1. 用 `vector<int>(26)` 代替 `unordered_map`，固定大小、比较快、可直接 `==` 比较
2. 窗口更新逻辑放在主循环里，不要藏在判断函数内（避免耦合）

## 关键卡点

> [!warning] 我当时卡在这
> - **第一版暴力 O(n·m)**：每个窗口都重新统计字符，没意识到可以滑动复用。
> - **第二版窗口更新藏在 isAnagram 里**：函数职责不清，上层不知道状态被修改，容易出 bug。应该把窗口更新移到主循环。
> - **数据结构选择**：用 `unordered_map` 比较重，固定 26 字母场景用 `vector<int>(26)` 更合适。

## 代码

```cpp
class Solution {
public:
    vector<int> findAnagrams(string s, string p) {
        vector<int> res;
        int len1 = s.size(), len2 = p.size();
        if (len1 < len2) return res;

        vector<int> sCount(26), pCount(26);
        // 初始化：p 全部 + s 前 len2 个
        for (int i = 0; i < len2; i++) {
            sCount[s[i] - 'a']++;
            pCount[p[i] - 'a']++;
        }
        if (sCount == pCount) res.push_back(0);

        // 滑动窗口：i 为窗口起始索引
        for (int i = 1; i <= len1 - len2; i++) {
            sCount[s[i - 1] - 'a']--;              // 移出 s[i-1]
            sCount[s[i + len2 - 1] - 'a']++;       // 移入 s[i+len2-1]
            if (sCount == pCount) res.push_back(i);
        }
        return res;
    }
};
```

## 复杂度
- 时间：O(26n) = O(n)
- 空间：O(26) = O(1)
