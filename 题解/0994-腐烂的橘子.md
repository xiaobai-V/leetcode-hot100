# 994. 腐烂的橘子

> [!abstract] 一句话本质
> **多源 BFS 层序遍历**，不是单个起点扩散，而是所有腐烂橘子同时向外扩展，BFS 一层 = 1 分钟。

> [!quote] 链接
> - https://leetcode.cn/problems/rotting-oranges/

## 题目
m×n 网格，0=空，1=新鲜橘子，2=腐烂橘子。每分钟腐烂橘子向四方向感染相邻新鲜橘子。求所有新鲜橘子腐烂的最少分钟数，不可能则返回 -1。

## 思路（从暴力到最优）
1. **暴力想法**：每分钟遍历整个网格，找出所有腐烂橘子，感染相邻新鲜橘子。重复直到无变化。O(mn × mn)。
2. **优化 → 多源 BFS**：所有腐烂橘子同时入队，BFS 层序遍历。每弹一层 = 过了 1 分钟，扩散到的新橘子变烂入队。
3. **关键**：多源 BFS 的核心是**多个起点同时入队**，BFS 自然按层扩散，不需要模拟每分钟。

## 关键卡点
> [!warning] 我当时卡在这
> - 没想到多源 BFS——多个起点同时入队，BFS 一层 = 1 分钟
> - `while(!q.empty() && fresh > 0)` 中 `fresh > 0` 的作用：防止最后一层空扩散（fresh=0 但队列还有橘子时，再进循环会多算一层）
> queue, pair 的语法不够熟悉

## 代码
```cpp
class Solution {
public:
    int orangesRotting(vector<vector<int>>& grid) {
        int m = grid.size(), n = grid[0].size();
        int res = 0;
        int fresh = 0;
        queue<pair<int, int>> q;

        // 初始化：统计新鲜橘子，所有腐烂橘子入队
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == 1) fresh++;
                if (grid[i][j] == 2) q.emplace(i, j);
            }
        }

        vector<pair<int, int>> dirs = {{0,1},{1,0},{0,-1},{-1,0}};

        // 层序遍历：每层 = 1 分钟
        while (!q.empty() && fresh > 0) {
            int sz = q.size();
            for (int i = 0; i < sz; i++) {
                auto [x, y] = q.front();
                q.pop();
                for (auto [dx, dy] : dirs) {
                    int nx = x + dx, ny = y + dy;
                    if (nx < 0 || nx >= m || ny < 0 || ny >= n) continue;
                    if (grid[nx][ny] == 1) {
                        grid[nx][ny] = 2;
                        fresh--;
                        q.emplace(nx, ny);
                    }
                }
            }
            res++;
        }
        return fresh > 0 ? -1 : res;
    }
};
```

## 复杂度
- 时间：O(m×n) — 每个格子最多入队一次
- 空间：O(m×n) — 最坏情况队列存所有格子
