# 215. 数组中的第 K 个最大元素

> [!abstract] 一句话本质
> **TopK 问题**：要找第 K 大，就维护一个**大小为 k 的小顶堆**，堆里始终装着"目前见过的最大的 k 个"，堆顶就是第 K 大。不是把所有数都塞堆里再 pop。

> [!quote] 链接
> - https://leetcode.cn/problems/kth-largest-element-in-an-array/

## 题目
返回无序数组中第 K 个最大的元素（注意是**第 K 大**，不是下标）。

## 思路（从暴力到最优）

**暴力 O(n log n)**：整个数组排序，返回 `nums[n-k]`。简单但没用到堆。

**堆解法 O(n log k)**（本题标准套路）：
- 建一个**小顶堆**，容量限制为 k；
- 遍历每个数：
  - 堆没满 k 个 → 直接 push；
  - 堆满了 → 看堆顶：如果当前数 **> 堆顶**，就把堆顶扔掉、放进当前数（替换掉"最大的 k 个"里最小的那个）；否则跳过。
- 遍历完，堆顶 = 第 K 大。

**进阶 O(n)（以后回来攻克）**：**快速选择 quickselect**。像快排那样选 pivot 做 partition，但只递归包含第 K 大的那一半，平均 O(n)，最坏 O(n²)（随机化 pivot 可规避）。先记名词，不展开。

> [!info] 为什么找"第 K 大"要用「小」顶堆？
> 堆里装的是"最大的 k 个数"。小顶堆的堆顶 = 这 k 个里**最小**的那个 = 正好是**第 K 大**。如果用大顶堆，堆顶是最大的那个 = 第 1 大，反而拿不到第 K 大。**反着记：找第 K 大→小顶堆；找第 K 小→大顶堆。**

## 关键卡点
> [!warning] 我当时卡在这
> - **第一版把 n 个全塞进大顶堆再 pop k-1 次**：能 AC，但是 O(n log n)，没满足进阶 O(n)。堆解法的精髓是**只维护大小 k 的堆**，不全塞。
> - **小顶堆语法在背**：`priority_queue<int>` 默认是大顶堆；小顶堆要写全三个参数 `priority_queue<int, vector<int>, greater<int>>`。
> - **lambda 比较器语法写错**：`auto cmp[](...)` 漏了 `=`，正确是 `auto cmp = [](...){...};`。

## 代码
```cpp
class Solution {
public:
    int findKthLargest(vector<int>& nums, int k) {
        // 维护大小为 k 的小顶堆，只放"最大的 k 个"
        priority_queue<int, vector<int>, greater<int>> pq;
        for (int x : nums) {
            if ((int)pq.size() < k) {
                pq.push(x);
            } else if (pq.top() < x) {  // 比堆顶大才替换
                pq.pop();
                pq.push(x);
            }
        }
        return pq.top();
    }
};
```

## 复杂度
- 时间：O(n log k)。每个元素至多一次 push/pop，单次 O(log k)。
- 空间：O(k)。堆大小不超过 k。
