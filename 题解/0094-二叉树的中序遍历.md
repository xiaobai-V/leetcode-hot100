# 94. 二叉树的中序遍历

> [!abstract] 一句话本质
> **中序 = 左→根→右**。递归版三行代码；迭代版用栈手动模拟递归调用栈，**框架通用，前中后序只挪一行 `push_back` 的位置**。

> [!quote] 链接
> - https://leetcode.cn/problems/binary-tree-inorder-traversal/

## 题目
给定二叉树根节点 `root`，返回其中序遍历结果。

## 思路

**递归版（直接）**
- 递归左子树 → 访问根 → 递归右子树
- 时间 O(n)，空间 O(h)，h = 树高（递归栈）

**迭代版（栈模拟递归）**

核心理解：**栈 = 递归调用栈**。`push` = 递归调用（展开），`pop` = 递归返回（回溯）。

为什么需要栈？二叉树不像链表可以一路往前，访问完左子树后要**"回头"**访问根和右子树，所以需要栈记住回来的路。

递归 ↔ 迭代对应：
| 递归 | 迭代 |
|---|---|
| `Traversal(root->left)` | `while(root){ stk.push(root); root=root->left; }` 一路左走，沿途压栈 |
| `res.push_back(root->val)` | `root = stk.top(); stk.pop(); res.push_back(...);` 弹栈 = 返回到那一层 |
| `Traversal(root->right)` | `root = root->right;` |

**框架通用，前中后序只挪一行**：

```cpp
while (root || !stk.empty()) {
    while (root) {
        // 【A】push 之前 → 前序（根先访问）
        stk.push(root);
        root = root->left;
    }
    root = stk.top(); stk.pop();
    // 【B】pop 之后 → 中序（左子树处理完才访问根）
    res.push_back(root->val);   // 中序在这
    root = root->right;
}
```

- 前序（根→左→右）：`push_back` 移到 **A** 位置（`stk.push` 之前），删掉 B 那行
- 中序（左→根→右）：`push_back` 在 **B** 位置
- 后序（左→右→根）：更复杂，需额外 `prev` 指针标记右子树是否处理过

## 关键卡点
> [!warning] 我当时卡在这
> - 迭代版不熟练：一开始只写递归，不敢碰迭代。把框架背下来多写几遍就熟了
> - 前序/中序迭代版的区别：`push_back` 位置不同，前序在压栈前记录，中序在弹栈后记录
> - 后序不是简单挪位置：需要额外状态，单独攻克

## 代码

**递归版：**
```cpp
class Solution {
private:
    vector<int> res;
    void traversal(TreeNode* root) {
        if (!root) return;
        traversal(root->left);
        res.push_back(root->val);
        traversal(root->right);
    }
public:
    vector<int> inorderTraversal(TreeNode* root) {
        traversal(root);
        return res;
    }
};
```

**迭代版：**
```cpp
class Solution {
public:
    vector<int> inorderTraversal(TreeNode* root) {
        stack<TreeNode*> stk;
        vector<int> res;
        while (root || !stk.empty()) {
            while (root) {
                stk.push(root);
                root = root->left;
            }
            root = stk.top(); stk.pop();
            res.push_back(root->val);
            root = root->right;
        }
        return res;
    }
};
```

## 复杂度
- 时间：O(n)
- 空间：O(h)，h = 树高。最坏 O(n)（链状树），平衡树 O(log n)
