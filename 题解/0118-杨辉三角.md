# 118. 杨辉三角

> [!abstract] 一句话本质
> **按行递推生成**杨辉三角：每个数 = 上一行「肩上左右」两数之和 `res[i][j] = res[i-1][j-1] + res[i-1][j]`，每行首尾是 1。本质是组合数 **C(i,j)**。

> [!quote] 链接
> - https://leetcode.cn/problems/pascals-triangle/

## 题目
给定行数 `numRows`，生成杨辉三角的前 `numRows` 行。

## 思路（递推生成）

**状态**：`res[i][j]` = 第 `i` 行第 `j` 个数（行、列都从 0 起，第 `i` 行有 `i+1` 个数）。

**转移**：`res[i][j] = res[i-1][j-1] + res[i-1][j]`（左上 + 正上）。

**边界**：每行首尾元素都是 1。

> [!info] 组合数联系
> 第 `i` 行第 `j` 个数 = **C(i, j)**，所以它左右对称、也是二项式 `(a+b)^i` 的系数。

## 关键卡点 / 易错
> [!warning] 两个点
> - **首尾的 1 怎么处理最干净**：用 `resize(i+1, 1)` 把整行先全填 1，循环只递推中间 `j=1..i-1`，首尾天然保留，省掉所有特判。
> - **这题空间不能滚动优化**：要 `return` 整个三角，每行都得留着 → 结果数组 O(n²)。能滚动的前提是「中间结果用完即弃」（如 [[0070-爬楼梯]] 只返回一个数），本题不满足。

## 代码

**自己 AC 的版本（首元素预填 + resize + 末尾特判）：**
```cpp
class Solution {
public:
    vector<vector<int>> generate(int numRows) {
        vector<vector<int>> res(numRows, vector<int>(1, 1));  // 每行首元素先填1
        for (int i = 1; i < numRows; i++) {
            res[i].resize(i + 1);
            for (int j = 1; j <= i; j++) {
                if (j == i) res[i][j] = 1;                    // 末尾1
                else res[i][j] = res[i-1][j-1] + res[i-1][j]; // 左上+正上
            }
        }
        return res;
    }
};
```

> [!tip] 更简洁写法（整行填1，只递推中间）
> ```cpp
> vector<vector<int>> c(numRows);
> for (int i = 0; i < numRows; i++) {
>     c[i].resize(i + 1, 1);                // 整行填1，首尾天然是1
>     for (int j = 1; j < i; j++)            // 只递推中间
>         c[i][j] = c[i-1][j-1] + c[i-1][j];
> }
> return c;
> ```

## 复杂度
- 时间：O(n²)，总元素数 = 1+2+…+n。
- 空间：结果数组 O(n²)（不可滚动）；辅助空间 O(1)。

## 一句话记忆点
> [!tip] 下次看到类似题
> **每个数 = 左上 + 正上，首尾填 1**；用 `resize(i+1,1)` 省特判。要返回全部行的，空间就别想滚动。
