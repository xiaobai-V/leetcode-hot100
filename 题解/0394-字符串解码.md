# 394. 字符串解码

> [!abstract] 一句话本质
> **栈处理「嵌套展开」**：遇到 `[` 把当前状态存快照、重置去处理子问题；遇到 `]` 取快照、用子结果扩展。不是「递归」,而是「显式栈 + 快照重置恢复」。

> [!quote] 链接
> - https://leetcode.cn/problems/decode-string/

## 题目
编码字符串 `3[a2[c]]` 解码成 `accaccacc`。形如 `k[encoded_string]` 表示把方括号内的串重复 k 次。数字、括号可嵌套。**数字可能是多位**（如 `11[c]`）。

## 思路（从暴力到最优）

**核心模型**：始终维护「当前正在拼的字符串 `res`」+ 两个栈存快照。

- `numStk`：进入 `[` 时的重复次数 k
- `strStk`：进入 `[` 时「之前已经拼好的结果」

**为什么字母不入栈，`[` 却要压栈？**
字母是「当前层的内容」，直接拼到 `res` 即可；`[` 标志着「新一层子问题开始」，必须把「上一层的结果」快照保存，等子问题结束（`]`）才能正确接回去。

**四个分支**：

| 字符 | 操作 |
|---|---|
| 数字 | `k = 10*k + ch - '0'`（高位先来，逐位累加） |
| 字母 | `res += ch;`（直接拼） |
| `[` | `numStk.push(k); strStk.push(res); k=0; res.clear();`（存快照 + 重置） |
| `]` | 取快照：`prev=strStk.top()`, `times=numStk.top()`；`while(times--) prev += res;` 最后 `res = prev;`（恢复） |

**关键巧思：数字解析不需要 `while`**。题目保证数字后必跟 `[`，所以遇到每个数字位累加 `k = 10*k + d`，等 `[` 自然来「收尾」压栈即可——被动等分隔符收尾，比主动 `while` 吃完更简洁。

**为什么 `]` 里必须 `res = prev`？**
让「内层拼好的完整结果」成为外层的「当前字符串」，外层 `]` 才能正确重复。
走一遍 `2[a3[b]]`：内层 `]` 算出 `res="abbb"`（靠 `res=prev`）；外层 `]` 拿到 `res="abbb"` 重复 2 次 → `abbbabbb`。**不写 `res=prev`**，内层 `]` 后 `res` 还停在 `"b"`，外层算成 `bb`，直接错。

## 关键卡点
> [!warning] 我当时卡在这
> - **数字可能是多位**（`11[c]`），不能假定只有一位 → 用 `k = 10*k + ch-'0'` 累加
> - `]` 里最后 **必须 `res = prev`**，否则嵌套结构外层拿不到内层结果
> - 不要用 `stack<char>` 一个个字符压栈——会丢失「层」的信息，遇到 `]` 时不知道从哪切分
> - 用 `stack<string>` + 一个 `res` 变量，比单字符栈清晰得多

## 代码
```cpp
class Solution {
public:
    string decodeString(string s) {
        string res;             // 当前正在拼的字符串
        stack<int> numStk;      // 进入 [ 时的重复次数
        stack<string> strStk;   // 进入 [ 时之前的 res 快照
        int k = 0;
        for (char ch : s) {
            if (isdigit(ch)) {
                k = 10 * k + ch - '0';
            } else if (islower(ch)) {
                res += ch;
            } else if (ch == '[') {
                numStk.push(k);
                strStk.push(res);
                k = 0;
                res.clear();
            } else if (ch == ']') {
                string prev = strStk.top(); strStk.pop();
                int times = numStk.top();  numStk.pop();
                while (times--) prev += res;
                res = prev;
            }
        }
        return res;
    }
};
```

## 复杂度
- 时间：$O(L)$，$L$ = 输出字符串长度。每个字符最终被写出一次。**不能用输入长度衡量**——`100[100[100[a]]]` 输入十几字符，输出 $10^6$。
- 空间：$O(L)$，栈深度 + 最终字符串。
