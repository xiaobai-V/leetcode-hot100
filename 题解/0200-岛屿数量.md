# 200. 岛屿数量

> [!abstract] 一句话本质
> **统计连通分量个数**，不是数格子，而是每次遇到未访问的陆地就 DFS 淹没整个岛，计数 +1。

> [!quote] 链接
> - https://leetcode.cn/problems/number-of-islands/

## 题目
给定 m×n 的二维网格（'1'=陆地，'0'=海洋），统计岛屿数量。岛屿由水平/垂直方向上相邻的陆地连接而成。

## 思路（从暴力到最优）
1. **暴力想法**：遍历每个格子，遇到 '1' 就 BFS/DFS 标记整个岛，计数 +1。
2. **优化**：不需要额外的 visited 数组——直接把访问过的陆地改成 '0'（淹没），grid 本身就是 visited 标记。
3. **最终**：遍历 grid，遇到 '1' 就 DFS 淹没整座岛，res++。

## 关键卡点
> [!warning] 我当时卡在这
> - 一开始同时维护 grid 和 isVisited 数组，其实只需要 grid 就够了（KISS）
> - `isVisited[i][j] == true` 写成了比较而不是赋值，碰巧能 AC 因为 isVisited 本就没用到

## 代码
```cpp
class Solution {
    void dfs(vector<vector<char>> &grid, int i, int j)
    {
        if(i < 0 || i >= grid.size() || j < 0 || j >= grid[0].size())
            return;
        if(grid[i][j] == '0')
            return;
        grid[i][j] = '0';
        dfs(grid, i-1, j);
        dfs(grid, i+1, j);
        dfs(grid, i, j-1);
        dfs(grid, i, j+1);
    }

public:
    int numIslands(vector<vector<char>>& grid) {
        int m = grid.size(), n = grid[0].size();
        int res = 0;
        for(int i = 0; i < m; i++)
        {
            for(int j = 0; j < n; j++)
            {
                if(grid[i][j] == '1')
                {
                    res++;
                    dfs(grid, i, j);
                }
            }
        }
        return res;
    }
};
```

## 复杂度
- 时间：O(m×n) — 每个格子最多被访问一次
- 空间：O(m×n) — 最坏情况（全陆地）递归栈深度
